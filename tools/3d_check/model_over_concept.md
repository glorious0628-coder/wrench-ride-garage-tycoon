# 시안과 겹쳐 보면서 3D 만들기 (모든 3D 세션 공통, 사용자 10-20 14:1x)

사용자: "그리고 하는 방법 알려줘. 시안과 겹쳐서 확인하면서 하는 거야."
→ 다 만든 뒤에 한 번 비교하는 게 아니라, **만드는 동안 단계마다** 시안 위에 겹쳐 보면서 맞춰요.

## 1. 시안 준비
1. 사용자 OK 난 6면 시안을 칸으로 나눔: `py -I tools/split_6view.py <sheet.png> <out_prefix>` → `_front/_back/_left/_right/_top/_bottom.png`
   (윗줄 = 앞·뒤·왼쪽(물건 자기 왼쪽), 아랫줄 = 오른쪽·위·아래)
2. 칸마다 물건이 차지하는 박스(투명/흰 배경 제외)를 재서 **폭:높이:깊이 비율**을 적어 둠 → 게임 자리 크기(슬롯 규격)에 맞춰 Blender 단위로 환산.

## 2. Blender에 시안 깔기 (헤드리스 스크립트)
- 앞·옆·위 칸을 **기준 그림(Reference Image Empty)**으로 축에 맞춰 놓음: 앞 = −Y 쪽에서 본 면(게임 앞 = −Z와의 변환은 내보낼 때), 옆 = X, 위 = Z. 물건 높이가 슬롯 높이와 같도록 크기·위치 맞춤, 불투명도 0.5.
- 같은 방향의 **정투영(Orthographic) 카메라** 6대를 시안 칸과 같은 화면 비율·같은 여백으로 둠 → 렌더하면 시안 칸과 1:1로 겹쳐짐.

## 3. 만드는 동안 (부품마다 반복)
1. 큰 몸통부터 기본 도형으로 → **앞·옆·위 3방향 정투영 렌더(투명 배경)**
2. `py -I notes/design/3d_tools/concept_compare.py`로 시안 칸과 **겹치기(50%)·윤곽 비교(시안 빨강/3D 파랑)·폭/높이 % 차이**
3. 차이가 **3% 넘으면 그 부품부터 고치고** 다시 2로. 맞으면 다음 부품(종·다리·손잡이·간판 …)
4. 곡선·원은 2배 확대 렌더로 각짐·물결 확인
5. 색: `tools/blender/part_colours.py`로 시안 칸에서 부위별 색 코드를 재서 그대로(눈대중 X), 색 경계는 엣지 루프로 직선

## 4. 1차 보고에 꼭 넣을 것
- 6방향 **시안 | 3D | 겹침** 비교 시트 1장 + 방향별 % 차이 표
- 2배 확대(곡선·색 경계), 뒤집힌 면 15방향, 삼각형 수
- 2차(pp-3d-check)는 이 시트가 없으면 바로 돌려보냄

## 5. 겉면 그림(블록에 입히는 것)도 같게
블록 앞면 크기 비율에 시안을 맞춰 텍스처를 만들고, 블록 앞면 렌더 위에 시안을 겹쳐 창문·간판 위치가 맞는지 확인.

## 섞기 표 (오리지널, 디즈니 X)
| 가져오는 곳 | 특징 |
|---|---|
| 실제 거대 호박(03) | 몸통 = **깊은 세로 골이 있는 납작한 주황 호박**, 지붕에 **굵고 꼬인 초록 꼭지** + 짧은 덩굴·잎 2~3장 |
| 퍼레이드 호박 차(01) | 진짜 차 바퀴·차대 위에 호박 껍데기 = 우리 세단 차대 + 호박 몸통 |
| 옛 동화 삽화(02·04, 1800~1900년대) | 마차풍 큰 바퀴 느낌(가는 살 휠 커버), 아주 적은 금색 테두리 장식, 뒤에 마부 발판 느낌의 작은 발판 |
| 잭오랜턴 | 전조등 = 둥근 눈 2, 그릴 = 웃는 입(이 몇 개), **귀엽게**(무섭지 않게) |
| 신데렐라 | 옛 삽화의 **풍성한 무도회 드레스 + 작은 티아라 + 유리 구두**만. 색은 디즈니 파랑 피해 **은빛 + 연분홍 + 호박 주황 포인트**(리본·허리띠). 머리띠·목 리본 X |
| 유리 구두 | 투명 유리 굽 높은 구두, 은빛 받침 쿠션 위 트로피(선반 장식) |

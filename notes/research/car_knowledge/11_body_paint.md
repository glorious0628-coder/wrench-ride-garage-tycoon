# 차체·판금·도색 (Body, Collision Repair & Paint)

> 기준 차: 가로배치 직렬 4기통 앞바퀴굴림(FF) 중형 세단, 미국 왼쪽 운전석 (예: Toyota Camry XV70/XV80, Honda Accord 10·11세대, Hyundai Sonata DN8, Nissan Altima L34).
> 차 안 좌표·이름은 `docs/specs/car_spec.md` 기준(앞 = −Z, 운전석 = −X).
> 출처는 각 줄 끝 [n] → 맨 아래 '출처' 목록. 출처 없는 문장은 쓰지 않아요. 못 찾은 건 "(확인 못 함)".
> 조사 한계: Eastwood·3M·PPG·RepairPal 페이지 다수가 막히거나(403) 시간 초과라, 도색 숫자는 열린 제품 자료(Eastwood 프라이머 자료표, 3M 마감 공정 기사, 도료 회사 공정표)와 위키를 썼어요. Camry 범퍼·보닛 수치는 wr-carbook가 확인한 Camry XV70 정비 매뉴얼(tocamry) 기준, 앞 범퍼 떼기 페이지는 직접도 열었어요.

## 한눈에 (3줄)
- 요즘 승용차는 **유니바디**(차체 = 뼈대): 앞 펜더·보닛·범퍼·문은 **볼트로 뗌**, 뒤 쿼터 패널·지붕은 **용접** [1][2][3].
- 범퍼는 **플라스틱 커버(PP/TPO)** + 뒤에 **스티로폼 같은 충격 흡수재** + **쇠 보강 빔**의 3겹, 커버는 볼트 몇 개가 아니라 **나사·클립·걸쇠(claw) 수십 개**로 붙어요 [4][5][6].
- 도색은 "샌딩 → 프라이머 → 칠"이 아니라 **세척 → 샌딩(80→180→320~400) → 마스킹 → 프라이머(에폭시/서페이서) → 실러 → 베이스(색) → 클리어(2K) → 건조 → 물사포(1500→3000) → 광내기** [7][8][9][10].

## 부품: 유니바디 기본 (Unibody / Unitized Body)
### ① 하는 일
- 바닥·차체·뼈대가 **하나로 힘을 받는 구조**. 따로 된 프레임 위에 몸통을 올린 방식(body-on-frame)보다 가볍고 단단해요. 지금은 일반 승용차의 표준이에요 [1].
- 엔진·서스펜션 무게는 **서브프레임**이 받아서 얇은 차체에 퍼뜨려요 [1].
- **찌그러짐 구역(Crumple Zone)**: 앞(가끔 뒤)을 일부러 약하게 만들어 부서지면서 충격을 먹고, 사람 칸은 단단한 "안전 셀"로 지켜요. 충돌 피해의 65%는 앞, 25%는 뒤 [2].
- 낮은 속도(약 20 km/h까지) 충돌은 범퍼 뒤 **크래시 박스**가 대신 찌그러져 뼈대 손상을 줄여요 [2].

### ② 모양·재질
- 강판을 찍어 **점용접**으로 이어 붙인 상자들(문턱·기둥·지붕 빔) [1].
- Accord 10세대: 차체의 **29%가 초고장력강(780 MPa 이상)**, 54.2%가 440 MPa 이상 고장력강, 구조용 접착제를 많이 씀 [11].
- 590 MPa 넘는 부품은 대부분 **교체만** 가능(잘라 이어 붙이기·열 가하기 제한) [11].

### ③ 위치 — 볼트 vs 용접
| 패널 | 붙는 방식 | 출처 |
|---|---|---|
| 앞 펜더 (Front Fender) | **볼트** — 풀고 새것으로 바꾸면 됨 | [3] |
| 뒤 쿼터 패널 (Quarter Panel) | 차체에 **용접** — 공장 이음선에서 잘라 내고 새 판 용접, 이음선 갈고 실링 후 도색 | [3][12] |
| 라디에이터 코어 서포트 (Radiator Core Support) | 보닛 걸쇠가 붙는 윗부분 = "upper radiator support"(wr-carbook 확인, diagrams/index.md) [13]. 볼트/용접 여부 (확인 못 함) | |
| 앞 범퍼 보강 빔 | 프레임 끝에 **볼트 8개, 43 N·m** (Camry) | [6] |

### ⑤ 흔한 고장
| 증상 | 원인 | 진단 | 수리법 · 시간 |
|---|---|---|---|
| 쿼터 패널 크게 찌그러짐 | 뒤 옆 충돌 | 눈, 안쪽 패널(숨은 손상) 확인 [12] | 전체 교체 = 뒷유리·뒤 범퍼 떼었다 붙이기 + 실링 포함, 연료탱크·안테나 떼기는 따로 추가 / 부분 교체(sectioning)가 공임 적음 [12]. Honda는 다른 차에서 자른 조각 붙이기 반대 [12] |

### ⑥ 게임 손맛 아이디어
- "볼트 패널(펜더) = 렌치로 쉽게, 용접 패널(쿼터) = 그라인더+용접기 필요" — 장비 해금의 이유가 돼요.

## 부품: 보닛 (Hood)
### ① 하는 일
- 엔진룸 덮개. 보행자 머리 부상을 줄이려고 안쪽 판 구조를 바꾸거나, 충돌 때 몇 cm 튀어 오르는 "액티브 후드"도 있어요 [14].

### ② 실제 모양·크기·재질·색 — 특징 3개
- 재질: 보통 차체와 같은 **강철**, 또는 알루미늄·유리섬유·탄소섬유 [14]. Accord 10세대 보닛이 알루미늄이라는 말은 검색 요약(SAE 기사)에만 있고, 열어 본 기사는 확인 안 해 줌 → (확인 못 함) [11].
- 바깥 판(outer skin) + 안쪽 뼈대 판(inner) 2겹 — 출처 (확인 못 함).
- Camry XV70: 안쪽에 **방음·단열 패드(hood insulator) 클립 9개**, 앞끝 아래 **라디에이터 서포트 쪽 실(seal) 클립 10개**, **워셔액 호스(클램프 5 + 고무 그로밋) + 워셔 노즐**이 보닛에 달림 [13].
- 캐주얼 특징 3개: ① 앞이 살짝 내려간 큰 판 ② 열면 안쪽의 **검은 단열 패드** ③ 뒤쪽 끝의 **워셔 노즐 2개**.

### ③ 차 안 위치
- 엔진룸 위, 경첩은 뒤쪽(앞유리 쪽), 걸쇠는 앞쪽 [13].

### ④ 붙어 있는 방식
- **경첩 볼트 4개(경첩당 2개), 13 N·m** (Camry XV70) [13]. 볼트 머리 크기 (확인 못 함).
- 받침: **받침대(prop rod, "hood stay") + 받침대 걸이** — 가스 쇼바 아님 (Camry) [13].
- 걸쇠: **hood lock** 은 upper radiator support 에 있고, **실내 레버 → 당김 케이블**로 열어요 [13][14]. 레버는 보통 운전대 아래·운전석 옆·문틀 쪽 [14].
- **안전 걸쇠(safety catch)**: 미국 FMVSS 113 — 모든 보닛은 1차 걸쇠, **앞에서 열리는 보닛**(열렸을 때 시야를 가림)은 **2차 걸림 위치 또는 2번째 걸쇠**가 의무 [15]. 2차 걸쇠의 실제 모양(앞틈 손가락 레버 등)은 (확인 못 함).
- 떼는 순서: 보닛에 달린 워셔 호스(클램프·그로밋)와 경첩 볼트 4개가 있다는 건 확인 [13], 정확한 순서 페이지는 (확인 못 함). 다시 달 때 틈 맞추기: Camry 보닛 틈 기준 **2.8~6.8 mm 등** [13].

### ⑤ 흔한 고장
| 증상 | 원인 | 진단 | 수리법 · 시간 |
|---|---|---|---|
| "보닛이 안 닫혀요 / 튕겨 올라와요" | 걸쇠 뻑뻑·녹, 위치 틀어짐, 케이블 늘어남 — 원인 출처 (확인 못 함) | 닫아 보기, 걸쇠 눈으로 | 걸쇠 청소·윤활, 위치 조정, 케이블·걸쇠 교체 — (확인 못 함) |
| 레버 당겨도 안 열림 | 케이블 끊김 (확인 못 함) | | |
| 보닛 틈이 한쪽만 넓음 | 경첩·걸쇠 위치 틀어짐 | 틈 게이지로 2.8~6.8 mm 기준과 비교 [13] | 경첩 볼트 살짝 풀고 맞춘 뒤 13 N·m [13] |
| 앞 끝 찌그러짐 | 앞 충돌 | | 판금 또는 교체 |
- 공임 시간: (확인 못 함).

### ⑥ 게임 손맛 아이디어
- 보닛 열기 2단계: 실내 레버 "딸깍" → 보닛이 2 cm 뜸 → 앞틈 손 넣어 안전 걸쇠 밀기 → 받침대 꽂기. 진짜 같고 귀여움.
- 다시 달 때 **틈 맞추기 미니게임**(좌우 틈이 같아지면 "딱" 소리).

## 부품: 앞 범퍼 (Front Bumper Assembly)
### ① 하는 일
- 작은 충돌 충격을 먹어 다른 부품 수리비를 줄여요 [16]. 미국 기준: 1972년 시작, 1976년 49 CFR 581로 통합, 1982년 시험 속도를 5 mph → **2.5 mph**로 낮춤 [16]. 보행자 다리 부상을 줄이려고 낮고 무르게 만들어요 [16].

### ② 실제 모양·재질 — 3겹 + 특징 3개
| 겹 | 재질 | 출처 |
|---|---|---|
| 바깥 **범퍼 커버(fascia)** | 대부분 **PP/TPO**(폴리프로필렌/열가소성 올레핀) 플라스틱 | [4][5] |
| 가운데 **충격 흡수재(energy absorber)** | Camry: front bumper energy absorber + No.2 absorber(폼), 옆 고정쇠(side retainer) 7.0 N·m | [6] |
| 안쪽 **보강 빔(reinforcement)** | Camry: 쇠 빔, **볼트 8개 43 N·m**로 프레임 끝에 | [6] |
- 커버에 붙는 것: 그릴, 안개등, **주차 센서**, **충돌 방지 레이더(Pre-collision)**·카메라 커넥터 [6].
- 캐주얼 특징 3개: ① 차 앞을 감싼 **둥근 플라스틱 얼굴** ② 아래 **큰 입(그릴)** + 양옆 작은 등 ③ 벗기면 뒤에 **두꺼운 스펀지 막대 + 쇠 빔**.

### ③ 차 안 위치
- 차 맨 앞, 양옆은 앞 펜더 앞끝·바퀴집 안쪽 라이너까지 감싸요 [6].

### ④ 붙어 있는 방식 — Camry XV70 실제 떼는 순서 [6]
1. 보닛 열고 **에어 덕트 실(cool air intake duct seal) 클립 5개** 빼기, 가이드 풀기.
2. 범퍼 둘레에 **보호 테이프** 붙이기.
3. 좌우 각각: 펜더 쪽 **걸쇠(claw) 2개**를 **테이프 감은 일자 드라이버**로 풀기.
4. 좌우 각각 **클립 1개**.
5. 아래쪽 **나사 8개**.
6. 좌우 각각 **걸쇠 3개** (손 넣어 당기기).
7. (있으면) 충돌 방지 레이더 커넥터 1, 주차 보조 커넥터 1 뽑기.
8. 위쪽 **클립 2개 + 볼트 4개**(장착 7.5 N·m, wr-carbook 확인) [6].
9. 마지막 **걸쇠 2개 + 가이드 2개** 풀고 앞으로 당겨 빼기.
- 합계: 볼트 4 + 나사 8 + 클립 4(+덕트 실 클립 5) + 걸쇠 12 + 가이드 2 + 커넥터 0~2.
- 다시 단 뒤: 앞 카메라 뷰 조정·파노라마 모니터 보정이 필요할 수 있고, 범퍼가 찌그러졌거나 붙는 자리를 고쳤으면 **밀리미터파 레이더 조정 필수** [6].
- 나사 머리(T25/T30 토크스, 10 mm 등) 종류·크기: 매뉴얼 텍스트에 없어 (확인 못 함).
- **헤드라이트**: **볼트 1 + 나사 3**씩(removal-4262), 범퍼 커버 위·뒤에 있어 **범퍼를 먼저 떼야** 해요(wr-carbook가 매뉴얼 그림에서 확인, diagrams/03) [6].

### ⑤ 흔한 고장
| 증상 | 원인 | 진단 | 수리법 · 시간 |
|---|---|---|---|
| "범퍼가 떨어지려 해요" — 한쪽 처짐 | 걸쇠·클립·나사가 부러지거나 빠짐 — 범퍼 고정 대부분이 걸쇠·클립이라는 건 확인 [6], "가장 흔한 원인" 통계는 (확인 못 함) | 눈: 처진 쪽 걸쇠 확인 | 새 클립·나사 / 부러진 탭은 **질소 플라스틱 용접**으로 붙이기 [5] |
| 커버 금·찢어짐 | 충돌 | 뒤쪽 ISO 표시로 플라스틱 종류 확인 [5] | 플라스틱 용접: 비눗물→전용 클리너 세척 → 알루미늄 테이프로 맞춤 → 뒤를 P80으로 갈기 → 리본 용접 → 앞면 V홈 용접 → 갈고 퍼티 [5]. 레이더·주차 센서 앞은 기능을 방해하면 고치지 말기 [5] |
| 긁힘·스크래치 | 주차 접촉 | 손톱 테스트(아래 도색 편) | 범퍼 칠 $300~700 / 금 수리+칠 $450~900 / 새 커버 칠+장착 $500~1,500+ / 센서·ADAS 있으면 $1,000~2,500+ [17]. 보통 1~3일 [17] |
| 겉은 멀쩡한데 비쌈 | **숨은 손상**: 흡수재·보강 빔·브래킷·클립·배선·센서 [18] | 커버 벗겨 보기 | 보정 $250+ 추가 [18] |

### ⑥ 게임 손맛 아이디어
- 범퍼 = "클립 퍼즐": 볼트 4개(렌치) + 나사 8개(드라이버) + **걸쇠는 손으로 '톡톡' 풀기**. 순서 틀리면 걸쇠가 "뚝" 부러져 새 클립 사야 함(돈 조금).
- 벗기면 뒤에 **폼 막대 + 쇠 빔**이 보이는 '속 보이기' 순간 — 아이들이 좋아할 구조 학습.

## 부품: 뒤 범퍼 (Rear Bumper)
### ④ 붙어 있는 방식 — Camry XV70 [19]
1. 뒤 콤비네이션 램프 덮개 떼기.
2. 좌우 각각 **나사 2개 + 클립 1개**.
3. 아래 **클립 9개(싱글 배기) / 8개(듀얼 배기)**.
4. 좌우 각각 **걸쇠 6개**.
5. 가운데 **걸쇠 4개 + 가이드 2개**.
6. **주차 센서 커넥터** 뽑기.
- 뒤에도 **보강 빔 + 충격 흡수재** [19].
- 합계: 나사 4 + 클립 11(또는 10) + 걸쇠 16 + 가이드 2 + 커넥터 1. 볼트는 없음.
### ⑤ 흔한 고장
- 뒤 범퍼 가벼운 스크래치 $150~500, 플라스틱 수리+칠 $450~1,400, 칠한 새 커버 $800~2,500, 센서·카메라 교체 +$1,000~2,500 [18].

## 부품: 트렁크·펜더·문·유리 (짧게)
- **트렁크 리드**: 경첩 볼트 수 (확인 못 함).
- **앞 펜더**: 볼트로 붙어 교체 쉬움 [3]. 볼트 개수 (확인 못 함).
- **문**(다른 차 예 — Tesla Model 3 정비 매뉴얼): 문 쪽 경첩 볼트 **4개(27 N·m)**, **체크 스트랩(문 멈춤 끈) 볼트 1개(24 N·m)**, 배선 묶음 클립 9개, 배선은 문 구멍의 **고무 마개(그로밋)** 를 지나감. 떼기 전 펜더에 테이프로 자리 표시, 아래 볼트 빼고 위 볼트는 반쯤 풀어 두 사람이 들어 올림 [20]. 체크 스트랩 풀면 문이 한계 넘어 활짝 열리니 주의 [20]. Camry 문 수치는 (확인 못 함).
- **앞유리**: 두 장 유리 사이에 **PVB 필름**을 낀 접합 유리, **우레탄 접착제로 붙임**(검은 세라믹 띠 'frit'가 햇빛을 막아 줌) [21]. 접착이 굳는 **안전 출차 시간**이 지나야 운전 가능(FMVSS 212/208 기준), 교체 자체는 보통 1시간 안 [21]. 떼기는 칼(cold knife)이나 와이어로 접착제를 자름(검색 요약 — 원문 못 엶).

## 녹 (Rust)
| 단계 | 모습 | 고치는 법 | 출처 |
|---|---|---|---|
| **표면 녹 (Surface)** | 작은 흠·문콕에서 시작, 칠 밑 쇠가 살짝 붉음 | 고운 사포로 **쇠가 보일 때까지** 갈기 → 프라이머 → 칠 1~2번 → 광 | [25] |
| **비늘 녹 (Scale)** | 작은 구멍(pit), **칠이 부풀어 오름(rust bubble)** | 와이어 브러시로 긁기 → 위와 같이 | [25] |
| **뚫린 녹 (Penetrating / Rot)** | 구멍이 남, 부서짐, 구조 약해짐 | 보통 부품 통째 교체, 또는 **잘라 내고 새 판 용접** → 프라이머·칠·광 | [25] |
- 녹 전환제(rust converter): 갈고 닦은 뒤 바르고 다 마르면 금속 프라이머 → 얇게 여러 번 칠 [26]. 뚫린 녹에는 전환제가 소용없다는 말은 검색 요약뿐 (확인 못 함).
- 잘 생기는 곳: **바퀴집(휠 아치)**, 펜더, 문 끝, 하체, 배기, 보닛 안쪽·트렁크 같은 숨은 곳 [26]. 원인: 염화칼슘(물을 전기 잘 통하게 해 녹 가속), 돌 튐 칩, 물 빠짐 구멍 막힘 [26].
- 칠 밑 **물집처럼 부푼 곳** = 밑에서 녹이 칠을 밀어 올리는 중 [26]. 문턱(rocker panel)은 이 출처에 따로 안 나옴 (확인 못 함).

## 도색 (Paint)
### 공장(OEM) 칠 층 — 위키 [8]
1. 전처리: 고압 물 세척 + **인산염 피막**(녹 방지).
2. **전착 도장(E-coat, ELPO)**: 차체를 통째로 담그고 전기로 칠을 붙임(칠 99.9% 사용, 소금물 시험 강함).
3. **프라이머**: 작은 흠 메움, 돌 튐·자외선 막고 다음 층이 잘 붙게.
4. **베이스 코트**: 색·메탈릭·펄.
5. **클리어 코트**: 반짝이는 투명 층, 긁힘·**자외선**을 버팀.
- 전체 두께 약 **100 μm(0.1 mm)** [8]. 클리어 층은 약 30~60 μm [27]. 단색에도 클리어를 올리기 시작한 건 1990년대 초 [8]. 공장 금속 차체 클리어는 보통 1K(최대 약 140 °C 굽기), 범퍼 같은 플라스틱은 2K(약 90 °C)로 따로 칠함 [8].

### ⑥ 게임 손맛 아이디어 (도색)
- **손톱 테스트 클릭**: 긁힘에 손가락 아이콘 문지르기 → "안 걸림 / 살짝 / 콱" 세 가지 소리. 안 걸리면 **광내기만** 하면 끝 → 칠하면 오진(돈 낭비).
- 도색 = **층 쌓기 미니게임**: 회색(프라이머) → 색(베이스) → 반짝(클리어). 클리어를 빼먹으면 손님 별점 깎이고 "광이 없네요".
- 샌딩 사포 고르기: 숫자가 커질수록 고운 사포(80 → 180 → 400 → 1500 → 3000) — 순서대로 해야 자국이 사라짐.
- 페인트 코드 찾기: 운전석 문 열고 스티커의 'C/TR' 찾기 → 정답 색 통 고르기.

## car_spec · fault_catalog 와 다른 점
1. **범퍼 고정 개수가 크게 달라요.** car_spec 앞 범퍼 "4 (위 2 + 아래 2)", 실제 Camry = **위 볼트 4 + 클립 2, 아래 나사 8, 옆 클립 2, 걸쇠 12, 가이드 2, 커넥터 0~2** [6]. 뒤 범퍼 "4 (바퀴집 옆 2 + 아래 2)", 실제 = **나사 4 + 클립 11(10) + 걸쇠 16 + 가이드 2 + 커넥터 1, 볼트 0** [19]. car_spec 표의 "실제 8~10"도 실제보다 적어요. 제안: 게임 볼트는 그대로 4개로 줄이되(손맛), **"걸쇠 톡톡 풀기"** 한 단계 + **센서 커넥터 1** 을 넣으면 진짜 같음. 앞 범퍼 위쪽 고정은 실제로도 보닛을 열어야 손이 닿아 `Hood:Open` 조건은 맞아요 [6].
2. **보닛 경첩 볼트 4개(2×2) = 실제와 같아요** (Camry 13 N·m) [13]. 받침대(prop rod)도 맞음. 빠진 것: **워셔 호스·노즐 연결**(떼기 전 풀어야 함), **단열 패드**, 걸쇠의 **2단 안전 걸쇠**(FMVSS 113) [13][15].
3. **헤드라이트는 범퍼 먼저** — car_spec 4-2 "`Bumper_F` 떼기"는 실제(Camry)와 같아요. 고정은 실제 **볼트 1 + 나사 3**(https://www.tocamry.com/removal-4262.html) — 게임 '3'은 줄인 값.
4. **도색 순서에 클리어가 빠져 있어요.** fault_catalog `BODY_RUST` "샌딩기 → 프라이머 → 도색", `BODY_SCRATCH` "샌딩 → 도색" → 실제는 **세척·탈지 → 샌딩 → 마스킹 → 프라이머(+서페이서 갈기) → (실러) → 베이스 → 클리어 → 건조 → 물사포·광** [7][8][9][10][28]. 최소 "프라이머 → 색 → 클리어 → 광" 4단은 넣기를 제안.
5. `BODY_SCRATCH`는 **깊이에 따라 답이 달라야** 해요: 손톱이 안 걸리면 광내기만, 걸리면 칠 [27]. 지금은 모두 "샌딩 → 도색"이라 얕은 긁힘에선 과잉 수리.
6. `BODY_DENT` "작은 것 = 판금 해머 미니게임": 실제로는 **칠이 멀쩡한 작은 찌그러짐 = PDR**(칠 안 함), 칠이 깨진 것만 해머·퍼티·도색 [22][23]. PDR 미니게임(막대로 뒤에서 밀기, 빛 반사로 확인)을 따로 두면 정확해요.
7. `BUMPER_HANGING` "볼트 새로 끼우기": 실제 범퍼는 볼트보다 **플라스틱 걸쇠·클립·나사**로 더 많이 붙어 있어요 [6] → 고치는 법 = 새 클립 또는 **플라스틱 용접**으로 탭 붙이기, 너무 심하면 커버 교체.
8. `HOOD_LATCH` 연출 "걸쇠 갈기 클릭": 걸쇠는 **라디에이터 서포트 위(차체 쪽)** 에 있고 케이블로 연결 [13] — 원인·수리법의 공식 출처는 못 찾음(확인 못 함). 청소·윤활·위치 조정·케이블 교체를 후보로.
9. 앞유리 "0 — 접착제 자르기"는 맞아요 [21]. 추가하면 좋은 진짜 규칙: 다 붙인 뒤 **안전 출차 시간** 기다리기 [21].
10. 문 "경첩 2×2 + 커넥터 1"은 실제와 비슷해요 [20]. 빠진 것: **체크 스트랩 볼트 1**(풀면 문이 활짝 열림) [20].

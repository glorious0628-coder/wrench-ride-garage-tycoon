# 겉이 상상인 차 — '속이 진짜인가' 점검표 (wr-carbook, 2026-10-22)

> 사용자 10-22: "구조가 현실적이지 않은 자동차들은 절대 금지" · "모양은 현실 세계에 없더라도 자동차 구조나 부품은 현실적이어야 돼."
> 방법: 그림을 직접 보고(호박차 6면·밈 차 시트·견인차·시대 차) → 아래 **§0 공통 점검표**에 하나씩 대 봄 → 차마다 "빠진 것 / 틀린 것 → 이렇게 고치면 진짜" 한 줄씩. 그림체는 캐주얼 그대로(구성만 진짜).
> 근거: 등 규정 = FMVSS 108 Table I-a(49 CFR 571.108, 직접 읽음, `teardown/turn_signals.md` §1) · 구조·분해 = `teardown/sedan_teardown.md`. 출처 번호는 맨 아래.

## 0. 공통 점검표 — 미국 도로를 달리는 승용·픽업·SUV에 있어야 하는 것
### 0-1. 등 (FMVSS 108 Table I-a [1])
| 자리 | 있어야 함 | 색 |
|---|---|---|
| 앞 | 헤드램프 2(하향·상향) | 흰색 |
| 앞 | **깜박이 2** — 좌우 대칭, 같은 높이, 되도록 바깥쪽, 땅에서 15~83 in | **주황** |
| 앞 | **옆표시등 2 + 옆 반사판 2** — 양옆 되도록 앞쪽, 15 in 이상 | 주황 |
| 뒤 | 미등 2 + **브레이크등 2** (브레이크 밟으면 더 밝게) | 빨강 |
| 뒤 | **뒤 깜박이 2** | **빨강 또는 주황** |
| 뒤 | **옆표시등 2 + 옆 반사판 2** — 양옆 되도록 뒤쪽 | 빨강 |
| 뒤 | **후진등 1개 이상** | 흰색 |
| 뒤 | **번호판 + 번호판등** (번호판등은 흰빛, 이 표 밖 규칙 — 확인 못 함) | 흰색 |
| 뒤 | **높이 단 브레이크등(CHMSL, 3번째 브레이크등)** — 폭 80 in(2032 mm) 미만 차에 필수(승용 1985년식~, 경트럭 1993년식~) [2](검색 요약) | 빨강 |
| 앞·뒤 | **비상등**(깜박이 동시 점멸 장치) [1] | — |
- 한 등이 여러 일을 해도 됨(빨간 한 칸이 미등 + 브레이크 + 깜박이 = 미국 허용 [3]) — 하지만 **후진등(흰색)·옆표시등(앞 주황/뒤 빨강)·반사판·번호판등은 따로 있어야** 함.
### 0-2. 차체·안전 부품
| 부품 | 규칙·이유 |
|---|---|
| **와이퍼 + 워셔** | FMVSS 104가 승용차·트럭·SUV에 와이퍼 면적·속도 규정 [4](검색 요약). 앞유리 아래에 팔 2 + 날 2, 워셔 노즐(보닛 위·카울) |
| **거울** | 실내 거울 + 운전석 바깥 거울(FMVSS 111 — 규정 문장은 검색에서 못 읽음, 일반 지식 → 확인 못 함 [4]), 보통 양쪽 |
| 경적 | 앞 범퍼 뒤 2개 `sedan_teardown` B10 |
| 안전벨트·에어백 | 실내 |
| **범퍼 + 충격 흡수재 + 철 빔** | 앞·뒤 커버 뒤 3겹(`sedan_teardown` A4~A6, A21~A22) |
| **바퀴: 타이어 + 휠 + 허브 + 휠 너트 5개**(캠리 기준) | 휠 가운데에 **너트 5 + 허브캡**이 보여야 — 그림의 바퀴는 너트 자국이 안 보이면 '장식 바퀴' |
| 보닛 + 경첩 + 받침대 + 잠금장치 | 보닛 선(틈)이 그림에 있어야 엔진룸으로 열림 |
| 문 손잡이·문 틈·창 | 문마다 손잡이·틈 |
### 0-3. 밑면 (앞바퀴굴림 가로 엔진 승용 기준, `sedan_teardown` §1·E·F)
- **앞**: 엔진 + 변속기(가로) + 앞 서브프레임 + 앞 스트럿·아래 팔·구동축 2(엔진 쪽에서 앞바퀴로 좌우)
- **가운데**: **배기관이 엔진 뒤쪽에서 → 차 밑을 따라 뒤로** → 머플러 → 꼬리관이 **뒤 범퍼 밑 끝**으로 나감. 촉매(앞관) + 산소센서
- **뒤**: **연료탱크**(뒷좌석 밑, 쇠 밴드 2), 뒤 서스(스프링·쇼크·팔), 뒤 차축/서브프레임
- 앞바퀴굴림이라 **차 가운데 길이로 길게 변속기·구동축이 지나가지 않음**(그건 뒷바퀴굴림 세로 엔진 모양).
### 0-4. 올바른 앞·뒤 판별
밑에서 올려다본 그림이면 **꼬리관이 있는 쪽 = 차 뒤**, 엔진·변속기가 있는 쪽 = 앞. (그림에서 앞·뒤를 헷갈리면 이 둘로 확인.)

## 1. 호박차 — `art/concepts/halloween/pumpkin_car_6view.png`
> 계획 = SUV 엔진룸을 호박 껍데기 속에 씀(앞바퀴굴림 가로 4기통 구성). **껍데기만 호박**, 속·부품은 진짜.

그림에서 본 것: 앞 = 노란 둥근 헤드램프 2 + 이빨 입 모양 그릴 + 금색 범퍼, 앞 범퍼 끝 금색 바(모서리), 앞 모서리에 **금색 거울 비슷한 작은 막대** 2. 뒤 = **빨간 둥근 등 2개**(좌우 한 개씩) + 금색 범퍼 + 번호판 + 오른쪽 꼬리관. 옆 = 문 1개·손잡이·창, 금빛 살바퀴(스포크). 위 = 큰 줄기(꼭지)가 지붕 위 + 앞 유리 아주 큼. 밑면 = 엔진·변속기 구조물이 **세로로** 길게(변속기·구동축 하우징) + 배기관이 가운데 길이로 + 머플러 + 양옆 판.

## 2. 밈 차 5 — `art/concepts/meme_cars/_check/meme_cars_sheet.png`
> 대부분 **진짜 차(픽업·미니밴·세단·SUV) + 얹은 소품**이라 짧게. 같은 앞 얼굴(가는 흰 줄 헤드램프)을 씀 → **앞 깜박이 주황이 안 보이는 문제가 5대 전부 같음**(`turn_signals.md`).

| 차 | 소품 | 그림에서 본 구조 문제 | 이렇게 고치면 진짜 |
|---|---|---|---|
| **bathtub_car** (픽업 + 욕조) | 짐칸의 욕조 + 오리 | ① 앞 깜박이 주황 안 보임(흰 줄 헤드램프) ② 짐칸 욕조가 **노란 끈 2**로 고정(OK) ③ 뒷문 내림 + **뒤 등** 확인 어려움 ④ 픽업의 **거울 깜박이**(선택) 없음 | 앞: 헤드램프 **바깥 끝 주황 칸** (픽업 흔한 자리 `turn_signals` §3). 테일게이트 양옆 세로 **뒤등(빨강, 후진등 흰 칸)** 보이게. 욕조는 **끈 + 짐칸 고리** 그대로 |
| **couch_car** (미니밴 + 소파) | 슬라이딩 문 열린 안의 소파 | ① 앞 깜박이 주황 안 보임 ② **소파가 시트 자리를 대신** → 시트 레일·안전벨트 없음 — 현실: 소파는 뒷좌석을 접고 실은 짐 ③ 슬라이딩 문 레일 OK ④ 거울 OK | 앞: 주황 칸. 소파는 **짐 끈 2 + 시트 접힌 모양**(바닥 평평하게) 보이게, 앞 좌석은 그대로 |
| **squeaky_toy_car** (세단 + 장난감) | 지붕 오리 + 차 안 장난감 | ① 앞 깜박이 주황 ② **차 안이 장난감으로 꽉 참 — 운전석·시야·에어백 막음**(현실이면 불법/위험) ③ 지붕 오리 = 장식 OK | 장난감은 **뒷좌석·트렁크 쪽만** 채우고 앞유리·운전석 창은 비움. 앞: 주황 칸 |

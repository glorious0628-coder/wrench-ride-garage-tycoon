## 1. 모델 T 시동 (레시피 #2 Openroad Tourer 근거)

### 1-1. 순서 (1919 설명서 = 기준, 영상 = 실제 손 모습)
| 단계 | 하는 일 | 근거 |
|---|---|---|
| 0 | 미리 확인: 라디에이터 물 가득, 휘발유(10갤런 통, 좌석 밑), **엔진오일 = 플라이휠 덮개의 작은 꼭지(petcock) 2개** — 위 꼭지에서 흘러나올 때까지 넣고, 두 꼭지 사이 유지 | 설명서 Answer 1~3 |
| 1 | **연료 꼭지 열기** — 좌석 밑 탱크에서 **중력으로** 내려옴(펌프 없음) | B 0:02 "gas valve … gravity feed, tank under the seat" &t=2s |
| 2 | **손 레버(바닥 왼쪽, 위로 솟은 막대)를 끝까지 뒤로** = 중립 + 바퀴 브레이크 | 설명서 Answer 6 · A 0:30 화면 &t=30s |
| 3 | 핸들 밑 레버 2개: **왼쪽 = 점화(spark) 늦춤 쪽(위)**, 오른쪽 = 스로틀 조금(설명서: 점화 3~4칸, 스로틀 5~6칸) | 설명서 Answer 5 · A 0:26 &t=26s |
| 4 | 점화 스위치를 **배터리(BAT)** 쪽 — **코일 상자에서 '지이잉' 버징** 소리 | B 0:15 "this side you have the coil. Hear that buzzing?" &t=15s |
| 5 | (차가울 때) **라디에이터 왼쪽 아래 작은 철사 = 초크(프라이밍)** 를 당긴 채 크랭크 2~3번 ¼바퀴 → 놓기 | 설명서 Answer 7 · A 0:42(왼손 초크·오른손 크랭크) &t=42s · D "pull the choke … few times" |
| 6 | **크랭크: 차 쪽으로 밀어 래칫이 물리면 → 위로 휙 당겨 올림.** 아래로 누르며 돌리지 않음. 엄지는 손가락과 같은 쪽(감싸 쥐지 않기) | 설명서 Answer 7 · history §3 [15][100][101] · A 1:02~1:15 &t=62s |
| 7 | 시동 걸리면 **점화를 앞당기고(레버 내림)**, 스위치를 **MAG(마그네토)** 로 | B 0:19 "once the car is running, you switch over to magneto" · A 1:40 &t=100s · 설명서 "magneto at all times" |
| 8 | 초크 다시 밀어 넣기 | D 1:00 "push the choke in" |
- **실패 모습**: Jay Leno 영상도 첫 크랭크는 "almost"로 실패(B 0:42) → 실제로 한 번에 안 걸리는 게 보통.
- **위험**: 점화를 너무 앞당긴 채 돌리면 **되튕김(back kick)** — 손목을 다침, 스타터 축이 휠 수도(설명서 Answer 5·7). D 1:15 "timing … too low or she might blow".
- **나중 모델(전기 스타터)**: 열쇠 켜고 **바닥 발 버튼**(C 0:06 "Hit the starter button") — 레버는 크랭크 때와 같게(설명서).
- **운전 페달 3개**: 왼쪽 = 끝까지 밟으면 저속, 반 = 중립, 떼면 고속 / 가운데 = 후진 / 오른쪽 = 브레이크. 손 레버는 달릴 때 앞으로(설명서 Answer 9~10).
- 화면에서 본 것: 놋쇠 라디에이터, 앞 아래 **크랭크 손잡이**, 운전석 바닥 나무판, 핸들 밑 레버 2개, 대시 위 **검은 코일 상자 + 열쇠**(A 0:54 &t=54s).

### 1-2. 우리 게임에 쓰는 법 (Openroad Tourer — 지금은 레시피만, 3대 먼저 결정과 같음)
- **'시동 의식' 미니 동작 5칸**: 연료 꼭지 → 손 레버 뒤로 → 점화 레버 위 → 초크 당기고 ¼바퀴 2번 → 크랭크 **위로 당기기**(탭 X, 아래→위 끌기). 성공하면 스위치 MAG, 점화 레버 내림.
- **실수 = 웃긴 실패, 벌 X**: 점화 레버를 내린 채 크랭크 → 손잡이 '퉁' 되튕김 + 캐릭터 손 흔들기(다치는 장면 X), 다시 하면 됨. 처음엔 1~2번 "Almost!" 실패가 자연스러움(B).
- 고장 후보: **코일 상자 버징 없음**(점화 X), 오일 꼭지 아래에서도 안 나옴(오일 부족), 탱크 비었는데 꼭지만 열림(중력식이라 연료 확인 = 좌석 들기).

## 2. 50년대 차 — Starlane Cruiser 수리 2가지의 실제 손순서

### 2-1. 기화기 공회전 맞추기 (E, 자막 전부)
- **왜 늘 일자(-) 나사?** 홈이 보여서 **몇 바퀴 돌렸는지 눈으로 셀 수 있게**(E 1:30 &t=90s, 5:43 &t=343s). → 게임 화면에 나사 홈 방향이 보이면 '세는 재미'.
- 기화기 회로 3개: **공회전(idle) = 밖에서 맞출 수 있는 유일한 곳**, 중간(transfer slot, 스로틀 날개 살짝 열 때 보이는 ¼인치 틈), 메인(부스터·제트) (E 4:05 &t=245s). 공회전부터 맞아야 나머지를 볼 수 있음.
- **처음 세팅**: ① 스로틀 멈춤 나사를 풀어 날개를 완전히 닫음 → **1½바퀴 조임** ② 혼합비 나사 2개를 **살살 끝까지(힘주면 바늘 자리 망가짐)** → **1½바퀴 풀기** ③ 시동 (E 5:24~7:36 &t=324s)
- 스로틀 멈춤 나사로 **약 800 rpm**(E 7:58 &t=478s).
- **맞추기**: 혼합비 나사를 **반 바퀴씩 번갈아 조이기** → rpm이 떨어지면 마지막 자리로 → 이번엔 **반 바퀴씩 번갈아 풀기** → 더 안 오르면 멈춤 → **¼~½바퀴 더 풀기**(낮·밤 공기 차이 대비 '평균') (E 10:26~13:37 &t=626s)
- 도구: 옛날 방식 = **진공계를 꽂고 가장 높은 진공**, 또는 회전계, 또는 **귀로**(E 9:01 &t=541s). history §3의 진공계 순서([106])와 같은 말.
- **고장 신호**: 스로틀 나사를 2~3바퀴 넘게 돌려야 겨우 공회전 = **공회전 통로 막힘** → 기화기 열어 청소. 한쪽 나사만 반응 없음(4바퀴 풀어야 반응) = 그쪽 통로 막힘, **오래 서 있던 차에 아주 흔함**(E 8:19 &t=499s, 14:19 &t=859s).

### 2-2. 드럼 브레이크 별바퀴 조정 (F, 자막 전부)
- **증상 3가지**: ① 페달이 깊이 들어감 ② (앞 드럼 차) 밟으면 **한쪽으로 쏠림** = 좌우 조정이 다름 ③ **찍찍 소리** = 슈가 백킹 플레이트에 긁힘(F 0:41 &t=41s, 3:29 &t=209s).
- 자동 조정기는 **50년대 말부터** 거의 다 있음 — 후진하며 브레이크 밟을 때 한 칸씩 돌림. 그런데 **실제론 잘 안 됨** → 손으로 조정(F 1:23 &t=83s, 2:46 &t=166s). 회사마다 모양이 다름(케이블식·삼각 레버식·쇠막대식).
- **손순서**: 차 들기 → 백킹 플레이트 뒤 **고무 마개 빼기** → **브레이크 스푼(또는 일자 드라이버)** 을 넣어 별바퀴를 '딸깍딸깍' 돌림 → **바퀴를 손으로 돌리며** '살짝 끌리는' 정도에서 멈춤 → 마개 다시 → **반대쪽도 똑같은 끌림**(F 6:23~10:14 &t=383s). 어떤 차는 바퀴·드럼을 떼고 앞에서 조정.
- **너무 조였을 때 풀기**: 작은 드라이버로 조정 레버를 밀어 둔 채 다른 드라이버로 반대로(F 10:57 &t=657s).
- **오래 서 있던 차**: 드럼 녹으로 브레이크가 붙어 안 굴러감 → 같은 방법으로 풀면 굴러감(F 12:02 &t=722s) → 복원 일의 첫 단계로 딱.

### 2-3. 크롬 살리기 (I, 자막 전부)
- **판정**: 크게 패인 곳(pit) 있으면 → **다시 도금(비쌈)** 또는 중고로 교체 / 얕은 녹·얼룩이면 → **아주 고운 철수세미(0000) + 윤활액으로 문지르기**(I 0:31~2:30 &t=31s).
- 뒤쪽(도금 안 됨)은 녹이 잘 슬어 → 철솔 → 녹 방지 페인트(I 3:36 &t=216s).
- 작은 찌그러짐: **망치에 천을 대고 살살** 톡톡(I 5:13 &t=313s). 작은 흠: 크롬 펜. 끝: 왁스로 보호.

### 2-4. 우리 게임에 쓰는 법 (Starlane Cruiser — era_cars §0 '그 차만의 수리' 그대로 근거 보강)
1. **공회전 맞추기 미니게임** = 화면에 **일자 홈 나사 2개 + 회전 바늘(또는 진공계 바늘)**. 반 바퀴씩 번갈아 조이다 바늘이 떨어지면 되돌리고, 풀다가 안 오르면 멈춤 → **"+¼ more"** 하면 별 3개. 소리(wr-sound)는 공회전 '부르릉' 높낮이로 보조 — 귀로도 할 수 있다는 게 영상 내용과 같음.
   - 실패/변형: 한쪽 나사가 안 먹음 → "Idle passage clogged" → 기화기 열어 통로 스프레이 청소 단계 추가.
2. **드럼 별바퀴** = 고무 마개 빼기 → 스푼 넣고 위로 쓸기(딸깍) → 바퀴 돌려 보기(끌림 막대) → **좌우 막대 맞추기**. 손님 말 = "It pulls to the left when I brake" / "Pedal goes way down".
3. **크롬 광내기** = 패인 곳 표시가 있으면 '교체' 버튼, 없으면 문지르기(끌기 반복) → 반짝. 크롬 범퍼는 Starlane의 상징이라 '보는 맛' 일.

## 3. 복원 — 오래 서 있던 차 살리기 (폐차장 복원·Barn Find 근거)

### 3-1. 실제 순서 (G = 요령, H = 실제 50년 서 있던 58년 차)
| 단계 | 하는 일 | 근거 |
|---|---|---|
| 1 | **엔진룸·그릴의 동물 둥지·낙엽 치우기**(불나고 과열됨), 열쇠가 뻑뻑하면 마른 윤활 스프레이 | G 0:31·2:06 &t=126s · H 2:05(낙엽) |
| 2 | **엔진오일 확인·교환**(서 있던 오일은 낡음) | G 3:09 &t=189s |
| 3 | **점화 플러그 빼기**(점화 순서 표시 해 두기) → 실린더마다 **윤활유 뿌리기**(H = 침투유, G = 포깅 오일) | G 4:42 &t=282s · H 3:07·6:14 &t=374s |
| 4 | **엔진이 손으로/스타터로 돌아가는지**(안 돌면 끝) — H는 배터리 + **원격 시동 버튼**으로 스타터 직접(쥐가 배선을 갉았을 수 있어서) | H 7:14 &t=434s → "We got compression" &t=495s |
| 5 | 점화 확인: **테스트 램프로 코일 전원** → 코일 저항(옴) → **포인트 청소**(몇 달만 서 있어도 부식) → **불꽃 시험기** → 새 플러그 | H 10:18~16:25 &t=618s |
| 6 | **오래된 휘발유 빼고 새 휘발유**(G는 사이펀으로 7~8갤런) / H는 우선 **병으로 기화기에 직접 부어** 시동 | G 6:45 &t=405s · H 12:20 &t=740s |
| 7 | 냉각수(비중계로 어는점), 브레이크액 확인 | G 7:47 &t=467s |
| 8 | 시동: '푸드득·펑(역화)' 여러 번 → 연료를 더 주니 **"She's running"** (H 23:40 &t=1420s) — 9:30에 와서 11:30에 성공 | H &t=1106s~1420s |
| 9 | 기화기 열어 **뜨개·바늘·통로 스프레이 청소** → 전기 연료 펌프로 깡통에서 공급 → **공회전 성공**, 기름 샘 발견, 충전(발전기/알터네이터) 안 됨 발견 | H 24:41~32:00 &t=1481s |
- G는 끝에 시동 스프레이로만 돌고 → "연료 펌프 고장" 진단(다음 일로 넘어감).

### 3-2. 우리 게임에 쓰는 법 (Lv8 폐차장 복원 의뢰 · Barn Find)
- **복원 = '살리기 체크리스트' 7칸**(위 1~8 그대로, 아이콘): 둥지 치우기 → 오일 → 플러그 빼고 오일 뿌리기 → **돌려 보기(첫 고비)** → 불꽃 → 새 휘발유 → 시동. 칸마다 짧은 동작, 끝의 **첫 시동 장면 = 보상 순간**(연기 퍽 + 손님/친구 환호).
- **'한 번에 안 됨'이 진짜 재미**: H·B 모두 첫 시도 실패 → 2~3번 '푸드득' 뒤 성공. 실패 횟수는 고정 연출(운 X)로.
- **살린 뒤 새 일거리가 '발견'됨**: 기름 샘·충전 안 됨·드럼 붙음·공회전 통로 막힘 → 다음 방문/다음 단계 일로(복원이 여러 번 오게 만드는 실제 근거).
- 드럼 브레이크 붙음(2-2)·크롬 광내기(2-3)·공회전(2-1)이 복원 뒤 마무리 일로 그대로 이어짐.

## 4. 1880년대 — 핫튜브 점화 (Pioneer Carriage 근거 보강)
- **핫튜브** = 한쪽 막힌 짧은 쇠관(설명 영상 기준 약 6인치)을 실린더 머리에 꽂고 **버너 불로 빨갛게 달굼** → 압축된 연료·공기가 관 속으로 밀려 들어가 **뜨거운 관에 닿아 저절로 불붙음**(J 0:30~3:40 &t=189s). 전선·플러그·포인트 없음.
- 관 둘레엔 **굴뚝(chimney)** — 바람 막고 온도 고르게(J 1:34 &t=94s). 그래서 밖에선 관이 잘 안 보이고 **작은 불꽃**만 보임(K 1:40 화면: 버너 불꽃 &t=100s).
- **타이밍 = 불꽃 세기**: 관을 **어두운 빨강 ↔ 주황**으로 바꾸면 불붙는 때가 바뀜(J 4:14 &t=254s). history §3의 Daimler 자료(버너 위치로 타이밍, 너무 달구면 하얗게 → 터짐)와 같은 방향.
- **고장**: 오래 쓰면 **관 안에 탄소(카본)가 쌓여** 열이 안 전해짐 → **관 빼서 청소 후 다시 끼우기**(J 2:39 &t=159s).
- 버너 = 가스 + 작은 구멍(벤투리)으로 공기 빨아들여 섞어 태움, 니들 밸브로 양 조절(J 5:15 &t=315s). (J는 고정식 엔진 예 — 원리 근거로만.)

### 4-1. 우리 게임에 쓰는 법 (era_cars §0 Pioneer Carriage '핫튜브 불꽃 맞추기')
- **불꽃 맞추기 = 관 색 바늘**: 니들 밸브 돌리기 → 관 색이 **검정 → 어두운 빨강 → 주황(정답 구간) → 노랑·하양(위험, 깜빡 경고)**. 정답 구간에서 플라이휠 돌리기 → 시동.
- **새 고장 후보 "Sooty tube"**: 관 속 카본 → 아무리 달궈도 안 붙음 → 굴뚝 열고 관 빼기 → 솔로 청소 → 끼우기. 사실 근거 있음(J), 동작이 짧고 눈에 보임.
- 하양까지 달구면 관이 상함(history [3]) → '터짐' 대신 **관에 금 간 그림 + 새 관 사기**(벌은 부품값 조금만).

## 5. wr-design에 보낼 요약 (board 한 줄용)
- Starlane Cruiser: 공회전 = **일자 홈 나사 2개 반 바퀴씩 번갈아(조임→되돌림→풀기→+¼)** · 800 rpm · 막힘 신호(한쪽 무반응) / 드럼 = **고무 마개 → 스푼 딸깍 → 바퀴 돌려 살짝 끌림 → 좌우 같게**, 증상 '깊은 페달·쏠림·찍찍' / 크롬 = 패임 있으면 교체, 없으면 0000 철수세미.

## 방법 메모 — 유튜브 자막 읽기 (10-21 새로 찾음)
- **된 방법**: 영상 페이지에서 `fetch`/`XMLHttpRequest`에 작은 감시를 걸고 → 플레이어의 자막 모듈을 껐다 켬(`player.unloadModule('captions')` → `loadModule` + `setOption('captions','track',{languageCode:'en'})`) → **플레이어가 스스로 받아 온 `/api/timedtext` 응답(json3)** 을 저장 → 문장으로 합쳐 읽음. **코드 = `video/yt_captions.js`**(javascript_tool에 통째로). 플레이어가 정상으로 받은 자기 데이터를 읽는 것이라 봇 확인 우회 X. 15분 영상도 몇 초.

- 광고: 창이 보일 때만 진행됨 → `tabs_select`로 앞에 두고, '건너뛰기'는 `find "건너뛰기"` → 클릭.

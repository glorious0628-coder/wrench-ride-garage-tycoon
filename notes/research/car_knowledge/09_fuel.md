# 연료 (Fuel System — tank, pump, injection, EVAP)

> 기준 차: 가로배치 직렬 4기통 앞바퀴굴림(FF) 중형 세단, 미국 왼쪽 운전석 (예: Toyota Camry XV70/XV80, Honda Accord 10·11세대, Hyundai Sonata DN8, Nissan Altima L34).
> 차 안 좌표·이름은 `docs/specs/car_spec.md` 기준(앞 = −Z, 운전석 = −X).
> 출처는 각 줄 끝 [n] → 맨 아래 '출처' 목록. 출처 없는 문장은 쓰지 않아요. 못 찾은 건 "(확인 못 함)", 검색 결과 요약만 본 건 "(검색 요약)".
> **주의**: tocamry.com 정비 매뉴얼의 연료·EVAP 페이지는 모두 **"2GR-FKS(V6)" 목차 아래**에 있어요. 탱크·펌프 모듈·서비스 구멍·캐니스터는 차체 쪽 부품이라 4기통도 같을 가능성이 크지만 확정은 못 해요 → "(V6 매뉴얼)" 표시. 4기통 A25A의 연료 장치 구조는 toyota-club 해설 [22]로 확인했어요.
> 엔진 쪽 미스파이어·P0171 진단은 [05_engine.md](05_engine.md), 배기·촉매는 [08_exhaust.md](08_exhaust.md).

## 한눈에 (3줄)
- 길: **뒷좌석 아래 탱크 → 탱크 속 전기 펌프 모듈(필터 내장, 300~530 kPa) → 엔진 앞쪽 저압 레일·포트 인젝터 4 + 캠이 돌리는 고압 펌프 → 고압 레일(2.4~20 MPa)·직분사 인젝터 4** (D-4S) [22].
- 펌프는 **뒷좌석 쿠션을 들고 바닥 '서비스 구멍'으로** 꺼내요 — 탱크를 안 내려도 됨(Camry) [2]. 손대기 전 **연료 압력 빼기 + 배터리 (−)** 가 철칙 [3][6].
- 고장 신호: 키 ON 때 **2초 '웅' 소리 없음 = 펌프 안 돎** [26], 연료 냄새 + 경고등 = **EVAP 샘(P0455/P0456, 주유 캡부터)** [12][28], 고압 쪽 **P0087(낮음)/P0088(높음)** [10][11].

## 부품: 연료 탱크 (Fuel Tank)

### ① 하는 일
- 휘발유를 담고, 위로 연료관·숨관(증기관)을, 옆으로 주입구 호스를 이어 줘요 [4].
- Camry XV70 용량: **2WD 16.0 gal (60.6 L)**, AWD 14.4 gal (54.5 L) [15]. 연료 경고등은 남은 양 약 2.4 gal(2WD) / 2.2 gal(AWD)에서 켜짐 [18].
- 연료: 무연 휘발유만, 옥탄 87(RON 91) 이상, **에탄올 15 %까지**(E30·E85 금지) [19].

### ② 실제 모양·크기·재질·색 — 알아보게 할 특징 3개
- 모양: **위가 울퉁불퉁한 넓적한 덩어리**(뒤 바닥 모양에 맞춘 안장형), 윗면에 펌프 모듈용 **둥근 큰 구멍** — 매뉴얼 그림 A449857C01 [4](V6 매뉴얼).
- 재질: Camry 탱크 재질 (확인 못 함). 일반론: 자동차 탱크는 금속 또는 고밀도 폴리에틸렌(HDPE) 플라스틱 [24].
- 크기 (확인 못 함 — 용량 60.6 L만 확인 [15]).
- **알아보게 할 특징 3개 (캐주얼 그림에서도)**
  1. 넓적한 통을 아래에서 받치는 **쇠 끈(밴드) 2개**, 각 끈 끝에 볼트 [4].
  2. 바닥 쪽 **보호판**(얇은 판, 너트/클립 4) [4][5].
  3. 옆에서 뻗어 나가는 **굵은 주입구 호스**(주유구로) + 위의 가는 관 2~3가닥(연료관·숨관·증기 차단 밸브 관) [4].

### ③ 차 안 위치
- **뒷좌석 아래, 차 바닥 밖** — 떼려면 가운데 배기관과 바닥 덮개 2장을 먼저 뗌 [5]. → car_spec `Deco_Underbody` 연료탱크 Z +2.0 ~ +4.4 와 맞음.
- 주유구 쪽(좌/우) (확인 못 함). 주유구 문은 실내 스위치로 열고, 안 열리면 트렁크 안 덮개 뒤 레버 [16].

### ④ 붙어 있는 방식 (V6 매뉴얼, 떼는 순서) [5]
1. 펌프 모듈 먼저 빼기(아래 '연료 펌프' 참고) → **연료 빼내기**.
2. 가운데 배기관 → No. 2·No. 1 바닥 덮개.
3. **No. 1 탱크 보호판**: 롱노즈 플라이어로 **클립 4개**.
4. 연료 본관(main tube)·숨관(breather tube)·**주입구 호스** 분리(퀵 커넥터) → 증기 차단 밸브관을 캐니스터(또는 연료 출구 밸브)에서 분리.
5. **엔진 리프터로 탱크를 받치고**(수평 유지) → **볼트 4개**와 **밴드 L/R** 풀기 — **45 N·m** [4][5].
6. 리프터를 내려 빼기 — 주변에 걸리지 않게 살짝 기울여서. "탱크는 매우 무거움, 리프터에서 떨어지지 않게" [5].
7. 탱크 위 **고무 쿠션**(No. 1 ×2, No. 6 ×1) 떼기 [5].

### ⑤ 흔한 고장
| 증상 | 원인 | 진단 | 수리법 · 시간 |
|---|---|---|---|
| 차 밑에 휘발유 냄새·젖은 자국 | 관·이음새·탱크 샘 | 차 주변·밑 눈으로 [10]. 사용설명서: 바닥에 연료가 샜으면 **시동 다시 걸지 말 것** [17] | 새는 곳 수리·교체 [10] |
| 꽉 찬 탱크에 더 넣다 경고등 | 넘치게 주유 → EVAP 이상 [16] | | 자동으로 '딸깍' 멈추면 더 넣지 말 것 [16] |
| 연료 게이지 이상 | 연료량 센서(아래 모듈) — 이 차 코드 목록에 연료량 센서 회로 코드(P0460 계열) 있음 [33] | | 센서(게이지) 교체 |

### ⑥ 게임 손맛 아이디어 (제안만)
- 탱크 내리기 = **엔진 리프터(테이블 잭)** 장비 필요 일: 받치기 → 밴드 볼트 4 → 천천히 내리기(기울이기 미니 조작) [5].
- 탱크를 내리기 전 '연료 빼기' 안 하면 리프터 바늘이 빨강(너무 무거움) → 다시 [5].

## 부품: 연료 펌프 모듈 (Fuel Pump Module — "fuel suction tube with pump and gauge")

### ① 하는 일
- 탱크 속 **전기 펌프**가 연료를 엔진으로 보냄. A25A: 저압 300~530 kPa, **연료 펌프 ECU가 PWM으로 속도를 무단 조절**, **에어백이 터지면 펌프를 끔** [22].
- 사용설명서: 엔진이 꺼지거나 충돌로 에어백이 터지면 **연료 펌프 차단 장치**가 연료를 막음 → 스위치 끄고 다시 켜면 재시동 [17].
- 탱크 속에 두는 이유: 펌프 '윙' 소리를 줄이고, 연료가 펌프를 식히고 윤활 [25]. 펌프 출구의 **한 방향 밸브(check valve)** 가 꺼져 있을 때도 관 속 압력을 남겨 둠 [25].

### ② 실제 모양·크기·재질·색 — 알아보게 할 특징 3개
- 모듈 구성(V6 매뉴얼 그림 A405983C01·A405970C01) [1][3]: **위 뚜껑 판(suction plate, 커넥터·관 꼭지)** + 아래 **컵 모양 서브탱크** + 그 안의 **원통 펌프** + 펌프 둘레 **연료 필터 통** + 맨 아래 **거름 양말(suction filter, sock)** + 옆의 **연료량 게이지(뜨개 팔)** + 연료 메인 밸브 2(저압·고압) + 배선.
- 고정: 큰 **고리 너트(fuel pump gauge retainer)** 가 탱크 구멍에 돌려 잠겨 있음 + 아래 **개스킷**(새것) [1][2].
- **알아보게 할 특징 3개**
  1. 탱크 위 **둥근 뚜껑 + 큰 링**(돌려서 품) [1][2].
  2. 뚜껑 밑으로 쑥 빠져나오는 **긴 통(컵) + 원통 펌프** [1].
  3. 옆에 달린 **긴 철사 팔 끝 뜨개(float)** — 연료량 센서 [1][2].

### ③ 차 안 위치
- 탱크 윗면 구멍, **뒷좌석 쿠션 아래 바닥의 서비스 구멍 덮개** 바로 밑 [2]. 덮개는 **부틸 테이프로 붙어 있음** [2]. 좌우 어느 쪽인지 (확인 못 함).

### ④ 붙어 있는 방식 (V6 매뉴얼 removal) [2]
1. **연료 압력 빼기** → **배터리 (−)** (끈 뒤 기다려야 할 수 있음) [2].
2. **뒷좌석 쿠션** → 쿠션 잠금 고리 떼기.
3. **서비스 구멍 덮개**: 끝에 보호 테이프 감은 클립 리무버로 떼기(부틸 테이프) → **펌프 커넥터 2개** 빼기.
4. **연료 본관 분리**: 관 이음 클립 빼고 **손으로** 당겨 빼기, 나일론관 꺾지 말기, 빈 구멍은 비닐로 덮기.
5. **고리 너트(retainer)**: 전용 공구(SST 판 + 발톱 + 손잡이)로 **천천히 수평으로** 돌려 풀기 — 임팩트·다른 공구 금지.
6. 모듈 들어내기 — **게이지 팔 휘지 않게** → 개스킷 빼기(새것으로).
- 다시 달 땐 **새 부틸 테이프**로 덮개를 꼭 붙임 [6].
- 안전: 불씨 근처 작업 금지, 배터리 (−) 먼저(불꽃 → 증기 점화) [2][6].
- 펌프만 / 필터만 갈 때도 모듈을 꺼내 분해: 게이지 → 펌프 → 메인 밸브 → 지지대(걸쇠 2) → 필터 [3].

### ⑤ 흔한 고장 (증상 → 원인 → 진단 → 수리법·시간)
| 증상 | 원인 | 진단 | 수리법 · 시간 |
|---|---|---|---|
| **크랭킹은 되는데 시동 안 걸림**, 키 ON 때 '웅' 소리 없음 | 펌프 고장 또는 **펌프 릴레이·퓨즈·배선** [26] | 키 ON 때 PCM이 펌프를 **2초쯤** 돌려 압력을 올림 → 소리 없으면 펌프가 안 도는 것 [26]. 릴레이 흔들어 보기·바꿔 끼우기·바이패스 → 펌프가 돌면 릴레이 문제 [26]. 사용설명서 순서: 연료 부족? 넘침? 이모빌라이저? [20] | 릴레이 / 펌프 교체 |
| 힘 빠짐(가속·고속·언덕에서) | 압력은 되지만 **양(volume)이 모자람**: 닳은 펌프, 막힌 필터·거름 양말, 낮은 전압 [26] | **압력 + 양 시험**: 좋은 펌프는 30초에 약 3/4~1 qt [26] | 원인 부품 |
| 경고등 없이 갑자기 멈춤 | 펌프는 대개 **예고 없이** 멈추고, **코드도 안 남기는 경우가 많음** [25] | 위와 같음 | 교체 |
| 아침 첫 시동만 오래 크랭킹 | 펌프 안 **한 방향 밸브** 샘 → 밤새 관 압력 빠짐 (검색 요약) [31] | 키 OFF 뒤 압력 유지 시험(잔압) [26] | 펌프 교체(밸브만 따로 X — 검색 요약 [31]) |
| 펌프 수명 단축 | 탱크 속 오염, **연료 바닥까지 타기**, **항상 적게 넣고 다니기(과열)**, 낮은 전압, 막힌 필터 [25] | | |
| 고압 쪽 압력 낮음 P0087 | (아래 고압 펌프 표) 저압 펌프 약함도 원인 목록에 있음 [10] | | |

- 교체 시간·비용: 일반적으로 **2~4시간**, 총비용 대부분 차 $1,150~1,400 (AAA) [27]. 시트 밑·트렁크 판으로 꺼내는 차와 **탱크를 내려야 하는 차**가 있어 공임이 크게 다름 [27]. Camry 정확 공임 시간 (확인 못 함).
- 펌프 갈 때 **필터도 같이** 갈 것을 정비사들이 권함, 탱크 개스킷·끈 같은 부속도 [27].

### ⑥ 게임 손맛 아이디어 (제안만)
- **'웅' 소리 듣기 진단**: 키 ON → 2초 웅(정상) / 무음(고장) — 손님 차 뒷좌석에 귀 대는 동작 [26].
- 릴레이 '흔들어 보기' → 안에서 달그락 = 릴레이 고장 (싸게 고치는 반전) [26].
- **트렁크/뒷좌석 접근 미니 루트**: 쿠션 들기 → 덮개(끈적이는 테이프) 떼기 → 커넥터 2 → 링 돌리기(천천히, 빨리 돌리면 미끄러짐) → 모듈 들기(팔 안 휘게) [2].
- 손님 습관 카드 "I always run it on empty" → 펌프 수명 짧아짐 복선 [25].

## 부품: 연료 필터 (Fuel Filter) — 짧게

- 교체하려면 모듈 분해(위 ④) [3].

## 부품: 연료관 (Fuel Lines) — 짧게
- 탱크 → 엔진: **나일론관 + 퀵 커넥터**(안에 O링, 걸쇠·리테이너로 잠김) [6].
- 퀵 커넥터 다루기 [6]: 주변 먼지 닦기 → 리테이너 잡고 당겨 걸쇠 풀기 → 빼기 → 비닐로 덮기. 끼울 땐 밀어 넣고 리테이너 **'딸깍' 소리 확인** → 당겨서 확인 → 누유 점검. 안 들어가면 깨끗한 휘발유 조금.
- 엔진 쪽: 저압 관 1줄은 포트 인젝터 레일로, 1줄은 고압 펌프로 → 엔진 내릴 때 **연료관 2줄(포트용·직분사용)** 을 분리 [22](05 파일 [10]).
- 탱크 쪽 관: 본관(main), **숨관(breather)**, **증기 차단 밸브관**(캐니스터 쪽), 주입구 호스 [4].

## 부품: 고압 연료 펌프 + 레일 + 인젝터 (High-Pressure Pump, Fuel Rails, Injectors — D-4S)

### ① 하는 일
- A25A는 **포트 분사 + 직분사 둘 다** [22]:
  - 낮은~중간 부하 = 둘 같이(섞임 좋음), 큰 부하 = 직분사만(노킹 줄임), 냉간 시동 직후 = 촉매를 빨리 데우는 특별 모드 [22].
- **고압 펌프**: 플런저 1개, **밸브커버 위**에 붙고 **배기 캠축의 4각 캠**이 밀어 줌, 압력 **2.4~20 MPa** 조절, 이상하면 **26.4 MPa** 릴리프 밸브가 탱크로 돌려보냄 [22]. (V6 매뉴얼은 2~25 MPa로 적음 [10].)
- **고압 레일**: 강철, 압력 센서 달림. 직분사 인젝터 = 6구멍, PTFE 링으로 밀봉 [22].
- **저압 레일**: 강철, 벽이 맥동 댐퍼 역할, 압력 센서. 포트 인젝터 = 10구멍 긴 노즐 [22].

### ② 실제 모양·크기·재질·색 — 알아보게 할 특징 3개
- 크기 (확인 못 함).
- **알아보게 할 특징 3개**
  1. 밸브커버 위에 붙은 **작은 펌프 덩어리**(볼트 2, 커넥터 1, 쇠관 연결) [9][22]. 정확한 모양 (확인 못 함).
  2. 엔진 옆에 가로로 누운 **쇠 막대(레일)** 에 인젝터 4개가 꽂힘 — 직분사용·포트용 **두 줄** [22].
  3. 고압관은 **유니언 너트(육각, 17 mm 렌치)** 로 잡힌 쇠관 [9].

### ③ 차 안 위치
- 고압 펌프 = 밸브커버 위 (배기 캠축 끝) [22]. 포트 인젝터 = 흡기 매니폴드 위(엔진 앞쪽), 직분사 인젝터 = 헤드에 직접 [22](05 파일).

### ④ 붙어 있는 방식 (V6 매뉴얼 — 4기통 수치 확인 못 함)
- 고압 펌프 떼기 [9]: 연료 압력 빼기 → 배터리 (−) → 흡기 매니폴드 → 펌프 보호판(볼트 2) → 저압관 분리 → **17 mm 유니언 너트 렌치**로 고압관 너트 2개 → 펌프 볼트 2 + 커넥터 → 펌프·리프터 가이드·O링·리프터·스페이서 개스킷.
- 직분사 인젝터 부품: 레일, 인젝터, **인젝터 실·백업 링·O링·C링(새것)**, 노즐 홀더 클램프, 진동 절연재 [8].

## 연료 압력 빼기 (Discharge Fuel System Pressure) — 모든 연료 일의 첫 단계 (V6 매뉴얼) [6]
1. **냉각수 60 °C(140 °F) 이하**일 때.
2. 방법 A: 엔진룸 릴레이 박스 **EFI MAIN NO. 2 릴레이** 빼기 (또는 방법 B: 뒷좌석 서비스 구멍에서 **펌프 커넥터** 빼기).
3. (직분사 인젝터 배선 커넥터 2개 분리 후) **시동 걸기 → 스스로 꺼질 때까지 기다림**(회전 올리거나 운전 X) → 다시 크랭킹해서 안 걸리는지 확인.
4. **주유 캡을 열어 탱크 압력 빼기**.
5. 배터리 (−) 분리.
6. 그래도 관에 압력이 남아 있음 → 관 뺄 때 **천으로 감싸기**. 고압관은 특히 많이 튐 → 압력 빼기 → 분리 → 남은 연료를 통에 받기 → 비닐로 덮기.
- 일반 안전: 담배·불 금지, 연료를 고무·가죽 부품에 묻히지 말기 [6].

## 부품: EVAP 캐니스터 + 퍼지 밸브 (Charcoal Canister / Purge VSV)

### ① 하는 일
- 탱크에서 나온 **휘발유 증기**를 숯(활성탄) 통에 모았다가, 엔진이 돌 때 **퍼지 밸브(VSV)** 를 열어 흡기로 빨아 태움 [22][12].
- A25A EVAP = 토요타 6세대: **ORVR**(주유 때 증기 회수), 증기 압력 센서, **누설 검사 펌프** 등 [22]. 캐니스터 펌프 모듈 = 벤트 밸브 + 누설 검사 펌프 + 캐니스터 압력 센서 [22][12].

### ② 모양·위치 — 알아보게 할 특징 3개

- 퍼지 밸브: V6는 흡기 서지 탱크에 볼트 1개(21 N·m), 커넥터 1 + 증기 호스 2 [8b]. A25A도 엔진 쪽 센서 목록에 'EVAP purge VSV' 가 있음 [22].
- **알아보게 할 특징 3개**
  1. 바닥 밑 **숯 통** + 호스 여러 가닥(탱크 벤트·벤트·퍼지·공기관) [7] — 통 모양·색 (확인 못 함, 부품표 글로만).

- → car_spec `Deco_Underbody` 의 "캐니스터" 맞음.

## car_spec · fault_catalog 와 다른 점
1. **fault_catalog에 연료 고장이 하나도 없음** → 실제로 흔하고 진단이 재밌는 2개를 후보로 제안: ① **EVAP/주유 캡(P0455·P0456, "Check Fuel Cap")** — Lv1급, 손으로 고침 [12][16][28] ② **연료 펌프("No hum", 크랭킹 OK 시동 X)** — 뒷좌석 서비스 구멍 일 [2][26].
2. **car_spec 후보 부품 목록에 FuelPump 없음** → Camry는 **탱크를 안 내리고 뒷좌석 밑 구멍으로** 펌프 모듈을 꺼내요 [2]. 게임 부품으로 넣으면 `Requires` = 연료 압력 빼기 + 배터리 (−) + 뒷좌석 쿠션 + 덮개(테이프) [2][6]. 리프트 불필요(실내 작업).
3. **Deco_Underbody "연료 라인(굵은 1줄만)"** → 실제 탱크 위엔 **본관 + 숨관 + 증기관 + 굵은 주입구 호스**가 있고 [4], 엔진 쪽에서도 **연료관 2줄(포트용·직분사용)** 을 분리해요 [22]. 그림체 결론(1줄)은 단순화로 OK, 단 **주입구 호스(굵고 짧음)** 는 탱크 옆에 보이게 하는 걸 제안.
4. **Deco_Underbody 연료탱크 "+끈"** → 맞음: **밴드 2개 × 볼트 2 = 4, 45 N·m**, 아래 **보호판** 도 있음 [4][5].
5. **Deco_EngineTop "연료 레일·인젝터 4"** → A25A는 **레일 2·인젝터 8 + 밸브커버 위 캠 구동 고압 펌프** [22] (05 파일과 같은 지적).
6. **'평생 필터'**: Camry 연료 필터는 탱크 속 모듈 안이고 미국 일정표엔 교체 항목이 없지만 [3][32], 유럽 일정엔 8년/120,000 km 교체가 있어 '평생' 이라고 단정하는 공식 문구는 못 찾음 (확인 못 함).
7. **연료 압력 빼기**는 거의 모든 연료·엔진 일의 첫 단계(엔진 내리기 포함) [6](05 파일 [10]) → car_spec EngineBlock `Requires` 에 넣는 걸 제안.

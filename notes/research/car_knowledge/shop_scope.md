# 정비소가 안 하는 일 · 커지면 하는 일 — 카센타 범위 (shop_scope) — wr-carbook, 2026-10-22

> 부탁(사용자: "카센타에서 자동차 관련한 모든 것을 다루는지도 조사하라고 했잖아"): 미국 동네 일반 정비소(independent general repair shop)가 **직접 안 하고 다른 곳에 보내는 일**, 정비소가 커지면 **어떤 일을 직접 하게 되나**, 우리 게임에 **성장 줄기**로 넣는 법.
> 짝 파일: `shop_operations.md`(동네 정비소가 하는 일 22개·하루 흐름 — 여기선 다시 안 씀), `under_car_work.md`, `11_body_paint.md`.
> 표시: **(열어 봄)** = 페이지를 직접 열어 읽음 · **(검색 요약)** = 검색 결과 요약만 봄 · **(확인 못 함)** · **(추정)**·**(제안)** = 내 해석. 값은 미국 달러, 장비 파는 회사·창업 블로그 값이 많아서 **'대충 얼마쯤'** 으로만 쓰세요(게임 느낌용). 조사 방법: 조사 도우미 1명(WebSearch/WebFetch) + 내가 몇 개 다시 열어 확인.

## 한눈에 (5줄)
1. 동네 정비소가 다른 곳에 보내는 이유는 거의 **세 가지**예요: **① 장비가 너무 비싸거나 자리를 많이 먹음**(도장 부스·프레임 기계·ADAS 보정 공간), **② 자격·법이 따로 있음**(냉매 EPA 609, 견인 면허, 고전압), **③ 돈을 버는 방식이 다름**(보증·리콜은 제조사가 값을 내서 딜러만 함).
2. **일반 정비소가 직접 하는 일도 많아요**: 타이어(기계가 싸서), 에어컨(609 자격 + 회수기 약 $4~8천), 머플러 간단 교체, 경고등 진단. 아주 흔한 패턴 = **'직접 안 하고 외주(sublet)로 보내고 중간에서 조금 붙임'** (추정).
3. **장비가 비싼 순서(어림)**: 에어컨 기계(약 $4~8천) < 타이어 기계(각 약 $3~4천, 2015 값) < 휠 얼라인먼트(약 $1~4만) < 파이프 벤더 세트($1~3만) < ADAS 보정 시설($1만~25만) < 도장 부스+프레임 기계(합 약 $5만~17만).
4. **미국 정비소 커 가는 순서는 공개 자료로 못 찾았어요(확인 못 함).** 아래 §B는 값에서 거꾸로 만든 **내 추정**이에요.
5. **우리 게임에 넣는 법 = 지금 규칙(모든 부품 따로·진짜 구조·맞는 공구·폰 화면 단순) 안에서 '새 구역 = 새 부품 묶음 + 새 공구'** 로 열어요(§C). 공개(10/31)엔 안 넣고, 업데이트로.

## §A 일반 정비소가 '보내는' 일 — 일마다

### A-1. 판금·도장 (body / collision shop)
- **왜 따로?** 도장 부스 약 $2만~10만, 프레임(차체 틀 바로잡는) 기계 약 $3만~7만(중고 인증품은 약 30 % 싸게), 공기 압축기 시스템 $5천~1.5만, 용접기 $2천~1만 — 합쳐서 **부스+프레임 기계만 약 $5만~17만**, 차체 공장 하나 여는 데 약 $16만~49만 (열어 봄) [S1]. 다른 요약은 부스 $1.5만~10만·프레임 $1만~7.5만, 보험사 협력 공장(DRP) 인증비 $5천~1.5만, 중고로 사면 처음 비용이 40~60 % 준다고 함 (검색 요약, BodyShop Business 글) [S1b].
- **보험·돈**: 도장 공장 영업배상보험 연 $1,200~7,000, 보통 정비소는 연 약 $652 (열어 봄) [S1]. 보험사가 정한 협력 공장(DRP)이 되면 일이 꾸준히 오지만 **지급 단가가 낮을 수 있음** (열어 봄) [S1]. I-CAR 교육비·DRP 비용 = (확인 못 함).
- **일반 정비소가 직접 하나?** 큰 사고 수리는 거의 안 함. 작은 겉 손질(범퍼 긁힘 정도)만 하는 곳은 있음 — 이걸 말하는 자료는 못 찾음 (추정).
- **보내는 모양**: 손님에게 "차체 공장 소개" 또는 보험사가 공장을 지정 (추정).
- **게임 관련**: 우리 `11_body_paint.md` = 부품(범퍼·펜더·후드)을 떼서 새 부품으로 바꾸는 쪽은 일반 정비소도 함. **도장(칠 올리기)** = 부스가 있어야 → 도색 부스는 빌더 물건 목록에 이미 있음(README).

### A-2. 자동차 유리 + ADAS 보정
- **왜 따로?** 앞유리 갈면 **앞 카메라 보정(ADAS calibration)** 이 필요한 차가 많아짐. 북미 정비소 300곳 조사에서 **처음 투자 평균 약 $55,494, 해마다 장비·도구 약 $18,773** (검색 요약, MOTOR 기사 요약) [S5]. 보정 시설 전체 $15만~25만이라는 곳도, 표적(타깃) 하나짜리는 $1만 이하라는 곳도 있음 (검색 요약) [S5]. 다른 글 = $2.5만~5만, 회수 12~24개월 (열어 봄, 자동차 정비 협회 글) [S2].
- **자리도 비용**: 바닥 평평(1/8 인치 안), 앞으로 보정하려면 길이 약 9 m(30 ft) 이상, 옆으로는 폭 약 3.5~4.5 m (열어 봄) [S2].
- **외주 값**: 차 1대 보정 $200~600. 자문가는 **한 달 보정 20건쯤 될 때까지는 일반 정비소가 외주(sublet)** 하라고 함 (열어 봄) [S2].
- **일반 정비소가 직접?** 유리 갈기 자체는 유리 전문점이 함. 보정만 사 오는 곳·구독으로 쓰는 곳 있음 (검색 요약) [S5]. 유리 갈기 장비 값 = (확인 못 함).

### A-3. 딜러 전용 (보증 수리·리콜·모듈 프로그래밍)
- **왜 따로?** 새 차 **보증(warranty)·리콜은 제조사가 돈을 내므로 인증 딜러만** 함 — 이 문장을 그대로 말해 주는 자료는 못 찾음 (확인 못 함, 상식 수준 — 쓸 때 '추정').
- **독립 정비소가 보증 때문에 일을 못 하는 건 아님**: 미국 연방 보증법(Magnuson-Moss)은 딜러가 아닌 곳에서 수리했다는 이유만으로 **보증이 무효라고 할 수 없다**고 FTC가 말함. 다만 정비소가 잘못해서 망가진 부분은 제외될 수 있음 (검색 요약, FTC 소비자 경고와 재인용 글) [S20].
- **모듈 프로그래밍**: 독립 정비소는 **J2534 패스스루**(제조사 소프트웨어를 쓰게 해 주는 표준 도구)로 가능 — 도구 값 = (확인 못 함), 제조사 소프트웨어 구독은 따로 듦. 원격 프로그래밍 서비스 한 곳 = 모듈당 $125 (검색 요약, 한 업체 값) [S7]. 일부 제조사는 **보안 게이트웨이**(2018년쯤부터 Stellantis 등)로 인증 안 된 도구를 막음 (검색 요약) [S9][S10].
- **일반 정비소가 직접?** 일반 수리·점검·부품 교체는 문제없음. 새 모듈 코딩·리콜은 딜러.

### A-4. 변속기 재생 전문점
- **왜 따로?** 변속기 속을 다 뜯어 검사하고 새 부품을 넣는 일이라 전문 지식·전용 공구·청결한 작업대가 필요 (열어 봄, 변속기 체인 글 — 숫자는 없음, 체인 이해관계 있음) [S11a].
- **값·시간 (검색 요약)**: 공장 재생(remanufactured) $1,300~3,400, 정비소 재생(rebuild) $1,500~3,500, 교체 평균 $1,800~3,400. 재생품 교체 약 2일, 뜯어 고치기 3~5일 [S11].
- **일반 정비소가 직접?** 변속기 **오일 교환·필터**는 함(shop_operations). 변속기 **통째 교체**는 '공장 재생품을 사서 갈아 끼우는' 일반 정비소가 흔함 — 이 문장을 직접 말하는 자료는 못 찾음 (추정). 열어 본 글도 "빼고 다시 다는 작업은 어느 쪽이든 거의 같고, 부품 품질이 값을 가른다"고 함 [S11a].

### A-5. 타이어 전문점
- **일반 정비소가 직접 하는 경우가 많아요.** 기계가 싼 편: 밸런서 약 $4천, 타이어 탈착기(공압) 약 $3천, 얼라인먼트 랙 약 $3.5만, 리프트 각 $3천~8천 (검색 요약, 2015년 값이라 지금은 더 비쌀 것) [S19]. 얼라인먼트 기계 $1만~4만 (열어 봄) [S4].
- 전문점이 따로 있는 이유 = **재고(타이어 수백 종·보관 자리)** + 타이어 회사와 거래 (추정).

### A-6. 머플러·배기 전문점
- 파이프 벤더 + 용접 세트 **$1만~3만**, 리프트 $8천~2.5만 (검색 요약) [S12]. 핵심 선택 = **파이프를 직접 구부려 맞춤 제작** vs 만들어진 계통을 사서 달기 (검색 요약) [S12]. 파이프·머플러 재고 보관도 비용.
- **일반 정비소**는 머플러·촉매 **'교체'** 는 흔히 함(`08_exhaust.md`, shop_operations 표) — 맞춤 구부림만 전문점 (추정).

### A-7. 세차·디테일링
- 이동식 디테일링 시작 $1천~1만, 가게 $1만~8만 (검색 요약) [S15]. 세차 터널 장비 값, 일반 정비소가 직접 하는지 = (확인 못 함).
- **수리 일이 아니라 청소·마무리 서비스** — 정비소가 '수리 끝낸 차 간단 세차'를 서비스로 해 주는 곳은 있음 (추정).

### A-8. 견인
- **왜 따로?** 트럭 + 보험 + 면허: 견인 사업 처음 $3만~15만 (검색 요약, 값이 글마다 크게 다름) [S13]. 보험이 제일 큼 — 상업용 자동차 보험 연 평균 약 $8,800 (검색 요약) [S13]. 면허는 주마다 다름. (이 숫자는 열어 보려 했으나 그 주소 페이지엔 견인 내용이 없었음 → 요약만이고 **신뢰 낮음**.)
- **일반 정비소**: 견인차를 직접 안 갖는 곳이 많고 '아는 견인 회사를 부른다' — 이 습관을 말하는 자료는 (확인 못 함, 추정). 큰 정비소·주유소 겸 정비소는 견인차가 있는 곳도 있음 (추정).
- **게임 관련**: 견인차는 이미 `structure_check_fantasy.md`에 있음(이벤트 차).

### A-9. 튜닝·퍼포먼스
- 다이노(출력 시험기) 값·튜닝 요금 = (확인 못 함).
- **법이 제일 큰 위험**: 배출가스 장치를 끄는 ECU 튜닝은 EPA가 **'defeat device'(불법 장치)** 로 봄, 경주용 예외 없음. Cobb Tuning 벌금 $290만, 작은 정비소도 $5,438~100,025, 장착 정비소도 벌금 대상 (검색 요약, The Drive) [S14].

### A-10. 에어컨 전문점 — 일반 정비소가 대부분 직접 함
- **EPA Section 609**: 자동차 에어컨을 **돈 받고** 손대는 사람은 모두 자격이 있어야 함(부품 하나 갈기도 포함) — EPA 안내를 인용한 검색 결과 (검색 요약) [S16][S21]. 시험·비용·유효기간: 한 글은 **25문제·약 $50·온라인·합격 72 %**(검색 요약) [S16] — 공식 EPA 페이지는 못 열어 정확하지 않음, **게임엔 숫자 안 쓰기**. 벌금 하루 수만 달러 급이라 함 (검색 요약, 2018 글).
- **기계**: 새 냉매 R-1234yf 회수·재충전기 약 $4,280~7,600, 냉매 식별기 달린 것이 비쌈 (검색 요약) [S17].
- 에어컨 수리 값 범위는 `shop_operations.md` ①-1.
- **일반 정비소는 직접 함**(shop_operations: 여름에 제일 흔한 수리). '에어컨 전문점'은 컴프레서·증발기 큰 수리까지 (추정).

### A-11. 전기차·하이브리드 고전압
- **장비**: 시험 거친 고전압 절연 장갑(Class 00), 절연 공구, CAT IV 멀티미터, 잠금·표찰(lockout/tagout), 절연 저항계(megohmmeter), 배터리 리프트, 전기차용 스캔 도구와 제조사 정보 구독(Tesla Toolbox 등) (열어 봄, Vehicle Service Pros) [S3]. 글마다 장갑 등급이 다름(다른 글 = Class 0, 6개월마다 재시험 — 검색 요약) → **쓸 땐 '절연 장갑' 정도만**.
- **고전압 안 만지는 전기차 정비는 독립 정비소도 이미 함**: 배터리 건강 시험, 브레이크, 서스, 냉각, DC-DC 변환기 시험, 구동 유닛 오일 (열어 봄) [S3].
- **자격**: ASE **L3**(경형 하이브리드/전기차) (열어 봄) [S3] — 글은 "장비·교육 갖추기 전엔 고전압 일 기다리라"고 함.
- 장비·교육 값, L3 시험비 = (확인 못 함).

| 8 | 판금·도장 | 부스+프레임 기계 $5만~17만 (제일 마지막) | [S1] |

- **보통 순서 = 값이 싼 것부터 + 지역 손님이 많이 찾는 것부터** (추정). 한 가게가 전부 갖는 경우는 드묾 — 판금·도장은 '다른 사업'에 가까움 (추정).
- **'full-service' 정의**를 말한 업계 글은 (확인 못 함). 우리 게임에선 '차를 받아서 점검·수리까지 한 곳에서 끝내는 큰 가게'로 쓰면 됨 (제안).

## §C 우리 게임에 넣는 법 — 성장 줄기 (제안, wr-design 몫으로 넘김)

### C-0 지켜야 할 규칙 (지금 게임 규칙 그대로)
1. **모든 부품이 따로 떼어지고 맞는 공구**가 있어야 함 → 새 구역마다 **새 부품 묶음 + 새 공구 1~2개**(공구 없이 '버튼 누르면 끝' X).
2. **진짜 구조·진짜 연결**: 도장 부스에서 칠하는 것도 실제 순서(떼기 → 사포 → 마스킹 → 프라이머 → 색 → 클리어 → 말림)를 한 줄로, 유리는 **실제로 앞유리를 접착제 칼로 떼고 새로 붙이는 순서**.
3. **폰 화면 단순**: 새 구역 = 새 화면이 아니라 **기존 작업 화면에 부품 몇 개 더**.
4. **돈으로 이기게 X**, 사용자가 쌓은 걸 빼앗는 변경 X (README).
5. 일 하나가 너무 오래 걸리면 안 됨(economy: 일 1건 약 5분 안팎).

### C-2 '안 하는 일'을 게임 재미로 쓰기 (제안)
- **"이건 우리 가게는 못 해요, 소개해 줄게요" 손님** (예: 큰 사고·보증 리콜): 일을 거절하는 게 아니라 **'다른 가게로 소개' 보상**(평판 조금, 별 점수 영향 X) — 현실 감각을 주는 짧은 이벤트. 지금은 FB #10 루프와 맞음(보류·판단은 wr-design).
- 레벨이 올라 구역이 열리면 같은 손님이 **"이제 여기서 해 주세요!"** 하고 다시 옴(지난번에 소개받아 갔던 손님) — 성장 체감, 돈 거래 X(제안).
- 장비 사는 순서는 플레이어가 고름(economy.md의 '작은 계획 재미')에 ①~⑧을 얹기.

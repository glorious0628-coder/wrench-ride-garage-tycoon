> 부탁: wr-design `docs/design/rival_upgrade.md` §B1·§A①·§B5의 진짜 확인. 없는 건 '모름'.
> 표시: **(열어 봄)** = 내가 페이지를 읽음 · **(검색 요약)** = 검색 결과 요약만 · **(이 폴더 노트)** = 이미 확인해 둔 것 · **(확인 못 함)** · **(추정)**·**(제안)**. 단서 7줄의 출처는 정비 상식 블로그·부품 회사 글이 대부분이라 **'흔한 정비 요령'** 수준이에요(공식 매뉴얼 근거는 따로 표시).

## 한눈에
1. **코어 값**: 맞는 말이에요(새 배터리에 '코어 값'을 붙이고 헌 배터리를 돌려주면 돌려받음). 다만 **돈 흐름이 우리 문서와 조금 달라요** — 정비소는 **부품점에 낸 코어 값을 부품점에서 돌려받음**이고, 손님한테는 보통 '코어 값'이 청구서에 한 줄로 붙었다가 헌 배터리를 같이 내면 빠짐. **미시간은 법으로 정한 보증금이 없음**(§1-1). 글 후보: **"Core credit"**(§1-3).
2. **진단 공임**: 따로 적는 게 **흔함**(미국 독립 정비소 약 $20~160, 딜러 $100~500), **수리하면 공임에서 빼 주는 곳이 많고**, 손님이 안 하면 진단비만 냄. **일 시작 전에 허락 받고 끝에 한꺼번에** 계산이 보통이에요 — '일 중간에 내는' 근거는 못 찾음(§1-2).
3. **단서 7줄**: 5줄은 맞음, **2줄은 고쳐야 함** — ① 딸깍 = 방전 vs 단자: 맞지만 '딸깍 소리만으로는 구분 안 됨, 전조등 밝기·흔들기·전압으로 구분' ② **코일 바꿔 끼우기 시험은 진짜 요령이지만 일부 엔진엔 하지 말라는 제조사 경고**가 있음(§2-6). 나머지 5줄은 §2.
4. **E2 서스**: 캠리 XV70 매뉴얼로 이미 확인한 숫자와 **거의 다 맞음**. 고칠 점 3개(§3): 앞 스트럿 위 너트 3 맞음, 너클 볼트 = '볼트 2 + 너트 2'(토크 290 N·m), **'브레이크 호스 받침 + 속도 센서 선'은 같은 볼트 1개**, 뒤 쇼바 = 바퀴 쪽 너트 1 + 차체 볼트 2(맞음), 뒤 스프링 = 아래 팔 내리면 빠짐(맞음). 바운스 시험은 **주관적이라 기름 자국과 짝으로** 쓰기.

## §1 B1 — 코어 값·진단 공임

### 1-1. 헌 배터리 코어 값 (core charge)
- **무엇**: 새 배터리 값에 **보증금(core charge)을 더해 받고, 헌 배터리를 돌려주면 돌려줌.** 이유 = 납 재활용·위험 폐기물 처리. 값 범위: 한 블로그는 **AutoZone·O'Reilly 같은 곳 약 $12~22**, Arkansas 최소 $10라고 함 (검색 요약, 질 낮은 블로그) [1]. 
- **주 법은 제각각**: 어떤 주는 최소 보증금을 정하고, 새 배터리 산 뒤 **30일** 안에 돌려받을 수 있게 하며, 같은 종류여야 하고, 영수증이 필요한 주도 있음 (검색 요약) [1]. 배터리 협회(Battery Council) 주별 표에는 **Idaho·Maine에 $10 보증금 의무**가 있다고 나옴(검색 요약) [2].
- ★ **미시간(우리 도시 모티브)은 다름**: 현재 법(Part 171, MCL 324.17103)은 **판매점이 새 배터리 판 수만큼 헌 배터리를 받아 줘야 한다**는 것이지 **보증금 의무는 없음** — 1989년에 $6 보증금 안이 있었지만 통과된 증거는 못 찾음 (검색 요약, 법 원문 PDF 목록으로만 봄) [3]. → **미시간풍이라고 'Core return $15'가 법이라고 하면 안 됨. '부품점 정책'이라고 하면 맞음.**
- **정비소 입장 돈 흐름**: 정비소가 부품점에서 배터리를 살 때 코어 값이 붙고, **헌 배터리를 부품점에 가져다주면 그 값을 돌려받음.** 손님에게는 청구서에 '코어 값'이 붙었다가 헌 배터리를 같이 내면 빠진다 — 한 포럼 글에 "정비소가 같은 청구서에서 $25를 깎아 줬다. 헌 배터리를 안 가져왔으면 안 깎아 줬다"는 사례가 있음 (검색 요약, 일화) [4]. **정비소 정책이라 공식 규칙은 못 찾음.**
- → **게임 해석**: 우리 게임은 '부품 상점에서 주문 → 헌 부품을 OLD 칸에 두면 돌려받음'이라서 **'정비소가 부품점에서 코어 크레딧을 받는' 모양이 가장 현실적.** 숫자 $15는 범위(약 $10~22) 안이라 자연스러움.
- 새 배터리 단자 덮개(B1 ④)는 이 폴더 노트 근거(`01_starting_charging.md`)로 검색 필요 — **내가 이 건은 새로 확인 안 했어요**(확인 못 함, '맞다'고 말하지 않음). 지금은 wr-design 표대로 두되, 3D 만들기 전 사진 1장 확인 부탁 시 내가 해 줄게요.

### 1-2. 진단 공임 (diagnostic fee)
- **따로 적는 건 흔함**: 독립 정비소 **약 $20~160, 딜러 $100~500** (한 2025 비용 안내, 검색 요약) [5]. 이 폴더 `shop_operations.md`엔 **평균 약 $100~130, 수리하면 공제해 주는 곳 많음**(검색 요약)도 이미 있음.
- **수리하면 어떻게?**: 보통 **수리비에서 빼거나(credit) 아예 안 받는 정비소**가 많음 — 소비자 안내와 Ford 지원 페이지가 "보증 대상이 아니면 진단이 수리비의 일부가 된다"고 함 (검색 요약) [5]. **손님이 수리를 안 하면 진단비는 냄** (같은 요약, 일화 하나).
- **언제 내나**: **일 시작 전에 허락(진단 승인)을 받고, 끝(수리 + 진단 정산)에 한꺼번에**가 보통이에요. '진단 끝나고 중간에 따로 받는다'는 근거는 못 찾음 (확인 못 함) — **게임에서 'Diagnosis $30'을 진단 직후 바로 주는 건 현실과 조금 달라요**: 현실에선 손님이 진단이 끝난 뒤 "이 수리 할래요?"를 듣고, **하면 진단비는 수리비에 합쳐짐**.
- **제안(wr-design 판단)**: ⓪ 진단 공임을 **'수리 정산 카드의 한 줄'**로 두면 현실과 같음("Diagnosis $30" 줄 + "Battery + labor"). 첫 돈을 2분 안에 주려는 목적이면 **'진단 완료 → 수리 허락 받음 → 선불(Deposit)'** 같은 모양은 근거 없음(확인 못 함). 근거 있는 쪽 = **손님 팁**(현실에서 정비소는 팁 문화가 약함 — 이 점은 (확인 못 함)). → **솔직한 결론: 현실 근거로는 '진단 직후 지급'이 약함, 게임 재미용(제안)이라고 표시하는 게 안전**.

### 1-3. "Core return" 말이 자연스러운가
- 미국 부품 용어는 **"core charge"**(보증금) · **"core return"**(헌 부품 돌려주기) · **"core credit"**(돌려받는 돈) — 세 말 모두 쓰임 (검색 요약) [1][4]. 정비소 사람이 말할 때는 보통 **"core"**("Bring your old battery back for your core")라고 한 줄로 부름 (추정).
- **글 제안(EN)**: 돈 줄 이름 = **"Core credit +$15"**(받는 쪽 관점), 안내 = **"Old battery goes back to the parts store."** 한국어는 "헌 배터리 반납 +$15".

| **브레이크 호스 받침 1** | **맞음 — 속도 센서 선과 같은 볼트** | 속도 센서·브레이크 호스 받침 **볼트 1, 29 N·m** (E3). 호스 이음 자체는 D8: 캘리퍼 쪽 UB 1 + **스트럿 쪽 볼트 1** + 쇠 관 이음 너트 15.2 N·m (좌우 바꿔 끼우기 X) |
| **스태빌라이저 링크 너트 1** | **맞음** | **74 N·m**, 6 mm 육각으로 잡고 풀기 (E3) |
| 앞 합 (너트 5+3+2+1+1 = 12) | **고치기: 12가 아니라 너트 3 + 너클 4 조각(볼트2+너트2) + 링크 1 + 센서 받침 1 = 9개 조이는 것 + 카울 덮개 클립** | 문서의 '너트 5'에서 5가 어디서 온 건지 확인 못 함 — **실제 조이는 것 수는 9개 안팎**(덮개 클립은 별도). 카운트 방식은 wr-design 판단. |
| **앞 스프링은 스트럿에 붙어 나옴** | **맞음** | 스프링 가운데 너트는 **압축기로 누른 뒤에만** 풀기, 임팩트 쓰지 말기(위험) (E4) — 공개 뒤(★5) 계획과 맞음 |
| **뒤 쇼바 볼트 2 + 너트 1** | **맞음** | 바퀴 쪽 **너트 1 + 판 와셔**(먼저 풀어 둠), 차체 쪽 **볼트 2**, 위 너트 25 N·m(나사 접착제) (E15) |
| **뒤 스프링 = 아래 팔 잭으로 받치고 내리기** | **맞음** | 뒤 스프링은 **조이는 것 없음 — No.2 팔(스프링 받침)을 잭으로 받치고 팔 볼트를 풀어 천천히 내리면 빠짐**(압축기 필요 X) (E16, E12). 팔 쪽: 서브프레임 쪽 **너트 1 + 캠버 캠 + 토 캠**, 바퀴 쪽 **볼트 1 + 너트 1** (E12) |
| **뒤가 이 모양인지** | **맞음** | **XV70 앞 = 맥퍼슨 스트럿, 뒤 = 멀티링크(No.1 아래 팔·No.2 팔(스프링 받침)·트레일링 암·쇼바·코일 스프링)** (sedan_teardown §E 머리말) |
| 바운스 시험 | **맞지만 '주관적'** | 차 모서리를 꾹 눌렀다 놓아 **2번 넘게 출렁이면 불량**은 일반 정비 요령 — 다만 **'주관적이라 기름 자국(눈)과 짝으로 확정'** 하라는 단서가 붙음 (`06_suspension_steering.md` §238~239, 검색 요약). **토요타 매뉴얼 자체 판정은 떼어서 로드 4번 이상 눌렀다 빼기(걸림·소리·복귀 속도)** — 게임엔 '눌렀다 놓기(2번 넘게) + 쇼바 오일 젖음'을 두 단계로 쓰는 게 가장 진짜에 가까움. |
- **추가로 알아 둘 것(E2 부품 표에)**:
  1. 뒤 No.2 팔을 만지면 **끝난 뒤 얼라인먼트가 필요** — 캠(캠버·토)에 **자리 표시를 하고** 돌아온 위치를 맞춤 (E12 표시 항목). 게임엔 '자리 표시 → 같은 자리에 조임' 한 단계를 넣으면 진짜 같고 'wheel alignment' 줄기(`shop_scope.md` §C ③)와 연결.
  2. 뒤 쇼바는 **먼저 뒤 바닥 덮개**를 떼야 손이 닿음 (E15: 바퀴 → 바닥 덮개 → 링크).
  3. 한쪽 차고가 낮음 = 스프링 파손 단서 — 이 폴더 `06_suspension_steering.md`에 있음(이번에 새로 확인 안 함).
  4. 앞 스트럿 빼기 전에 **아래 팔 밑에 잭 + 나무로 받치기**(너클이 매달려 브레이크 호스·구동축이 당겨지지 않게) (E3).

# 차 밑에 누워서 하는 작업 (under_car_work) — wr-carbook, 10-21

> 사용자: "그리고 아래로 누워가지고 하는 것도 있고" / "그래서 차 구조 같은 거 보라고 한 거거든".
> 기준 = Toyota Camry XV70 정비 매뉴얼 '차 들어 올리기·받치는 자리'(Vehicle Lift And Support Locations) + 사용설명서 '플로어 잭 놓는 자리' + 이 폴더 노트. → wr-design `work_view`.

## 1. 실제 순서 — 플로어 잭 + 잭 스탠드 + 누움판(creeper)

**토요타 매뉴얼 규칙(그대로)** [1]
1. **평평한 바닥**에서, **바퀴 고임목(wheel chock)을 항상** 써요.
2. 들어 올리기 전에 **주차 브레이크를 풀고 기어를 N**에 둬요(매뉴얼 문구).
3. **앞만 들 때**: 먼저 **뒷바퀴 양쪽에 고임목**. **뒤만 들 때**: **앞바퀴 양쪽에 고임목**. 차 전체를 들 땐 앞을 먼저 들면 고임목은 뒷바퀴 뒤에.
4. 잭과 스탠드는 **정해진 자리에 정확히**, 스탠드엔 **고무 받침**.
5. **"잭만으로 받친 차 위나 밑에서 일하거나 차를 그대로 두지 마세요. 반드시 안전 스탠드로 받쳐요."** ← 게임 안전 규칙의 근거.
6. 차에 짐을 실은 채 들지 말 것. 엔진·변속기처럼 무거운 걸 떼면 **무게 중심이 바뀌니** 반대쪽에 무게추·잭.

**잭·받침 자리 (그림 = [diagrams/25](diagrams/25_camry_xv70_jack_support_positions.jpg), 아래에서 본 차, 앞 = 왼쪽)** [1][2]
| 자리 | 무엇 | 게임 좌표 감 |
|---|---|---|
| **앞 잭 자리** | 차 앞 **가운데 아래**(앞 서브프레임·엔진 받침 쪽, 앞 범퍼 뒤) — 사용설명서 그림도 앞 범퍼 아래 가운데에 플로어 잭 | (0, 바닥, 약 −6.5) — 그림 비율 추정 |
| **뒤 잭 자리** | 차 뒤 **가운데 아래**(뒤 서브프레임 쪽) | (0, 바닥, 약 +6) — 추정 |
| **받침 자리 4곳**(스탠드·스윙 팔 리프트 공용) | 문턱(rocker) **아래 접합 테두리**, **앞바퀴 바로 뒤 · 뒷바퀴 바로 앞** 양쪽 | car_spec `LiftPoint_*` (±3.0, 0.5, ±3.0) **맞음** |
| 판형 리프트 자리 | 문턱 가운데 | — |
| 무게 중심(빈 차) | 앞뒤 바퀴 사이, 앞쪽에 가까움 | — |

**그래서 실제 순서(세단, 앞을 들 때)** — 위 규칙을 이은 것
1. 고임목을 뒷바퀴 양쪽에 → 2. 플로어 잭을 **앞 가운데 잭 자리**에 → 3. 들기 → 4. **앞 받침 자리 양쪽(앞바퀴 뒤 문턱)**에 잭 스탠드 → 5. 잭을 살짝 내려 차를 스탠드에 얹음 → 6. 누움판으로 밑에 들어가 작업 → 끝나면 거꾸로(스탠드 빼기 전 잭으로 다시 받치기).
- 스탠드 높이·누움판 두께 숫자는 출처를 못 열었어요 (확인 못 함). 참고: 세단 지상고는 약 0.14 m(car_spec 0.5 stud)라 **들지 않으면 밑에 못 들어감**.

**누움판(creeper)** [3]: 바퀴 달린 **낮은 판** — 사람이 차 밑으로 미끄러져 들어가게, 높이를 최대한 낮게. 머리 받침·팔 쪽 홈이 있는 것도, 접어서 의자가 되는 것도 있음. 대신 매트·종이 상자 위에 눕기도.

## 3. 누움판으로 하는 일 vs 리프트로 서서 하는 일
| 일 | 차 밑에서 하는 이유 (근거) | 누움판(잭+스탠드) | 2주 리프트 |
|---|---|---|---|
| **오일 교환** | 드레인 플러그·오일 필터가 **엔진 아래**, 덮개 No.4 나사 4개 [4] | 앞만 들고 누워서 | 서서 위로 손 뻗기 |
| **머플러·배기** | 머플러 볼트 2 + 고무 걸이 2, 가운데 관은 바닥 덮개·보강대 먼저 [5] | 누워서 | `Under` 높이에서 서서 |
| **하체 점검**(새는 곳·고무 부트·걸이·녹) | 오일·냉각수 자국, 부트 찢김, 걸이 끊김은 밑에서만 보임 [08, 07] | 손전등 들고 누워서 훑기 | 걸어 다니며 |
| **뒤 쇼크** | 차 **아래에서** 볼트 2 + 너트 1 [06] | 가능 | 쉬움 |
| **연료탱크·연료 펌프 바깥 일** | 탱크 쇠끈 2 볼트 [diagrams/19] | 무거워서 어려움 | 변속기 잭 + 리프트 |
| 바퀴·브레이크 | 바퀴는 **들기만** 하면 됨(밑에 들어갈 필요 X) | 잭으로 한 모서리 + 스탠드 | `Wheel` 높이 |
- 매뉴얼은 **잭+스탠드**와 **스윙 팔(2주) 리프트**를 같은 받침 자리로 둘 다 다뤄요 [1]. 즉 같은 일을 두 방식으로 할 수 있고, 차이는 **자세(누움 vs 섬)·속도·안전 단계**.

## 4. 게임으로 옮길 때 (제안만)
1. **누움판 모드**: 리프트가 없는 Lv1~5(기획서 '수동 잭')에서 하체 일 = **고임목 → 잭 → 스탠드 → 누움판**. 스탠드를 빼먹고 밑에 들어가려 하면 **못 들어감 + 경고 "Put the jack stands under first!"**(벌점 X, 매뉴얼 규칙 [1] 그대로).
2. 누운 시점 = 위 표 2의 하체가 머리 위로 지나감(누움판 바퀴로 앞뒤·좌우 이동). 손이 닿는 범위는 좁게, 리프트를 사면 서서 넓게 → **리프트 = 편의·속도 업그레이드**.
3. **오일 교환 손맛**: 덮개 작은 판 **나사 4개** → 드레인 플러그(새 와셔) → 기름 받이 → 필터 → 위에서 오일 붓기·딥스틱 [4].
4. 차 무게 중심 규칙: 엔진·변속기 같은 큰 부품을 뗄 땐 '흔들림 경고' 같은 작은 연출 [1].

## 한눈에
1. **바퀴 = 휠 너트 5개 M12×1.5, 103 N·m(76 ft·lbf)**, 끼울 때 **뾰족한 쪽(테이퍼)이 안쪽**, 바퀴 바꾼 뒤 **1,000 마일 뒤 다시 조임 확인**, **너트·볼트에 기름·그리스 금지** (열어 봄 사용설명서) [1][2]. 녹슨 차는 이 '**마른 채 조이기**' 규칙이 중요(녹 일에서 다시).
2. **브레이크 패드(앞) = 바퀴 → 캘리퍼 슬라이드 핀 볼트 **1개**(아래 핀을 잡고) → 캘리퍼를 들어 **걸어 둠**(호스에 매달기 X) → 패드 2 → 심(shim) 2종 → 마모 표시판**. 패드는 심·표시판을 **같이 새것**으로, 끼울 땐 **피스톤을 눌러 넣고(리저버 넘치지 않게)**, **캘리퍼 볼트 34.3 N·m**, 끝나면 **페달을 밟아 단단해질 때까지** (열어 봄) [3][4].
3. **교체 한계(열어 봄)**: 앞 패드 **새것 11.0 mm → 1.0 mm 미만이면 교체**, 앞 디스크 **28.0 mm → 25.0 mm 미만**, 뒤 패드 **9.5 mm → 1.0 mm**, 뒤 디스크 **12.0 mm → 10.5 mm** [5][6].
4. **뒤는 전자 주차 브레이크(EPB)** — 패드 일 전에 **'뒤 패드 교체 모드'** (진단기 필요, 순서는 못 읽음)로 캘리퍼를 풀어 줘야 함 [7][8]. **게임 쓰임**: 일반 공구로 안 되는 '스캐너가 필요한 일'.
5. **녹은 '순서(기름 → 기다림 → 톡톡 → 6각 소켓 → 열 → 임팩트)'** 와 **'부러지면 견적 승인'**, 가장 위험한 건 **녹슨 브레이크 관 터짐**(미국 연방 조사 사례)(열어 봄) [9].

## 1. 바퀴·타이어 (Wheels & tires)

### 1-1. 사용설명서 순서·숫자 (열어 봄) [1][2][10]
- **휠 너트 토크 76 ft·lbf = 103 N·m(10.5 kgf·m)** — 바퀴를 갈면 **가능한 빨리 토크 렌치로**. 너트는 **테이퍼(뾰족한) 쪽이 안쪽**. **너트 5개, 나사 M12×1.5, 피치 5×114.3, 센터 보어 60.1 mm**(맞춤 안내 사이트 검색 요약 — 토요타 글엔 없음, 낮은 품질).
- **바퀴 떼기**(비상용 순서): 고임목 → (강판 휠) 장식 캡 → **너트를 한 바퀴만 풂(차를 들기 전에)** → 잭을 **차 문지방 아래 표시된 자리**에 → 잭 올려 타이어가 살짝 뜰 때까지 → 너트 빼고 타이어. **누구도 차 밑에 있지 말 것**, **잭만으로 아래 작업 X — 잭 스탠드 사용**.
- **바퀴 끼우기**: **휠이 닿는 면 청소**(이물질이 너트를 헐겁게 함) → 너트를 손으로 고르게 **테이퍼가 닿을 때까지** → **차를 내림** → **그림에 나온 순서(별 모양)로 2~3번 단단히**(순서는 그림에만 있음 — 글엔 없음) → 휠 락은 마지막에 조이고 먼저 뺌, **휠 락 너트에 임팩트 X**.
- **기름 금지**: **너트·볼트에 오일·그리스 X**, 알루미늄 휠엔 **토요타 너트**, **휘거나 갈라지거나 심하게 부식된 휠은 교체**, 밸런스 추는 **순정급**, 알루미늄에 **플라스틱·고무 망치**.
- **바닥 잭 위치**(`positioning_a_floor_jack`): 사용설명서엔 **앞·뒤(2WD)·뒤(AWD) 그림만, 글 없음** — `under_car_work.md`·`sedan_teardown.md` F11 참고.
- **스페어**: **임시 소형 스페어(TEMPORARY USE ONLY)**, 트렁크 바닥, **센서 없음**, **최대 50 mph(80 km/h)**, 체인 X, ABS/VSC에 영향 줄 수 있음 (열어 봄 `x-2011`·`x-2013`). 스페어 공기압은 (확인 못 함).
- **타이어 점검**: 공기압은 **'차가운 상태'(3시간 주차 또는 1마일 미만 주행)** 에서, **2주마다·최소 한 달에 한 번**, 압은 **문틀 라벨에만**(글에 숫자 없음 — 약한 출처는 35 psi라는 곳과 32 psi라는 곳이 있어 **쓰지 말고 라벨이라고만**). **마모 표시(TWI)가 나오면 교체**, 한쪽만 닳았는지 보기, **회전 순서는 그림**(글엔 패턴·주행거리 없음), **회전·압 조정·타이어 크기 변경 뒤에는 TPMS를 다시 맞춰야 함**.
- **타이어 교체 기준(토요타)**: 마모 표시, **베임·갈라짐·혹(bulge)·깊은 금**, 반복 펑크·수리 불가, **6년이 넘으면 기술자 점검**, 18·19인치 저편평은 더 빨리 닮, 스노우 타이어는 **4 mm(0.16 in)** 에서 교체.
- **크기**(검색 요약, 낮은 품질): 205/65R16(LE 하이브리드), 215/55R17(LE), 235/45R18(SE·XLE), 235/40R19(XSE) [11].

### 1-2. TPMS (공기압 경고) — 열어 봄 `x-1991` [12]
- 바퀴마다 **밸브 + 송신기(센서)**. 타이어·휠을 바꿀 때 **센서도 같이 끼우고 ID 등록 → 초기화**. **금속 밸브 캡 금지**, **액체 실런트가 센서를 망칠 수 있어 그런 타이어면 센서도 교체**. 공기압을 바꾸면 **초기화**: 엔진 끄고 **20분 넘게** → 차가운 압으로 맞춤 → 시동 → 계기판 메뉴 **Vehicle Settings → TPWS → "Set Pressure"**(경고등이 3번 깜박일 때까지 꾹) → **시속 25 mph 이상 10~30분 주행** → 표시창에 '- -' 다음 압력. **1시간 안에 못 하면 20분 쉬고 다시**.
- **새 센서 ID 등록**: TPWS → "Change Wheel"(꾹, 느리게 3번 깜박) → 불이 1분쯤 깜박이다 켜짐 → 주행 → 초기화. **20분 주행했는데 경고등이 계속** = 센서 고장·등록 안 됨. **스페어엔 센서 없음**.

### 1-3. 타이어 기계 일(타이어 전문점 방식 — `shop_scope.md` A-5) (열어 봄 Modern Tire Dealer) [13]
- **순서**: 림을 기계에 고정 → **비드 브레이커로 비드를 떼기** → **양쪽 비드에 윤활제** → 타이어 끼우기 → **공기를 넣어 비드를 앉힘(40 psi 넘기지 말 것)** → **밸런서에 올려** 휠 치수 입력 → 옛 추를 떼고 **기계가 알려 주는 곳(무거운 쪽 반대)에 추** → 알루미늄 림은 **붙이는 추**.
- **흔한 실수**: 비드 브레이커가 비드에서 **너무 멀어 옆면 코드·휠을 망가뜨림** / **윤활제 양·종류 틀림(미끄러짐·떨림·부식, 실리콘 X)** / **TPMS 센서를 망가뜨림**(작업 전 센서 시험, 밸브를 기계 머리와 3시 방향 — GM, 검색 요약) / **철 클립 추 재사용 금지** / 남은 약 **0.5 oz 불균형**이 떨림을 만듦 / **잘못된 휠 너트 토크가 떨림의 큰 원인 — 밸런스 뒤에 토크**.
- **트레드 깊이**: 홈 속 **마모 바(wear bar) = 2/32 in(약 1.6 mm)**, **동전 시험**: 링컨 머리가 다 보이면 2/32 이하(법적 한계), **쿼터 시험**: 워싱턴 머리 일부가 가려지면 4/32 이상 — **현실 교체 시점 4/32** (검색 요약) [14].
- **제조 날짜(DOT)**: 마지막 4자리 = **주·연**(2420 = 2020년 24번째 주), 안 쓴 타이어도 늙음, 토요타는 **6년이면 점검**. **10년 한계는 (확인 못 함)**.
- **펑크 수리 규칙**(검색 요약, 출처마다 숫자 다름): **트레드 가운데 약 70 %에서만**, 구멍 **1/4 in(6 mm) 이하**(3/8이라는 곳도), **타이어를 림에서 떼서 안쪽을 보고 '패치 + 플러그'**, **어깨·옆면은 수리 불가**, **옆면 혹 = 바로 폐기**, 밖에서 꽂는 플러그만 = 임시 [15].
- **앞바퀴굴림 회전**(검색 요약, 낮은 품질): 뒤는 **같은 쪽 앞으로**, 앞은 **반대쪽 뒤로 엇갈려**(forward cross), **5,000~7,000 mi 또는 6개월**, 방향성 타이어는 앞뒤 직선만 — **토요타 그림은 못 읽음**.

### 1-4. 바퀴 — 우리 게임에 넣는 법 (제안)
- **이미 있는 일**(Lv1~5 `Wheel` 펑크 교체·브레이크 패드 때 바퀴 떼기) + **새 일**: **Tire Rotation**(★1, 바퀴 4개를 '엇갈려' 옮기기 — 손 퍼즐), **Tire Mount & Balance**(★3, 타이어 기계 구역 — `shop_scope.md` §C ① 와 같이), **TPMS 초기화**(★2, 계기판 메뉴 단계를 '화면 단계'로).
- **동작**: 너트 **별 순서 '톡톡톡' + 마지막 '토크 렌치로 딱'(103 N·m = 토크 보너스)**, **테이퍼 안쪽**(너트 메시에 테이퍼를 보이게), **'휠 면 청소' 한 번**(솔질 한 번 = 이물질 → 진짜 이유 한 줄), **차를 내린 뒤 최종 조임**(진짜 순서).
- **규칙 한 줄(교과서 '진짜 규칙')**: **"Lug nuts go on dry."**(기름 금지) — 이후 '녹 일'과 연결.
- **새 공구**: **토크 렌치**(있음) · **타이어 레버**(`tool` 칸에 있음) · **비드 브레이커·타이어 기계·밸런서**(기계 구역) · **TPMS 스캐너**(EPB용 진단기와 같은 계열).
- **새 단서·고장**: `TIRE_WORN_BARS`(홈 속 바 보임 + '비 오는 날 미끄러움'), `TIRE_OLD_CRACKS`(옆면 가는 금 — DOT 날짜 6년 넘음), `TPMS_LIGHT`(계기판 불, 센서 고장·등록 안 됨), `WHEEL_NUTS_LOOSE`(바퀴 갈고 1,000 mi 뒤 '덜덜' — 진짜 규칙의 이유).
- **하지 말 것**: 공기압 숫자(35·32 psi)를 화면에 쓰기(문틀 라벨 — **차마다 다름**), 펑크 수리 크기를 단정(출처 갈림), 스페어를 풀사이즈로 만들기(**소형 임시 + 센서 없음 + 50 mph**).

## 2. 브레이크 (Brakes) — 앞 패드 · 디스크 · 캘리퍼 · 액

### 2-1. 앞 패드 (`x-2101`·`x-2102`, 열어 봄) [3][4]
**떼기**: ① 앞 바퀴 ② **아래 슬라이드 핀을 잡고** 캘리퍼 슬라이드 핀 **볼트 1개** 풂(**브레이크 호스를 꺾거나 상하게 하지 말 것**) ③ **캘리퍼를 들어 올려 고정**(떨어지면 손가락 끼임) ④ 패드 **2개** ⑤ **No.1·No.2 소음 방지 심(shim)** ⑥ 패드마다 **마모 표시판**을 드라이버로 떼기.
**끼우기**: ① **심 양면에 브레이크 심 그리스**(08887-80409) ② 심 + **새 마모 표시판** ③ **피스톤을 억지로 말고 눌러 넣기, 리저버 수위가 넘치지 않게 지켜봄** ④ 패드(**마모 표시판이 위쪽**) ⑤ **아래 핀을 잡고** 캘리퍼를 끼워 **볼트 34.3 N·m** ⑥ 바퀴 → **페달을 밟아 단단해질 때까지**.
**경고(열어 봄)**: **심·표시판은 패드와 같이 새것**, **라이닝(마찰면)에 윤활제 X, 기름·그리스가 마찰면에 닿지 않게**, **새 패드는 처음엔 제동이 약하니 시운전**, 페달이 물렁하면 밟아서 단단하게.

### 2-2. 디스크·캘리퍼 (`x-2493`~`x-2495`, 열어 봄) [5][16]
- **한계**: 패드 **11.0 → 1.0 mm 미만**, 디스크 **28.0 → 25.0 mm 미만**. 디스크 흔들림(runout) 한계는 (확인 못 함).
- **점검**: 캘리퍼 **보어·피스톤의 녹·긁힘**, 패드 받침판의 **탄성·균열·녹**, 허브 베어링 헐거움·허브 흔들림 → 디스크를 **허브 너트 5개 103 N·m로 임시 장착**해 측정. **캘리퍼 브래킷(마운팅) → 너클 볼트 2개 107 N·m**. **새 디스크 = 허브와 맞춤 표시, 흔들림이 가장 적은 자리**.
- **캘리퍼 분해**(재생): 피스톤 씰 새것 + 리튬 비누 계열 글리콜 그리스, **피스톤에 새 부츠, 억지로 넣지 말기**. **유니온 볼트·개스킷은 한 번 쓰고 버림**.

### 2-3. 뒤 브레이크 + 전자 주차 브레이크(EPB) (`x-2123`~`x-2126`, `x-2511`~`x-2513`, 열어 봄) [7][8]
- **떼기**: 뒤 바퀴 → **'뒤 패드 교체 모드'** 실행(진단기, 순서는 못 읽음) → **No.2 주차 브레이크 와이어 분리** → **아래 핀 볼트 1** → 캘리퍼 들어 올림 → 패드 2 → **심 3개**(안쪽 No.2·No.1 + 바깥 1) → 표시판.
- **끼우기**: 패드 식별 표시 확인 → 심 안쪽 그리스 → **바깥 심의 발톱이 차 바깥쪽** → **새 표시판(이번엔 '아래' 쪽)** → 피스톤 누름 → **새 볼트 34.3 N·m**. 뒤 브래킷 → 액슬 캐리어 **볼트 2개 107 N·m**.
- **한계**: 패드 **9.5 → 1.0 mm**, 디스크 **12.0 → 10.5 mm**. **캘리퍼 안에 브레이크 클리너 X, 빨리 해서 녹 방지, 열었으면 공기 빼기, 주차 브레이크 구동기 너트를 돌리지 말 것**.
- **EPB 모드**: 많은 EPB 차가 **정비 모드로 캘리퍼를 풀어야** 패드를 갈 수 있고, **정비 모드엔 스위치가 안 먹음**(Snap-on 등, 검색 요약) — 2018 캠리 하이브리드를 **스캐너로 가능**하다는 판촉 글도 있음 [8].

### 2-3b. 브레이크액 교환·공기 빼기 (`x-2756`·`x-2760`, 열어 봄) [17]
- **액**: SAE J1703 / **DOT 3** 또는 J1704 / **DOT 4**. **새 액만**, **리저버 필터 제거 X**, **MIN~MAX 사이 유지**, **도장에 묻으면 바로 씻기**.
- **순서(바퀴마다)**: **P 단 + 주차 브레이크** → 리저버 캡 열고 채움 → **블리더 캡 열고 비닐 관 연결** → **페달을 여러 번 밟고 → 누른 채 블리더를 풀기 → 흐름이 멈추면 조임 → 페달 놓기** → **공기 없는 새 액이 나올 때까지 반복** → **블리더 8.3 N·m**.
- **조심**: **공기가 있는 동안 ABS 구동기(액추에이터)를 작동시키지 말 것**(공기가 들어감, 못 빼면 구동기 교체). **바퀴 빼는 순서·진단기 사용·'본딩(bed-in)' 절차는 (확인 못 함)**.

### 2-4. 일하는 방식·고장 (검색 요약) [18][19]
- **현장 요령**: 캘리퍼는 **훅·걸이에 걸어 호스에 무게가 안 걸리게**, **C 클램프·압축 도구로 피스톤(나무·수건 대고)**, **브래킷은 브레이크 클리너로 청소(철솔 X)**, **가이드 핀은 점검·그리스, 찢어진 부츠 교체**, **하드웨어 접촉점 그리스**, **매뉴얼 토크**, **새 디스크는 클리너로 닦고 너트로 임시 고정한 채 브래킷**.
- **소리·증상**: **끼익(제동 중 멈추면 사라짐) = 마모 표시 탭이 디스크에 닿음**, **드르륵 갈림 = 패드가 다 닳아 금속 뒷판이 디스크에 닿음**, **페달·핸들 떨림 = 디스크가 휘거나 두께가 고르지 않음**, **물렁한 페달 = 공기·액 부족·마스터 실린더**, **한쪽으로 쏠림 = 패드 마모 차이·캘리퍼 끼임·액 문제**.
- **디스크 갈기(resurface) vs 교체**: 근거 못 찾음 — **매뉴얼 규칙 하나 = 한계 두께 미만이면 교체**. **브레이크 작업 값(범위)은 (확인 못 함)** [20].
- **흔한 실수**(토요타 경고 문구 기준): 피스톤 안 누름 / 호스 손상 / 마찰면 오염 / **토크 안 줌** / **밟아서 단단해지기 전에 출발**.

### 2-5. 브레이크 — 우리 게임에 넣는 법 (제안)
- **일 사다리**(앞 패드 = 이미 튜토리얼 일): ⓐ **앞 패드 교체(★2, 심·표시판 새것까지)** ⓑ **뒤 패드 + EPB(★3: 진단기가 필요 — '뒤 패드 교체 모드' 단계, 공구 칸 '스캐너'를 한 번 더 씀)** ⓒ **디스크 교체(★3: 두께 측정)** ⓓ **캘리퍼 재생/교체(★4)** ⓔ **브레이크액 교환(★2~3: 공기 빼기 '펌프 꾹 – 풀기' 2인 동작)**.
- **새 동작**: **캘리퍼 걸어 두기**(호스에 매달면 '꺾임' 경고 — 이미 `Swing`/캘리퍼 젖히기 있음), **피스톤 누르기**(이미 있음 `act.pushPiston`) + **리저버 수위가 오르는 걸 보기(넘치기 직전 '철렁')**, **캘리퍼 볼트 '딱'(34.3)**, **마모 표시판 = 패드 위쪽 작은 쇠 판(보이게)**, **심에 그리스 한 번**(작은 손동작 = 진짜 이유 한 줄), **페달 3번 밟아 단단해지기(= 시운전 전 마지막 단계)**.
- **새 공구**: **캘리퍼 피스톤 도구(C 클램프)**, **마이크로미터/캘리퍼(두께 측정 — 새 점검 동작)**, **브레이크 블리더 키트(비닐 관 + 병)**, **EPB 스캐너**.
- **단서**: 끼익(표시판) → 드르륵(금속) 순서(`wr-sound` 이미 있음), **디스크에 갈린 홈·푸른 열 자국**, **페달 떨림 = 디스크 두께 차이**, **물렁함 = 공기**, **한쪽 쏠림 = 캘리퍼 끼임**.
- **측정 재미(제안)**: **'디스크 28.0 → 25.0 mm' 같은 한계를 눈금자로 직접 재서 판단**(손님 승인 근거). 값은 차마다 다름 — **캠리 숫자를 '캠리 이름표'와 같이만**.
- **하지 말 것**: 패드 교체 때 **바퀴 너트 별 순서를 건너뛰게** 하기, 디스크 갈기 minigame(근거 약함 — 한계 두께 교체만), **EPB 모드를 '버튼 하나'로 숨기기**(진짜는 진단기), 액 순서를 지어내기.

### 3-1. 왜·어디서 (열어 봄 CBS Detroit/NHTSA, 나머지 검색 요약) [9][21]
- **미국 연방 조사 사례(열어 봄)**: GM 트럭·SUV **약 500만 대(1999~2007년식)** 의 **브레이크 오일 관이 녹슬어 샘**, 한 신고는 **갑자기 브레이크가 안 들음**. NHTSA가 2015년 4월 **리콜 없이 조사를 끝내며 '도로 소금 + 안 씻음' 탓**, 권고 = **겨울 동안·뒤에 차 밑을 여러 번 씻고 브레이크 관을 점검·교체**. **미시간·오하이오·일리노이·인디애나·펜실베이니아·뉴욕·위스콘신·미네소타** 등 소금 쓰는 주가 대상 [9].
- **시작되는 곳**(검색 요약): **문지방 패널**(낮고 물·소금·자갈 맞고 속이 빈 판 안쪽에 물이 고여 **안에서도 녹**), **바퀴집**(두 겹이 만나는 가장자리에 끼는 흙), 작은 칩 하나로 소금이 맨 금속에 닿으면 **부풂·떨어짐**. 펜더 아랫부분·트렁크 바닥·서브프레임·배기·볼트·휠 너트·디스크 허브는 '낮고 젖고 숨은' 곳이라 같은 패턴 (**글로 인용할 근거는 못 찾음**, 추정).

### 3-2. 녹슨 볼트 — 풀기 사다리 (검색 요약 — 열어 본 글이 거의 없음) [22]
- **순서**: **침투제 뿌림 → 기다림(최소 15~30분, 심하면 몇 시간~하룻밤, 다시 뿌림) → 볼트 머리를 정확히 망치로 톡톡**(스레드 충격, 머리를 망가뜨릴 만큼은 X) → **6각(6-point) 소켓으로 꾸준히 당김**(12각은 미끄러져 머리를 둥글게 만듦) → 안 되면 **열(가열은 주위 금속을 늘려 녹 결합을 깸, 너무 달구지 말 것) 또는 임팩트**(짧게 세게, 너무 세면 부러짐), **브레이커 바는 천천히 꾸준히**. **부러질 것 같으면 멈춤**.
- **둥글어진 머리**: 추출기(나선형·소켓형). 부러진 스터드·왼나사 드릴 비트는 이번에 못 찾음(`undercar_study.md` §1-2에 vehicleservicepros 순서가 있음).
- **침투제 시험 순위(포럼에 다시 올라온 2007 기계공 잡지 시험 — 주관적, 원문 못 찾음)**: 풀리는 데 든 힘(낮을수록 좋음) 없음 약 516 · WD-40 약 238 · PB Blaster 약 214 · Liquid Wrench 약 127 · Kroil 약 106 · ATF + 아세톤 반반 약 53 [23]. **ATF-아세톤 혼합은 매우 불이 잘 붙음**. → 게임엔 **침투제 등급을 '일반 < 좋은'** 정도만.
- **안티시즈(anti-seize)와 토크**(포럼): 공개된 토크 값은 **'마른 상태' 기준**이라 **윤활하면 같은 힘을 더 낮은 토크로 얻어 과조임**됨(예: 85 ft·lbf가 실제 약 95), **휠 너트·휠 면은 마른 채** 둠 — **토요타 사용설명서도 '너트·볼트에 기름·그리스 금지'**(열어 봄). **안티시즈는 토크가 중요한 곳(휠)에는 틀린 선택** [24].

### 3-3. 디스크가 허브에 녹아붙음 (검색 요약) [25]
- **순서**: 스터드와 디스크 허브 사이에 **침투제** → 180° 돌려 반복 → **허브 모자 둘레를 망치로 돌리며 톡톡**(말렛은 부족할 수 있음, 4~5번 세게) → 허브에 **잭 볼트 구멍**이 있으면 **볼트를 살짝 넣고 디스크 가장자리를 치고 1/4바퀴씩 조임**(과조임 시 나사 뜯김) → 없으면 **캘리퍼·브래킷을 떼고 긴 볼트 + 와셔 + 너트로 디스크 면을 살살 눌러 뺌** → 열은 **허브 접촉부에**(베어링 그리스가 녹지 않게), 안 되면 **유압 풀러**, 최후엔 **디스크를 잘라 부숨**.
- **예방**: **허브 면 청소 + 안티시즈**(기름은 열에 타서 굳음). **스터드를 직접 치지 말라는 말**과 **디스크 고정 나사**는 이번에 못 찾음(확인 못 함).

### 3-4. 녹슨 브레이크 관 (검색 요약 + 열어 봄) [9][26]
- **교체 재료**: **구리-니켈 관**(DIY에서 가장 흔함 — 강철보다 휘고 플레어가 쉬움, 브레이크용으로 규격 있음, 싼 것은 꺾이거나 플레어가 나쁨). **도구**: 좋은 **더블 플레어 공구**, **플레어 너트 렌치**, 작은 관 커터, 휨 플라이어, 침투제. **녹슨 플레어 너트가 가장 힘듦** — 너트 근처를 자르고 침투제, **박스형 플레어 렌치**. 미리 만든 관 + 유니온으로 플레어를 피하는 방법도 있음. **끝나면 공기 빼기를 꼼꼼히**.

### 3-5. 차체 녹 수리 단계 (검색 요약) [27]
- **표면 녹**(부풂·드러난 금속, 구멍 없음) → **맨 금속까지 사포 → 녹 변환제·억제제 → 프라이머 → 칠**(DIY 약 $20~150·2~4시간 — 블로그 주장).
- **비늘 녹**(떨어지고 번짐) → **잘라내고 패치 용접 → 퍼티 → 프라이머 → 칠**.
- **구멍(관통)** → **패널 교체**(많은 정비소가 더 빠르고 싸서 통째 교체). 변환제·퍼티는 구멍엔 안 맞음. 비용 '패널당 $2,000 넘음, 큰 구조 작업 $5,000 이상'은 블로그 주장.
- **살 차의 녹 단서**: 구멍, **금속이 드러나는 떨어짐**, **물렁하거나 구멍 난 프레임 레일**, **스트럿 타워·서스 마운트 녹**, **갈라진 브레이크 관**. **안전 검사에서 녹을 잡는지는 주마다 다름**(미시간엔 검사 없음, `shop_operations.md`) — 정비사가 **리프트로 들어 프레임·관·마운트를 찔러 봄**이 권고 [28].

### 3-6. 녹 — 정비소 경제 (포럼 일화, 낮은 신뢰) [29]

### 3-7. 녹 — 우리 게임에 넣는 법 (제안)
- **★4 '녹슨 차' 재료**: 볼트·너트·스터드·디스크 허브·브레이크 관이 **'녹 단계 0~3'** 을 가짐(갈색 + 가루 + 구멍). `full_teardown.md` §1 '녹(★4 차)' 줄 — **칙(침투제) → 2초 기다림 → 풀기** 그대로 + 아래를 더함.
- **풀기 사다리(작업 화면)**: ① **침투제 칙**(볼트에 '촉촉' 효과) ② **기다림 N초**(**기다리는 동안 다른 일을 할 수 있게** — 정비소 '병렬 작업' 맛, 지루함 X) ③ **망치 '톡톡'**(탭 2번) ④ **6각 소켓**(12각 소켓은 '미끄러져 머리 갈림' 실패 — **공구 맞춤 규칙과 이어짐**) ⑤ **열(토치)**(Lv 높은 공구) ⑥ **임팩트/브레이커 바**. **단계를 건너뛰고 세게 하면 부러짐**.
- **부러진 볼트 = 이벤트(벌 X)**: **'견적 승인' 카드**("A bolt snapped. Fixing it costs extra. OK?" — 손님이 허락하면 **추출기 일**(새 공구) → 허락 안 하면 **일부만 하고 돌려줌**) — `shop_operations.md`의 '추가 작업 허락' 흐름과 같음. 시간·돈 추가는 **'열 요금'처럼 영수증 한 줄**.
- **휠 너트·디스크·허브의 녹**: **'마른 채 조이기' 규칙**(안티시즈를 바르면 경고 한 줄 — '토크가 달라져요'), **디스크가 허브에 붙음 = 4단계**(침투제 → 허브 둘레 톡톡 → 잭 볼트/긴 볼트 → 안 되면 '디스크를 잘라 새것').
- **녹슨 브레이크 관(★4~★5, 안전)**: **관이 샘 = 페달이 바닥까지 + 바닥 웅덩이(브레이크액 색)**, **플레어 너트 렌치 + 플레어 공구**, **끝나면 공기 빼기**(§2-3b). **가장 위험한 고장**이라 **'손님 안전'** 보너스로(교과서 '진짜 규칙').
- **차체 녹 3단계**: 표면 녹(사포 → 프라이머 → 칠, 이미 `rsact.sand/primer/paint`), **패치 용접**(이미 `rsact.weld`), **패널 교체**(공개 뒤) — 이미 복원 일(`wreck`·`rust.sev1~3`)에 있음 → **'침투제 일'·'녹 볼트 일'을 일반 일에도 확장**하자는 제안.
- **지역 근거**: **디트로이트 소금**(검색 요약) — 도시 손님 차에 **'문지방·바퀴집 녹'** 이 더 많이 나오게 하는 이유로 충분(실제 통계 못 찾음 — 확률은 게임 값).
- **하지 말 것**: 모든 볼트를 녹슬게 하기(★4 차만), 녹 일을 '기다리기만'으로 만들기(기다리는 동안 할 일 필수), 침투제 순위 숫자를 화면에 쓰기(주관적 시험).

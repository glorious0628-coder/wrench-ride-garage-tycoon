# 장식 덩어리 빠른 참고표 (decor_quickref) — 3D·6면용 (wr-carbook, 10-21)

> 메인 부탁: car_spec §5 `Decor/…` 덩어리마다 **실제 모양·크기·색·알아보는 특징**.
> 기준 차 = Toyota Camry XV70 2.5 L(A25A) — 실제 사진 [diagrams/23](diagrams/23_photo_2018_camry_25_engine_bay.jpg)(2018 캠리 2.5 엔진룸, 앞에서 본 모습: 사진 오른쪽 = 차 왼쪽 = 운전석) + 정비 매뉴얼 그림(diagrams/01~22) + 하체 사진 [diagrams/24](diagrams/24_bing_camry_underside_photos.jpg).
> 환산 1 stud = 280 mm. 실제 치수가 공개 안 된 건 **'그림·사진 비율 추정'** 이라고 적었어요(숫자 근거가 아니라 눈대중 — 3D가 더 잘 아는 값이 있으면 그걸 우선).
> 그림체 B(둥근 캐주얼): 모양은 단순하게, **색 덩어리·자리·연결**은 진짜대로. car_spec §5 메인 결론: 큰 색 덩어리(엔진·라디에이터+팬·배터리·에어박스·큰 탱크) / 한 구역(발전기+벨트+에어컨) / 가까이서 보는 디테일(캡·단자·딥스틱·퓨즈박스), **검은 부품끼리 붙지 않게 명도 차**.

## 0. 사진으로 본 엔진룸 색 지도 (diagrams/23)
| 자리 (차 기준) | 무엇 | 실제 색 |
|---|---|---|
| 맨 앞 가로 전체 | 라디에이터 위를 덮는 **큰 플라스틱 덮개**(공기 덕트 실, 클립 5) + 가운데 보닛 걸쇠 | 무광 검정 |
| 가운데 | **엔진 커버** — 넓적한 판, 둥근 **오일 캡 구멍** + 가운데 로고 자리 | 진회색(차콜) |
| 엔진 커버 앞 | **흡기 매니폴드**(검은 플라스틱 관 뭉치) + **스로틀 바디**(은색 알루미늄) + 노란 **딥스틱 고리** | 검정 / 은색 / **노랑** |
| 운전석 쪽 **앞 구석** | **에어클리너 통**(큰 각진 상자) → 굵은 **주름 흡기 호스**가 스로틀로 | 무광 검정 |
| 운전석 쪽 **가운데** | **배터리**(위에 흰 라벨, + 단자에 **빨간 덮개**) | 검정 + 빨강 |
| 운전석 쪽 **바깥(펜더 옆)** | 키 큰 **릴레이·퓨즈 박스**(뚜껑에 'RELAY & FUSE') | 무광 검정 |
| 운전석 쪽 **뒤(방화벽)** | **브레이크액 통**(반투명 흰 통 + 검은 캡) | 반투명 흰색 |
| 조수석 쪽 앞 | **냉각수 보조탱크**(반투명 흰 통, 안에 **분홍** 냉각수) + 은색 **에어컨 배관** | 흰 + 분홍 / 은색 |
| 조수석 쪽 바깥 | 작은 퓨즈 박스(검정), 스트럿 탑(차체색) | |
| 양쪽 뒤 모서리 | **스트럿 탑** — 차체 색 판에 볼트 3개 | 차체 색 |
| 뒤 끝 | **와이퍼 카울**(검은 그릴 판) | 검정 |
- 정리: 엔진룸은 **검정·진회색 + 은색 포인트**, 눈에 띄는 색은 **노랑(딥스틱), 빨강(배터리 +), 반투명 흰 통 2개, 분홍 냉각수** [diagrams/23]. (README·ref_sedan의 관찰과 같음.)

## car_spec §5 와 다른 점 (→ board에 wr-design 앞으로)
1. **운전석 쪽 앞→뒤 순서**: 사진(diagrams/23)·사용설명서 그림(01) 모두 **에어클리너 통(맨 앞 구석) → 배터리(가운데) → 브레이크액 통·부스터(방화벽)**, 퓨즈·릴레이 박스는 배터리 **바깥(펜더 쪽)**. car_spec 배터리 Z −6.6(엔진룸 앞쪽)은 실제보다 **앞**이에요 → **Z 약 −5.6 ~ −5.8**(엔진룸 −8.0 ~ −3.8의 가운데쯤), 앞 구석(Z −7 근처)에 에어박스. (그림·사진 비율 추정 — 정확한 mm는 확인 못 함.)

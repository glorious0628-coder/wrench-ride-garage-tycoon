## 0. 어떻게 봤나, 한계

- 내장 브라우저로 YouTube를 열고, 영상 칸만 크게 키워서 시간(&t=초)마다 화면을 찍었어요. 게임당 영상 1~3개.
- **자동 대본(자막)을 통째로 읽었어요** → 첫 10분 단계, 한 대 걸리는 시간은 대본 시각 + 화면 숫자로 쟀어요. (그래서 "몇 분 몇 초" 숫자는 믿을 만해요.)
- **소리는 못 들었어요.** 효과음·음악 평가는 못 해요. 소리 얘기는 말하는 사람이 말한 것만 적었어요.
- 영상 보는 중에 광고(Junk Mechanics 광고)가 새 탭을 자꾸 열었어요. 닫기만 했고, 아무것도 누르거나 로그인·결제·다운로드는 안 했어요.
- 숫자 중 "약"이 붙은 건 화면 글자로 짐작한 거예요.
- 우리 게임은 오늘 직접 안 켜 봤어요. "우리가 부족해 보일 곳"은 기획 노트·메인 메모 기준이라, 켜서 확인이 필요한 건 (확인)이라고 적었어요.

## 1. Fix It Up! (Roblox) — 가장 가까운 라이벌

**영상**
- 주: https://www.youtube.com/watch?v=ElikeZ_yT-U — "$0 - $100,000 | Rags To Riches | Roblox Fix It Up #1" (Mecker, 22분 53초, 조회 7.9만, 1년 전)
- 보조: https://www.youtube.com/watch?v=jOCrBh85W6o — "Flipping Definitely-Not-Junk Cars for Money! (Roblox Fix It Up)" (Camodo Gaming, 19분 47초, 10만, 11개월 전)

**핵심 한 바퀴**: 폐차장에서 녹슨 차 사기 → 부품 가게에서 부품 사기(분사기 $60 / 점화 플러그) → 정비소로 운전 → 엔진 분해 → 부품을 작업대 칸에 놓기·씻기·낡은 것 버리기 → 다시 조립 → 배터리 충전 → 운전해서 폐차장 팔기 자리에서 팔기. 돈이 쌓이면 더 좋은 차.

**화면 구성(HUD)**
- 운전 중: 왼쪽에 키 8줄이 항상 떠 있음(M 변속모드·N 운전모드·E/Q 기어·P 주차·F 시동·L 라이트·H 경적). 왼쪽 아래 "Condition 44%" 알약, 미니맵, 속도계·회전계·연료. 오른쪽 가운데 아이콘 5개 세로 + 돈(€). 왼쪽 위 채팅/시스템 글. [사진 fixitup_02]
- 정비소 안: 왼쪽에 3줄(Grab Part / F Install Part / R Store Part), 가운데 아래에 "PRESS [F] TO INSTALL PART" / "PRESS [R] TO STORE PART" 노랑·파랑 막대. [사진 fixitup_05, 07]
- 한눈에 너무 많아요: 키 8줄 + 채팅 + 미니맵 + 아이콘 5개 + 돈이 동시에. 우리 "한 번에 하나" 규칙과 반대.

**부품 떼기·공구·진단**
- 후드 열기 → 엔진 조각들이 월드 물체로 튀어나와 작업대(칸마다 "WAITING FOR PART" / "INVALID PART" 팻말)에 올림. 전용 자리에 맞아야 인정. [사진 fixitup_05~07, 10, 11]
- 씻기 싱크, 배터리 충전기("BATTERY CHARGE 100%"), 낡은 부품 쓰레기통, 엔진 칸이 따로 있음. 후반에는 휠·타이어 따로 해체.
- **진단 거의 없음**: 무슨 부품이 나쁜지 가르쳐 주는 곳이 약해요. "Condition %" 숫자 하나가 전부(진단이 아니라 사기 전 겉모양으로 고름). "Where did half of my engine fling shot to"(15:53) = 부품이 물리로 튕겨 날아가 헤맴. "Why can't this just sit right?"(16:05)

**운전/시운전**: 정비소까지 직접 운전(폐차장 → 부품 가게 → 정비소 약 30~40초씩). "느린 차"가 불만("I feel like a snail", 5:12). 팔 때도 운전해서 감. 시운전 평가 없음.

**도감**: 영상에서 못 봄(버튼은 있을 수 있음). 대신 **희귀 차 방송**: 채팅에 "[System] A rare car has appeared: ○○ — Chance 10%" 줄이 계속 뜸. [사진 fixitup_01]

**올라가는 느낌(레벨/해금)**: XP·레벨 표시 못 봄. 돈 = 진행. 폐차장 안에 **순위판 4개(Time / Sold / Money / KMs)**가 서 있음 [사진 fixitup_08]. 경매에 "확률표(75,000€ 50%, 150,000€ 7%…)"와 큰 경고 "PLAY AT YOUR OWN RISK – DON'T BLOW ALL YOUR CASH HERE! Auctions aren't for profit — they're only for rare cars!" [사진 fixitup_09]

- 5대, 22분에 **순이익 21,526**(영상 마지막 말). 한 대 평균 3~4분, 이익 1천~6천.

**③ 레벨·해금 간격/연출**: 숫자·빛 연출 거의 못 봄. "돈 + 희귀 차 방송 + 순위판"이 전부. 해금 개념이 약해서 "다음 목표"가 흐릿함.

**④ 손맛**: 부품이 **물리 물체**라 튀고 겹침(재밌을 때도 있지만 대부분 불만). 들고 옮기는 건 아바타가 팔로 듦(Roblox 기본). 씻기 싱크는 "깨끗해짐"만. 카메라는 아바타 뒤 근거리 3인칭이라 후드 안이 잘 안 보임. 손에 도구를 쥐는 칸은 아래 가운데 도구 슬롯 하나(렌치 모양).

**⑤ 그림체·색·글꼴·UI**
- Roblox 기본 아바타 + 녹슨 질감(주황·파랑 얼룩)이 입혀진 실사풍 차. 정비소는 회색 콘크리트, 파란 2주 리프트 + 노란 팔, 붉은 배터리 충전기. 거리는 벽돌·회색.
- UI = 어두운 곤색 판 + 주황 머리글("CONFIRMATION") + 초록 CONFIRM / 빨강 CANCEL. 글꼴은 가는 대문자, 작아서 읽기 힘듦. 화면 사진 [fixitup_04, 08].

**수익화(화면에서 본 것)**: 코드 입력(6:54), 경매 확률표(도박성). 게임 패스 팝업은 못 봄. 한 영상(Camodo)에서 가진 돈이 33k → 365k까지 늘어나는 동안 유료 팝업은 못 봄.

**조명/색 분위기**: 흐린 하늘 + 차분한 회색 정비소. 녹슨 주황 차가 유일한 색 포인트라 "고치면 달라 보임"은 잘 보임(녹 → 깨끗 → 도색 전환).

**따올 것**
- 정비소 작업대에 **"WAITING FOR PART" 팻말**: 어디에 뭘 놓을지 월드가 알려 줌(우리 부품 놓는 칸 안내로 좋음).
- 폐차장 안에 **순위판**(Time / Sold / Money / KMs) — 친구끼리 비교 거리.
- **희귀 차 방송 한 줄**("A rare car has appeared") — 우리 시대 차 가끔 등장과 맞음.
- "팔기 전 확인창"(차 이름 + 값 + CANCEL/CONFIRM) — 한 줄로 단순.
**피할 것**
- 부품이 물리로 날아다님(부품이 어디 갔는지 모름) — 우리는 제자리 놓기.
- 키 8줄 상시 표시, 채팅 줄 상시 표시.
- 첫 돈이 5분 40초 늦음.
- 진단이 없음(그냥 "Condition %") — 우리 진단은 강점으로.
- 경매 = 확률 도박(어린이 많은 게임에 위험).

## 2. Car Dealership Tycoon (CDT)

**영상**
- 주: https://www.youtube.com/watch?v=cvIOIzKhBvQ — "Broke to RICH in Car Dealership Tycoon! (Roblox)" (Quacks, 28분 49초, 조회 17만, 1년 전)
- 지금 상황 확인(제목·조회수만): "ALL 50 CRYSTALS LOCATIONS IN CDT! … HALLOWEEN EVENT 2026" (1.6만, 2일 전), "Buying The Best Car For 10 Million Dollars!"(237만, 3년 전) = 아직 살아 있는 인기 게임. 차 사진에 **"SEASON 14"** 표시.

**핵심 한 바퀴**: 돈 4,500으로 시작 → 쇼룸에 플랫폼(전시대) + 차 한 대 사기(전시만 해도 돈이 들어옴) → 맵을 운전해서 돈(마일당) → 손님이 오면 색·휠·스프링을 골라 팔기(약 4천) → 배달 일(몇 마일 운전, 큰돈) → 번 돈으로 건물(벽·바닥·지붕·계단·화장실·주방·가로등)과 더 비싼 차 → 목표: 1천만 달러짜리 슈퍼카.

**화면 구성(HUD)**
- 위 가운데: 돈 알약 + 초록 "+"(돈 사기) + 아이콘 4개 + 별. 왼쪽 세로 둥근 아이콘 6개(번호 배지). 아래 가운데 **"INCOME: $xxx" 막대(26% → 90% 차오름)** + 가방·물음표·망치. 오른쪽 아래 퀘스트 칩("Complete the quest to unlock hu…"). 운전 중엔 속도·주행 마일. [사진 cdt_01, 02]
- 비교적 정리돼 있고 숫자(돈·소득)가 크고 한눈에 보임.

**차 정보 판**: 차마다 **Class(등급) / SPEED / HANDLING / DRIVETRAIN / REWARD / PER MILE** 6칸 + 큰 가격 버튼 [사진 cdt_04, 05]. 상점은 "Owned" 필터·검색·카테고리 탭 8개(차·비행기·집…).

**부품 떼기·진단**: 없음(차를 고치는 게임이 아님). 손님 응대 = 색·휠·스프링 "커스터마이즈 후 FINISH" 한 번. [사진 cdt_03, 06]

**운전/시운전**: **게임의 중심.** 운전으로 돈(마일당 $2,500 같은 숫자가 큼), 배달 일, 레이스. 운전하다 길 잃으면 쇼룸이 어딘지 몰라 헤맴("I have no clue where my dealership is", 1:06). 속도계·마일 표시 [사진 cdt_01].

**도감**: 직접 도감은 못 봄. 대신 **Garage 카드**(차 이름·등급·스펙·사기 가격·색/공구/엔진 3아이콘) + 상점 "Owned" 표시 = 컬렉션 느낌. [사진 cdt_05]

**② 한 번의 일**: 손님 한 명 = **약 20초**(말 걸기 → 색 → 휠 → FINISH), 이익 약 4천. 배달 = 1~2분, 후반 $28k. 운전은 마일당 수백~수천(자동 소득).

**③ 해금 간격·연출**: 처음 7분 동안 **30~60초마다** 새 해금(플랫폼 → Class 2 → 벽 → 지붕 → 2층 → 계단…) → 이후 1~2분. 연출 = 건물이 **월드에 실제로 생김**(벽·바닥이 올라옴), "INCOME" 막대가 차오름, 숫자 팝업("+$300"), "% 완성" 표시. 시즌 번호·퀘스트 칩.

**④ 손맛**: 손동작은 거의 없음. 손맛 = "산다 → 바로 월드가 바뀐다 → 돈이 흐른다". 손님 응대는 속도전.

- 보통 차: 한 바퀴 약 3분(부품 5~6개) + 흥정 15초~1분.
- 새 사람(비교 영상): 폴크스바겐 0:45 구입 → 휠 1:01~1:57 → 엔진 2:07~3:19 → 매니폴드 3:22~3:39 → 배터리 4:03~4:14 → 변속기 깜빡 4:31 → 도색 4:50~5:25 → 판매 6:35 = **약 6분**(첫 판).
- 정비소 작업 = 부품마다 **10~40초 미니 작업**.

**③ 해금 간격·연출**: XP는 못 봄. **돈 문턱**으로 열림: 휠(약 $40k, 4분) · 전문 정비소/중형 차고 $400,000 · 럭셔리 구역(잠김) · 차 등급 Tier 1~5(Tier 4~5는 'Mr. Lupin'에게만 팔 수 있음) · 업데이트 카운트다운("update in 3 days"). 연출 = 판매 때 **초록 지폐가 화면에 쏟아지고 "Sold your car for $14,600!"** [사진 jm_03], "PART REPAIRED" 표지, 선 따라 진행 막대, 입구마다 GPS.

**④ 손맛(이 게임의 핵심)**: 모든 부품에 **다른 손동작** — 문지르기(싱크·닦기), 드래그(분쇄·호닝, "Hold Left Click and drag over each glowing seam"), 집게 꽂기, 휠 기계 + 슬라이더, 스프레이. **진행 막대(%)가 항상 보여서** "얼마 남았나"가 즉시. 끝나면 초록 표지가 '탁' 서고 숫자가 오름. 단점: 모든 부품이 "기계에 넣고 드래그"라 비슷해질 위험(비교 영상 "grinding machines don't have one"과 같이 일부는 단조).

**⑤ 그림체·색·글꼴·UI 품질**: 정비소 = 어두운 산업 톤(다이아 무늬 바닥, 빨간 공구함, 파란 리프트, 스포트 조명) + 낮의 지도는 선명. **차 = 광택·플레이크 도색의 하이폴리 임포트 모델**(비교 영상: "imported models, 그래도 멋있다"). 아이콘은 입체 일러스트(빨강 카트·주황 상자·파랑 책·초록 할일), **견적 패널은 '나무 클립보드' 질감**. 글꼴은 굵은 대문자 + 초록 돈 숫자 + 흰 글자에 검은 윤곽. 도색 화면: 왼쪽 재질 4개(Default / Flake $500 / Matte $250 / Metal $400) + 오른쪽 색 판 + HEX + 큰 초록 $750 버튼. [사진 jm_05, 07]

**수익화(화면)**
- **Starter Pack(한정 시간) 알림 — 약 4분**에 처음 나옴 [사진 jm_03].
- **59 Robux 상자(돈 39k~79k 또는 폐차장 차 — 슈퍼카 포함)** + 게임 돈으로도 같은 뽑기. 진행자: "pay to win"이라 부름.
- **VIP = 팔기·운전 돈 +10%**, 휴대 잭 패스, 더 큰 인벤토리, 경매 한정 차(GT3 RS), 이벤트·"업데이트 3일 뒤".
- 돈 옆 초록 "+" 버튼.

**견적 클립보드(★)**: 팔 때 나무 클립보드 한 장에 **부품 이름 + 상태 % + 값**(Cylinder Head 100% $2,000 / Engine $4,500 / Transmission $4,600 / Rims $1,200 / Paint $250), **TOTAL OFFER $19,013**, **DECLINE RISK 39%**(거절 위험), **남은 시간 00:29**, ACCEPT / DENY. [사진 jm_05] — **"부품이 모여서 차 값이 된다"**를 한 장으로 보여 줌. 우리 "오늘의 영수증"과 같은 뜻.

**조명/색 분위기**: 정비소 어둡고 대비 강함(스포트 + 반짝임). 지도는 맑은 하늘. 우리 정비소(약간 밝게 → 다시 약간 낮춤)와 비슷한 "어둑한 작업장 + 밝은 차".

**따올 것**
- **왼쪽 세로 큰 버튼 4개**(상점·보관함·도감·할일) — 일러스트 아이콘. 한눈에 정돈.
- **화면 아래 한 줄 안내 + 핵심 낱말 노랑 + 목적지 윤곽선 + 초록 점선 GPS**.
- **견적 클립보드**(부품별 값 + 합계 + 거절 위험 + 남은 시간).
- **부품마다 '진행 막대 %' + "PART DONE" 초록 표지**.
- **판매 때 지폐 쏟아짐 + "Sold for $X!"**.

- 도색 화면(재질 4 + 색 판 + HEX + 큰 가격 버튼) → 내 차 애착.
**피할 것**

- **상자 뽑기 + 게임 돈 도박**(어린이·친구 서버에 위험, 사용자 방향 "친구끼리").

## 6. 우리 게임이 이 게임들보다 부족해 보일 곳 (짧게)

(우리 규칙인 "진짜 구조·부품 전부 따로·맞는 공구·캐주얼 그림"은 오히려 **CMS급 깊이 + Roblox식 화면**이라 강점. 아래는 강점 밖에서 부족해 보이는 것.)

1. **첫 2분 안의 '번 돈'**: 라이벌은 0:40(JM)·0:57(CDT)에 돈이 들어옴. 우리 첫 보상 시간은 (확인) — 늦으면 10분 안에 떠남.
2. **한 번에 끝나는 짧은 일**: JM 한 바퀴 2~3분, 부품 하나 10~40초 + %막대. 우리 한 대가 길거나 '막대(%)'가 없으면 느리게 느껴짐 (확인).
3. **손동작 종류**: JM은 닦기·드래그·집게·휠 기계·스프레이로 다양. 우리는 공구가 다양하지만, 손동작 종류(문지르기/드래그)가 적으면 반복처럼 보일 수 있음 (확인).
4. **돈이 눈에 보이는 성장으로 안 바뀜**: CDT는 산 만큼 건물이 올라오고 "% 완성". 우리 "정비소가 자란다"는 설계뿐 (코드 없음).
5. **바깥 세상(시운전·미니맵·도감 버튼)**: JM·CDT는 운전·미니맵·인덱스가 처음부터 있음. 우리는 시운전·도감 설계만 있음(코드 아직).
6. **사는 사람**: JM은 이름 있는 NPC 여러 명(Juan·Rick·Lupin)·흥정·등급별 전문가. 우리 NPC 다양화는 공개 뒤 목록.
7. **내 차 꾸미기**: JM의 도색 화면(재질 4 + 색 판 + 가격) = 애착. 우리가 도색만 있고 고르는 화면이 약하면 정이 덜 감 (확인).
8. **정산 연출**: JM은 지폐가 쏟아지고 "Sold for $X!", CDT는 "+$300". 우리 정산 카드 연출이 조용하면 약해 보임.
9. **업데이트 예고·이벤트**: CDT 할로윈 크리스털 50개·시즌 14, JM "업데이트 3일 뒤"·경매 한정 차. 우리는 호박차(10/30)가 같은 역할 — 예고 표시가 있으면 좋음.
10. **영상 거리**: JM은 광고 + 인플루언서 영상 다수. 우리 첫 장면(썸네일·첫 30초)이 영상으로 보여 줄 만해야 함.

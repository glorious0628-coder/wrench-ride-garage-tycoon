**가장 큰 발견 3가지**
1. Junk Mechanics는 "진단"이 얕다 — 부품 상태 %를 보고 기계에 넣으면 100%가 됨. **고장 원인 추리(소리·색·누수 단서 → 맞는 공구로 확인)는 우리가 훨씬 깊게 갈 수 있는 자리.** 반대로 **안내(하이라이트·한 줄·화살표)와 손님 정산 화면은 JM이 우리보다 앞섬.**
2. My Summer Car는 "진짜 구조를 만지는 기쁨"이 큰데, 같은 이유로 **초보는 첫 1시간을 헛수고**함(퓨즈가 필요 없었는데 사러 감, 샤워 켜는 법을 몰라 헤맴). 우리는 **그 기쁨은 가져오고 헛수고는 끊어야** 함 → "지금 할 일 1개 + 맞는 부품만 빛나기".
3. Gas Station Simulator의 **'과제 → 완료 팝업 → 큰 목표 → 레벨업 → 새 칸 해금'** 흐름이 우리 목표 "정비소가 자란다"와 가장 잘 맞음.

## 1. 조사 방법과 한계 (꼭 읽기)

- 영상은 YouTube. 각 게임마다 영상 2~6편을 열고, 영상 아래 **'스크립트'(자동 자막)를 통째로 읽어** 시간·가격·순서를 뽑았고, 같은 시각 화면을 **프레임으로 확인**함. (자막만 믿지 않고 화면으로 맞춰 봄. 예: 흥정 화면 숫자, 부품 이름표.)
- **소리는 못 들음.** 효과음·배경음 평가는 못 했고, "손맛" 칸의 소리는 말하는 사람의 말(자막)로만 추정. → 소리는 사람이 직접 한 번 들어봐야 함.
- 영상 중간 광고 프레임 몇 장이 섞였고(분석엔 제외), 광고는 누르지 않음. 로그인·다운로드·쿠키 동의 없음.
- **브라우저 사정:** 내장 브라우저 창을 다른 세션(A조 도우미 등)과 같이 써서 내 탭이 자주 닫히고(여러 번), 내가 앞으로 가져오면 그쪽 명령이 내 탭에 들어가는 일이 있었음. Chrome 확장은 연결이 안 됨. 그래서 **영상마다 빠르게 열어 자막+프레임을 한 번에 뽑는 방식**으로 함. 시작할 때 실수로 **다른 세션 탭('seed')의 재생 위치를 한 번 바꿨고**, 그 탭에서 읽기 전용으로 YouTube 검색 글만 몇 번 불러옴(그 탭 화면은 안 건드림). 필요하면 그쪽 세션에 알려주세요.
- "수첩(notebook) 목록 화면"은 영상에서 목록 전체를 못 봄. 부품을 누르면 뜨는 **이름표(부품 이름 + 상태 %)**만 확인함. 수첩은 "한 차의 모든 부품과 상태 목록"으로 보임(말로 확인: "수첩에 라디에이터가 없다", "수첩에 아직 안 고친 게 한가득").

### 2-6. 부품 떼기 · 공구 · 진단

- **도구 순서:** 수첩(보기) → 렌치(떼기) → (부품 들고) 기계로 → 기계 종류마다 미니 동작.
- **하이라이트:** 다음 부품이 **빛남**. 안내 한 줄 "**빛나는 라디에이터를 눌러 떼세요**" [JM_18], "손상된 변속기를 **빛나는 연마기**로 가져가세요" [JM_17], 바닥엔 흰 **쉐브론 화살표 길** [JM_19].
- **부품 이름표:** 부품을 누르면 작은 상자에 **이름+사양+상태 %**(예: "Cylinder Head L4 / 100%", "Transmission 5") [JM_09, JM_12]. 100%인 부품에 또 하면 파란 글씨 **"이미 완벽한 상태예요"**, 고치면 초록 글씨 **"…고쳤어요"** [JM_14].
- **기계별 동작:**
  - 연마기: 부품을 올림 → 자동/짧은 동작 (엔진은 연마기에 안 들어감: "Grinding machine cannot process L4").
  - **엔진 용접대:** "**빛나는 이음선 위를 꾹 누르고 끌기**" + **진행바 %** [JM_20]. 요령: 이음선 5~6개를 한 줄로 쭉 끌면 한 번에 됨.
  - 라디에이터: 싱크대에서 **좌우로 빠르게 문지르기**.
  - 배터리: **집게 두 개 끌어 붙이기** [JM_04].
  - 휠: 휠 머신에 올리고 **림 크기 슬라이더**(예: 67) → 조립 → 볼트를 **눌러서** 풀기. TireZone에서 "림 몇 개 살래요? **$600 / 2개**, 녹슨 건 1개뿐이니 − 눌러 1개만" **작은 힌트** [JM_21].
  - 엔진 호이스트, 유압 리프트("아래 프롬프트로 차 내리기").
- **큰 차 특징(E):** 미드십 차는 **뒷범퍼를 렌치로 떼야 엔진이 보임**. 엔진 스왑(직렬6 → V6 "맞는지 보자")도 됨. 즉 **차마다 구조가 다름**은 있음.
- **진단은 얕음:** 상태 %를 보고 기계에 넣으면 끝. 소리·색·누수 같은 **단서로 고장을 추리**하는 건 없음 → 우리의 차별점.
- **제한/막힘:** 바닥 부품 90초 후 삭제, 바닥에 부품 **최대 8개**, 인벤토리 가득이면 못 담음(C 14:16), 부품 하나 빠뜨리면 **차가 안 굴러감**(B 4:31, A 6:41) — 이게 영상에서 제일 많이 헷갈린 곳.

### 2-7. 손맛 (영상으로 본 것 + 자막에서 추정)

- 카메라는 3인칭, 미니 동작 때는 **부품 클로즈업**으로 바뀜 [JM_20]. 마우스 드래그가 거의 전부(폰이면 손가락 드래그).
- 말하는 사람들 반응: "**이거 시원하다**"(청소), "**Powerwash 느낌**", "에어브러시 칠하기 괜찮다", "엔진 용접 와 이거 미쳤다". 반대로 "부품 하나씩 하는 건 현실이면 훨씬 힘들 텐데 이건 너무 매끈하다"(A 15:49).
- 효과음/진동은 **못 들음**. 시각 보상은 확실: **초록 글씨 + 진행바 + 부품이 반짝 + 돈 숫자 오름**.

### 2-8. 운전·시승

- 운전은 **돈을 줌**(처음 약 $10/초, 빠르면 2초마다 $32 정도). 하지만 사람들은 "느리다, 핸들링 별로"(C 4:35).
- 속도계(km/h + 기어 1st), 속도 시험(E 5:46: 214~218 km/h) 같은 **재미로 몰아보기**는 있음. **시험 주행으로 고장을 알아내는 요소는 없음.**

### 2-9. 도감(Index)

- 왼쪽 **INDEX** 버튼 → 격자에 **까만 실루엣 + 물음표 + 이름**, **틀 색이 등급**(보라, 금색 등) [JM_03], 아래쪽에 **진행 "2/32"**.
- 맨 아래(희귀)가 **먼저 눈에 띄어서 "와 갖고 싶다"**를 만듦(A 4:15) = 장기 목표 역할.
- 티어 색(말로 확인): 티어1 = 흰/회색 계열, 티어2 = 보라, 티어3 = 파랑, 4~5 = 금색(추정).

### 2-10. 판매 · 흥정

- **구매자 여러 명:** Juan(일반, 좋은 값), **Rick(경매장 즉시 판매, 값 낮음 — "이익 없음")**, Lupin(럭셔리, 티어 4~5만, 값 제일 좋음), Ashley/Riley(번호판 가게 등).
- **클립보드 정산:** 부품 줄(이름 / 상태 % / 가격) → **TOTAL OFFER $19,013** → **DECLINE RISK 29%** → 버튼 **수락(초록)·흥정(주황)·거절(빨강)** + 위쪽에 **남은 시간 00:32** [JM_07, JM_10].
- 흥정: 누르면 값이 오르고 **위험 %**가 오름. **너무 밀면 −$500~−$1,000에 처음 제안으로 돌아감**, 한 번 더 해도 안 됨. 제안은 약 **60초마다 갱신**.
- 사람들 말: "Juan이 항상 화난 얼굴(웃김)", "흥정이 은근 중독".

### 2-11. 진행 · 해금 · 연출

- 레벨 숫자 대신 **돈·티어·잠금**으로 단계를 느끼게 함: 럭셔리 구역 잠김 / 특별·중형 정비소 **$400,000** / 도감 잠긴 차 / 티어 3+ 차는 **서버 채팅 공지**.
- 해금 간격: 처음 $13k → 스타터팩 후 $40k → 약 $80k에서 벽(10분) → 영상 말로 "진행이 너무 느리다"(A 10:57), 사람들이 **기지/자동 수익** 같은 걸 원함.
- 업데이트: **카운트다운 게시판**(21:27:10) + 업데이트 로그(5대 신차, 경매, 알바, 버그 수정) + "**가입 시 $5,000**"(알림 신청으로 보임, 확인 못 함) [JM_05]. F: 새 차 + **카 비드(1시간마다 플레이어끼리 경매, 럭셔리 쪽)** + 떼는 문 + 언더글로우 + 프리미엄 경매(제작자 혜택 키 주 8회) + 코드(bids!)로 돈.
- 연출: 부품 고침 = **초록 글씨**, 판매 = **큰 숫자**, 서버 공지, 도감 색 틀.

### 2-13. 분위기 · 그림체 · 글꼴

- 그림체: **반사실**(차는 실제 모델 느낌, 영상 B 말로 "수입한 모델 같지만 괜찮다", "Driving Empire보다 덜 만화적"). 정비소는 **어두운 회색 철판 바닥 + 빨간 공구함 + 파란 리프트 + 노란 팔**(정비소의 정석 색), 야외는 **모래색 + 푸른 하늘 + 야자수**.

### 2-14. 따올 것 (우리 규칙에 맞는 것)

2. **부품 이름표(이름+상태 %)**, 100%는 "이미 새것"으로 재수리 막기 [JM_09]. (S, 공개 전)
3. **클립보드 정산**(부품별 줄 + 합계 + 수락/흥정/거절 + 거절 위험 % + 짧은 타이머). 우리는 **흥정 1번 + 위험 숫자**만. (M, 공개 전)
4. **끌기 동작 3종**(문지르기·이음선 따라 끌기·집게 끌어 붙이기) + 진행바 [JM_20, JM_04]. (M, 공개 전)
5. **도감**(실루엣+?, 틀 색 = 등급, "n/N" 진행) [JM_03]. (M, 공개 뒤 — 시대 차와 연결)
6. **정비소 구역 이름**을 길 위에 표지로(Nando's repair, TireZone, Paint) + 미니맵 점. (S, 공개 전)
7. **서버 알림**(희귀 차 도착) + 60초마다 새 차. (S~M, 공개 뒤)
8. **업데이트 로그 클립보드 + 카운트다운**. (S, 공개 뒤)

### 2-15. 버릴 것

- **유료 랜덤 경매 상자 / 게임 돈 도박**: 아이들, 불공정, 손해 느낌, 플랫폼 규칙(확률 공개 등 — **확인 필요**) → 버림. 대신 **보여주고 고르는 판매**.
- **오른쪽 키 안내 8~10줄**: 폰 화면 단순함 규칙에 어긋남.
- **공용 기계 줄서기**(기계 다 차면 멀리 이동): 친구끼리만 오는 서버라면 문제 적지만, 작업 기계는 **차마다 자기 자리**가 안전.
- **바닥 부품 90초 삭제·8개 제한**: 어린이가 실수하면 억울 → 우리는 **자리에 자석처럼 돌아오게**.
- **너무 느린 성장**("진행이 느리다") — 우리는 속도 약 10% 정도 섞는 정도만(사용자 10-21 결정).
- **한 글자 바꾼 진짜 브랜드 이름.**

### 2-16. 우리 게임이 JM보다 부족해 보일 곳 (솔직히)

- **안내**: 어디로 가야 하는지(GPS+화살표+한 줄)가 JM이 훨씬 친절함. 우리는 아직 화면 단위로만 정해 둠.
- **판매 쾌감**: 손님마다 값을 받는 정산 화면 + 숫자 연출이 JM에 있음.
- **차 종류·도감·경매·튜닝** 같은 **콘텐츠 양**과 **희귀차 설렘**(서버 공지).
- **우리가 더 나은 곳(지켜야 할 것)**: **진짜 구조 + 고장 진단 + 맞는 공구**. JM은 "기계에 넣으면 100%"라 얕음.

### 3-10. 분위기 · 그림체 · 글꼴

### 3-11. 따올 것

6. **보고서 종이 연출**(떨어지는 종이) — 정비 후 **영수증/보고서 종이**를 재밌게. (S, 공개 뒤)

### 3-12. 버릴 것

- **속임수 판매자와 거짓 정보로 손해 보는 설계** — 어린이에게 억울함이 큼. 우리는 **공정한 진단**.

### 4-4. 차 한 대(=전체 복원) 처리

- **70시간**(B). 순서(B 7:35~19:00): 서브프레임 → 조향 → 휠 → 브레이크 → **엔진(가장 힘듦)**: 크랭크 → 베어링 → 피스톤 4 → 헤드 → 캠 → 타이밍 체인 → 워터펌프 → … **약 45개** → 호이스트로 차에 넣기 → 전기·연료·라디에이터·배기 → 외장(문·펜더·범퍼) → 계기판·**배선** → 오일·냉각수·연료 → **시동 → 튜닝(귀로)** → **검사**(경고 삼각대 + 소화기 필요) → 랠리 부품(롤케이지, 레이싱 시트, 하네스).

### 4-5. 화면(HUD) — 가장 적음

- **왼쪽 위 노란 글씨 막대 6~7줄**: THIRST·HUNGER·STRESS·URINE·FATIGUE·DIRTINESS·MONEY [MSC_01]. **가운데 아래 작은 라벨 한 줄**("DASHBOARD METERS" 같은 **부품 이름**) [MSC_06]. 그 외엔 화면이 비어 있음. → **월드 쪽에 정보를 두는** 방식(참고할 만).
- 키 안내는 없음(어렵다는 말이 나옴).

### 4-6. 부품 떼기 · 공구 · 진단

- **볼트는 이미 박혀 있고, 맞는 렌치 크기를 갖다 대면 볼트가 초록으로 빛남**(B 4:39). → 우리 "**맞는 공구**" 규칙의 최고 참고. 틀린 크기면 안 빛남.
- **라쳇 모드(조이기/풀기) 스위치**를 꺼 줘야 함(B 16:31).
- **부품 눈 진단**: **피스톤이 더 어두우면 불량**(A 3:05), 시동 후 **고주파 딸깍 소리 = 튜닝 필요**, **딥스틱으로 오일 확인**(B 19:48).
- **카탈로그 주문 → 봉투 → 가게 → 전화 올 때까지 기다림(수 시간) → 찾기**. 우리는 짧게 줄여 쓸 수 있음.

### 4-7. 손맛

### 4-8. 운전 · 시승

- **1995 핀란드 늦여름**: 낮은 해상도 + 거친 그레인 + 초록·갈색, **밤은 아주 어둡고 안 보임**(A 21:25). 차 속은 거칠지만 **부품 구조가 진짜 차 같음** [MSC_04, MSC_05]. 글꼴은 **노란 작은 비트맵 느낌**.

### 4-12. 따올 것

1. **맞는 렌치 크기를 가져가면 볼트가 초록으로 빛남** — 우리 공구 규칙을 **눈으로** 보여줌 (그리고 틀린 건 안 빛나서 억울하지 않음). (M, **공개 전**)

6. **검사 통과 = 이벤트**(경고 삼각대·소화기 체크리스트) — '검사소 시험' 컨텐츠. (M, 공개 뒤)

| **수리 손님**(정비소 해금 뒤) | 차를 리프트에 올림 → **부서진 부품을 눌러 정보(LMB)** + **L-Shift로 부품 하이라이트** [GSS_08] → 부품 주문 → 교체 → 팁 | 1~3분(타이어는 가장 길다) |

### 5-5. 화면 · UI

- **왼쪽 위 돈(주황 동전 아이콘)**과 아래 **인기도 바**, **오른쪽 위 시계 + Day + Lv**, **오른쪽 현재 과제 상자**, **왼쪽 손님 목록("Customer at [FUEL] x1")**, **가운데 아래 미니게임 패널**, **오른쪽 아래 키 힌트 1~3줄** → **5~6묶음** [GSS_01, GSS_02]. 정보가 많지만 **같은 자리에 늘 같은 것이 있어** 배우기 쉬움.
- 색: **주황 머리글 + 어두운 반투명 패널**, 글꼴은 **좁은 고딕(DIN 느낌)**. 페인트 색 팔레트는 **레벨에 잠금("Gas Station Lv.2에 해금")** [GSS_03].

### 5-6. 부품 · 도구 · 진단 (정비소 칸)

- 정비소 해금 비용은 영상에서 확인 못 함(세차 부지는 **$1,000**). 부서진 **거울**: **옛 조각을 마우스로 뜯어내고 새 것 끼우기**(짧음), **타이어**: **애니메이션이 길어서 가장 긴 미니게임**(B 24:14). 손님 한 명이 타이어 3~4개 부서진 채로 옴.
- **부품 가격이 변함**(타이어 $30~$40) → **싼 날 사 두기** 전략(B 34:38).
- **직원(수리공)**: 직무 **1순위 = 차 수리 / 2순위 = 청소**, 시급 약 $13.58, **12시간 교대**, 직원은 **숙소(트레일러) 구입 필요** [GSS_09].

### 5-7. 손맛

- 주유 바늘 + 부스트 키 = 간단하고 **리듬감**. 계산 스캔 = **반복 노동**(규모 커지면 직원 필요). **청소 전/후가 눈에 띄게 좋아짐**("이제 깨끗!"), 페인트 롤러로 **색 고르기**.
- 사람들 말: "벽을 칠하다가 줄 선 손님을 잊음"(B 21:20), "**색을 매번 다시 고르는 건 번거롭다**"(A 36:30).

### 5-8. 운전·시승

- 운전 없음(손님 차만 옴, 굴착기·트럭만 탐). 시승 없음.

### 5-9. 수집 · 진행 · 해금 간격

- **레벨 1→2:** 삼촌 대출 갚고 창고 열쇠 → 크기 **약 2배**(B 12:10~12:31, 영상 **12분쯤**). **창고 레벨**도 따로.
- **레벨 3:** 과제 **"주유 11대 + 가게 손님 25 + 수리 5대"** + **$750**(B 25:41~26:24, 영상 **26분쯤**).
- **레벨 4:** **"주유 45 + 수리 10 + 팁 40 + 가게 손님 100"** + **$1,500**(B 38:23). **레벨 5(마지막)** 있음.
- **인기도**(팁 + 청결로 오름): 레벨 2 → 3 → 5 → 6(B 17:28, 19:13, 26:16, 37:54). 인기도가 높으면 **손님 수가 늘어남**.
- 매 레벨 **새 페인트색 · 선반 · 주차칸 · 창고 · 정비소 · 세차($1,000) · 화장실**이 열림 → **눈에 보이게 정비소가 자람**.
- 연출: **"Task complete" 팝업**, **업적 알림**, 인기도 레벨업 안내, **이벤트**(모래폭풍 → 모래 언덕이 길을 막음, **낙서범 Dennis**를 물건 던져 쫓기, 외계인).

### 5-10. 돈벌이

- Steam 유료. 앱 안 결제 없음. (삼촌의 **대출 + 마감 + 협박 연출**이 압박 장치.)

### 5-11. 분위기 · 그림체

- **루트 66 사막, 노을색 따뜻한 조명**, 먼지, **나무 판자 실내 + 선풍기 + 철제 선반**. 처음엔 **어둡고 더러워서**(파리·쓰레기) → 청소할수록 **밝고 따뜻**해지는 **변화 보상**이 큼 [GSS_04, GSS_06]. NPC는 **어색하게 웃긴 모델**(영상 사람들이 계속 놀림).

### 5-12. 따올 것

1. **'현재 과제' 상자(제목 + 힌트 한 줄) + 2~3분마다 완료 팝업** [GSS_01] — 튜토리얼과 장기 목표를 **같은 틀**로. (S~M, **공개 전**)
2. **레벨 올릴 때 숫자 과제 + 비용**("차 5대 수리·손님 25명·$750") — "정비소가 자란다" 목표와 맞음. (M, 공개 전)
3. **인기도**(청결 + 서비스 팁 → 손님 수) — 우리 "**오늘의 영수증**"과 연결. (M, 공개 뒤)
4. **부품 하이라이트 키 + 부서진 부품을 누르면 정보** [GSS_08] — 진단 도움을 **버튼 하나로**. (S, 공개 전)
5. **청소·페인트 전/후 변화** — 정비소가 **깨끗해지면 밝아지는 연출**. (M, 공개 뒤)
6. **레벨에 잠긴 색 팔레트("Lv.2에 해금") 표시** [GSS_03] — 잠금도 **보여 주면 목표가 됨**. (S, 공개 뒤)
7. **직원(자동 도우미) 고용**과 직무 우선순위 [GSS_09] — 친구가 못 올 때 도우미. 단 **교대·숙소는 버림**. (L, 공개 뒤)
8. **메일(우편)로 튜토리얼 팁** — "삼촌의 메일"처럼 이야기와 팁을 한 곳에. (S, 공개 뒤)
9. **가벼운 이벤트**(모래폭풍, 낙서범 쫓기) — 일정이 단조롭지 않게. (M, 공개 뒤)

### 5-13. 버릴 것

- **삼촌 빚 마감·협박**(못 갚으면 "총" 연출) — 어린이에게 부적절, **실패=처벌**. 대신 부드러운 목표.
- **가게 열기 오류**: 문 앞에서 손님이 그냥 돌아감(A 41:00) — "왜 안 사지?" 억울함.
- **12시간 교대·직원 숙소 구입** 같은 복잡 경영.
- **너무 긴 타이어 애니메이션**(B 24:14). 반복 길이가 **10초**를 넘으면 지루.
- **손님 목록이 길어짐**(왼쪽 "Customer at …" 줄이 늘어남).
- **계산 스캔 반복 노동**(규모 커질수록 직원 필요) — 우리는 **손님 1명씩 단순**.

### 5-14. 우리 게임이 GSS보다 부족해 보일 곳

- **눈에 보이는 성장**: 새 건물·새 기계·새 색이 **레벨마다 쏟아짐**. 우리는 "정비소가 자란다"를 아직 눈에 보이게 계획 안 함.
- **이벤트(모래폭풍·낙서범·외계인)와 업적**의 가벼운 재미.
- **인기도 + 수치 목표**로 "지금 내가 잘하고 있나"를 알려주는 점.
- 우리가 더 나은 곳: **부품을 진짜 구조로 직접 떼고 진단**(GSS 정비소는 거울·타이어 교체 위주로 얕음).

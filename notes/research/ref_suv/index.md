## 섞기 표 — 차마다 한 가지씩 (대표 얼굴은 피함)
| 차 | 가져오는 특징 | 안 가져오는 것 (그 차 얼굴) |
|---|---|---|
| Toyota RAV4 | **검은 플라스틱 아랫단·바퀴 둘레 덮개(cladding) + 각진(사다리꼴) 바퀴 아치** | 팔각형 두 겹 앞모양, 두 단 사다리꼴 그릴 |
| Honda CR-V | **지붕 레일 2줄**(검정), 길고 수평인 옆창 줄 | H 로고 그릴, 세로 크롬 바 |
| Chevrolet Equinox | **높고 평평한 보닛 + 서 있는 네모진 앞 끝**(보닛 앞선이 높음) | 가로 빛 띠 + 나비넥타이 그릴, 투톤 흰 지붕 |
| Hyundai Tucson | **지붕 끝 뒷유리 위 스포일러** + 리프트게이트 와이퍼 | 숨은 보석 주간등(Parametric Hidden Lights), T자 테일램프 |
| Nissan Rogue | **검정 D필러(떠 있는 지붕)** — 세단의 검정 C필러와 같은 '가족 표시' | V자 그릴, 2단 램프 |
| Mazda CX-5 | **뒷유리가 앞으로 살짝 누운 리프트게이트**(완전 세로 상자 X) | 날개 그릴(시그니처 윙), 가는 눈매 램프 |
| 우리 세단(가족 느낌) | 얇은 가로 헤드램프 + **곧은 가로 빛 띠**, 사다리꼴 아래 흡기구, 5스포크 은색 휠, 같은 그림체 B(무광·둥근 판) | — |

## 크기 (wr-carbook suv.md §2 게임 권장 — 실제 4대 평균 기준)
- 길이 **16.6**, 폭(거울 빼고) **7.7**, 높이 **6.6**, 휠베이스 **9.7**, 지상고 **0.7**, 타이어 **2.6 / 1.0**, 림 1.55 stud.
- 길이 : 폭 : 높이 = **2.52 : 1.17 : 1** (세단 2.93 : 1.31 : 1 → 더 높고 짧아 보임).
- ⚠ car_roster §2-1은 '길이 약 −1.5 stud'(≈15.5)라고 적혀 있어 suv.md(16.6, 실제 평균)와 달라요 → **그림은 suv.md 16.6**으로 그렸고 wr-design에 확인 부탁.
- 속: 세단과 같은 가로배치 I4 FF 엔진룸 배치(RAV4는 Camry와 같은 TNGA-K) → 엔진룸 위 시점은 세단 `sedan_enginebay_top.png` 기준 그대로. AWD 판의 프로펠러 샤프트·뒤 디퍼렌셜은 6면 아래 뷰에서.

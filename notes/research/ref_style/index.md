## 사용자 그림체 기준 (10-20, 메인 정정본)
- **차체도 부품도 전부 같은 캐주얼 그림체**(단순·깨끗한 모양, 읽기 쉬운 색). 부품만 실사로 그리지 않음.
- '제대로' = **구성**: 실제 차 부품이 실제 자리에 빠짐없이(엔진·배터리·라디에이터·호스·디스크+캘리퍼·쇼바·머플러…), 하나하나 뭔지 알아볼 수 있게.

## 공통점 — Roblox 차 게임 (01~03)
1. Roblox 인기 차 게임(Car Dealership Tycoon, Greenville, SWFL)은 **차만 실제 차 비율의 매끈한 메시**, 맵·아바타는 블록. 블록 아바타 옆에서도 차가 어색하지 않은 건 **차를 실제 비율로 두고 디테일만 덜어서**.
2. 색은 **밝고 채도 있는 단색 페인트**(빨강·파랑·노랑·흰), 반짝임은 있지만 반사가 단순. 먼지·때 거의 없음.
3. Roblox 정비 게임(03)은 차가 **더 단순한 덩어리**(블록·과장), 리프트 기둥은 원색(빨강·파랑·노랑), 엔진룸은 대개 거의 비어 있음 → **우리가 이길 곳 = 캐주얼한데 엔진룸이 꽉 찬 것**.
4. 화면이 '읽히는' 이유: 큰 단색 면 + 굵은 형태 + 또렷한 부품 경계. 작은 질감보다 **모양과 색 대비**.

## 공통점 — 캐주얼 차 그림체 (04~05)
1. 캐주얼 세단 = 실제 세단 구조(보닛·캐빈·트렁크 3박스, 문 4개)는 그대로, **모서리를 둥글게, 바퀴를 조금 크게, 판을 통통하게**.
2. 과하면(04의 짧고 땅딸한 '치비' 차) 장난감 → 사용자 기준 "과한 장난감 X"에 걸림. 비율은 실제에 가깝게, 조금만 둥글게.
3. 05의 '보닛 열린 캐주얼 차' 일러스트: 엔진룸 부품도 같은 매끈한 그림체로 단순화했지만 **색과 모양으로 구분**(검정 엔진 커버, 은색 금속, 반투명 통, 빨강 단자). 이게 우리 방향.

## 부품 구성 기준 (06, 실사 PC 게임)
- Car Mechanic Simulator류는 부품이 실사. 우리는 **같은 부품 목록·자리**만 가져오고 그림체는 캐주얼로.

## 3안 방향 (캐주얼 정도만 다르게, 셋 다 엔진룸 꽉 참)
- A = 깔끔한 캐주얼: 실제 비율 그대로, 매끈한 면, 디테일 덜어냄(Roblox 인기 롤플레이 차 느낌).
- B = 통통한 캐주얼: 모서리 더 둥글게·바퀴 살짝 크게·판 두툼하게, 부품도 굵고 단순(읽기 쉬움 최우선).
- C = 로우폴리 캐주얼: 각진 면(파셋)·평평한 색 면·그러데이션 없음(인기 로우폴리 에셋 팩 느낌). 비율은 A와 같음.
- ("과한 장난감 X" 기준이라 04의 땅딸한 치비 비율은 3안에서 뺌.)
- 배경: 서양권(미국식 동네 정비소: 롤업 셔터·파랑 2주 리프트·타공판 공구 벽·빨간 공구함), 글자 X.

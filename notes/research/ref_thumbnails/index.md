## 왜 눈에 띄나 — 공통점
| 항목 | 인기 썸네일 | 우리 옛 4장(`final/`) |
|---|---|---|
| **주인공 크기** | **하나가 화면 40~70%**(차 한 대·펫 얼굴·캐릭터). 작은 카드(265 px)에서도 한눈에 '무엇'인지 | 차 + 바닥 + 벽 + 공구 다 같은 무게 — 바닥이 넓음 |
| **이야기(전·후)** | 정비·청소 게임은 거의 다 **고장/더러움 → 새것**(Car Flipper 3장, Junk Mechanics #4, Car Wash, Repair a Car, Fix my phone) — 한 장에 '이 게임에서 뭘 하나'가 보임 | 멈춘 장면(일하는 순간 X) |
| **캐릭터** | 30장 중 약 절반에 나옴. 대개 **일하는 자세**(광내기·엔진 보기·차에 기대기), 높이 40~60%. 표정을 크게 쓰는 건 소수(Sell Fries) — 큰 얼굴은 **아이콘** 쪽이 주로 씀 | 캐릭터 없음 |

## 로블록스 공식 규칙 (직접 읽음)
출처: ① https://create.roblox.com/docs/production/publishing/thumbnails (Thumbnails 문서, 10-22 읽음) ② https://about.roblox.com/community-standards → '무결성 › 반복적이고 오해의 소지가 있는 콘텐츠'(Spam and Misleading Content).

**규격**: 16:9, 가능하면 1920×1080(그 이상 X — 홈 페이지 올리기 칸은 3 MB·1920×1080 아래), jpg/png/gif/tga/bmp. 16:9가 아니면 늘려서 보임. 최대 10장(이미지·영상), **2장 이상 켜면 홈 화면 개인화**(사람마다 잘 먹히는 썸네일을 보여 줌 — 테스트 평균 질 좋은 플레이 +8.5%). 큰 업데이트마다 새 썸네일 몇 장 넣고 여러 장 켜 두기를 권함. 모든 썸네일은 커뮤니티 규칙·이용 약관으로 **검토됨**.

| 할 수 있는 것 | 안 되는 것 |
|---|---|
| 게임의 **특징을 보여 주기**, 업데이트·이벤트 알리기(문서 첫 줄) | **게임에 없는 놀이·UI·장면**(문서 영상 규칙 'Misrepresented Gameplay' — 롤플레이를 레이싱처럼 X, 공포면 공포답게) |
| **카메라 각도를 멋지게**(영상 규칙도 OK: 'Camera Work') — 낮은 각도·가까이 | **실제 게임보다 그래픽을 부풀리기**(영상 'Artificial Visuals') — 우리 차를 사진 같은 슈퍼카로 X |
| **밝기·대비·작은 효과** 조금(영상 'Minor Post-Processing') | **실제 사람·장소·게임 밖 것**(영상 'External Content') — 실사진·실제 브랜드 X |
| **우리 게임 로고** 얹기(영상 규칙도 OK) | **광고·홍보·주관적 자랑 글**: "50% off", "Free UGC!", "#1", "BEST" 같은 것(영상 'Text, Claims, Advertisements') |
| 놀이를 설명하는 **짧은 글**("Collect coins to boost jumps" 예) | 커뮤니티 규칙: **발견·참여를 늘리려는 기만적·선정적·오해를 부르는 콘텐츠·메타데이터**, 다른 게임과 **헷갈릴 만큼 비슷한** 것 |
| 게임 주제를 **색·분위기**로 보여 주기(밝은 코믹 = 밝은 색) | 흐릿하고 뭔지 모를 그림('ambiguous imagery') |
| | **아래쪽에 중요한 글·물건**(플레이어 수 표시가 가림) |

- 이미지 썸네일은 문서에 '진짜 화면만' 규칙이 따로 없고, 인기 게임 거의 전부가 **렌더·일러스트**를 씀 → 그림은 OK. 단 영상 규칙의 정신(게임에 있는 것만, 부풀리지 않기)을 그대로 지켜요. 우리 기준: **"이 그림의 모든 물건·놀이가 첫 1시간 안에 게임에서 보이나?"** 아니면 빼기(복원·폐차·쇼룸은 약 3시간 뒤 해금 → 대표·앞쪽 썸네일 X, 쓴다면 뒤쪽 한 장에만).
- 돈 숫자를 쓰면 **게임에서 실제로 나오는 크기**로(첫 일 정산 약 $300대, 첫 팁 $150 — `docs/design/first10_payout.md`). "$1,000,000" 같은 부풀린 숫자 X.

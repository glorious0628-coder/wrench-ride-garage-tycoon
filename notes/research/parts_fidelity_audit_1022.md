# 부품 "진짜 같음" 점검 — 우리 세단·SUV vs 진짜 캠리 XV70 (10-22, 도우미 점검)

> 사용자 말(10-22): "우리가 구현한 부품들이 실제로 들어가는 것과 똑같은지, 어째 내눈에는 조금 부족해보여."
> 기준 차 = Toyota Camry XV70 2.5 L(A25A) 앞바퀴굴림. 진짜 쪽 근거 = `teardown/sedan_teardown.md`(부품 118줄), `diagrams/`(01·04·07·12·13·18·23·24 직접 봄), `parts_quickref.md`, `decor_quickref.md`.
> 우리 쪽 근거 = 게임 화면(`notes/playtest/wr-builder/lighting/engine_*`, `wr-play/t2_p163·p177`, `wr-gamer/g14·a24`, `wr-dev/faultparts_1`), 3D 검수 그림(`art/3d/sedan_body/review/`, `battery·radiator·muffler·brake·wheel` 색 시트, `fault_parts/`), 그리고 **3D를 만든 코드 자체**(`tools/blender/wr_body/build_decor.py` — 덩어리 안에 뭐가 들었는지 한 줄씩 확인), `CarParts.luau`, `PartData/`, `car_spec.md` §4-2·§5.
> 쉬운 말 약속: **따로 있음** = 게임에서 떼는 부품 / **따로 3D** = 모양은 따로지만 못 뗌 / **뭉개짐** = 덩어리 하나(메시 1장)에 붙어 있어 못 뗌 / **없음** = 모양 자체가 없음.

---

## 1. 한눈에

### 판정: 진짜와 꽤 멀어요. 사용자 눈이 맞아요.
- **"큰 것의 자리"는 거의 맞아요.** 운전석 쪽 앞→뒤 = 에어박스 → 배터리 → 부스터, 퓨즈박스는 배터리 바깥, 조수석 쪽 냉각수·워셔 통, 변속기는 왼쪽·벨트는 오른쪽, 흡기는 앞·배기는 방화벽 쪽, 배기관·연료탱크·머플러 자리까지 사진(diagrams/23)과 같아요. 이건 잘 했어요.
- **"부품의 수와 잔부품"은 많이 모자라요.** 캠리 분해 지도 118줄을 손으로 세어 보면(대략):

| 상태 | 줄 수 | 비율 |
|---|---|---|
| **진짜로 뗄 수 있음** (보닛·앞뒤 범퍼·배터리·라디에이터(+팬)·머플러·바퀴·패드) | 9 | 약 8% |
| 따로 3D지만 못 뗌 (보닛 받침대·캘리퍼·와이퍼 팔/날·냉각수/브레이크 통) | 약 6 | 약 5% |
| **덩어리 하나에 뭉개져 모양만 있음** | 약 63 | 약 53% |
| **아예 없음** | 약 40 | 약 34% |

- **덩어리 7개는 각각 메시 1장**(GLB 노드 1개)이라서, "있다"고 적은 줄도 지금은 **골라서 만질 수도, 떼서 뒤를 볼 수도 없어요.** 눈에 보이는 건 있는데 손이 안 가는 상태 = 사용자가 느끼는 "부족함"의 큰 이유.
- **문서(car_spec §5)와 실제 3D가 달라요.** 문서엔 "연료 레일·인젝터 8·고압 펌프, ABS 모듈, 엔진 마운트 4, 앞 검은 덮개판"이 덩어리 안에 있다고 적혀 있는데, 3D를 만든 코드엔 **없어요**(엔진 마운트는 2개, 나머지는 0). 문서만 보고 "있다"고 믿으면 안 돼요.
- **SUV는 세단 엔진룸을 그대로 복사해(+0.5, +0.15 옮김)** 써서 위의 모자람이 똑같이 있어요. SUV만의 추가 구멍: 리프트게이트 가스 지지대, AWD(프로펠러 샤프트·뒤 차동기어)는 스펙에만 있고 3D 확인 못 함.

### 가장 큰 구멍 TOP 10 (눈에 띄는 순서 + 첫 묶음에 필요한 순서)
1. **떼는 부품이 7종(9줄)뿐.** 나머지는 덩어리라 "눈에 보이는데 안 떼짐".
2. **앞 스트럿 + 코일 스프링, 뒤 쇼바 + 뒤 코일 스프링이 아예 없음.** 3D는 자리(`rooms`)만 비워 뒀어요. 바퀴를 떼면 **빈 검은 바퀴집**이 보여요(진짜는 큰 스프링 기둥이 꽉 차 있음).
3. **엔진룸 앞 검은 덮개판(덕트 실 + 클립 5 + 환기 슬릿 + 보닛 걸쇠)이 없음.** 진짜는 보닛 열면 제일 먼저 보이는 폭 전체의 큰 검은 면. 우리는 얇은 가로대만 보여서 앞이 휑해요.
4. **점화 플러그 4 없음 + 코일이 커버 밖으로 튀어나옴**(진짜는 엔진 커버 밑에 숨음). 첫 묶음 P4(코일·플러그)가 이대로는 못 만들어요.
5. **엔진 보조 부품이 통째로 없음**: 연료 레일·인젝터 8, ECM, 시동모터, 오일 필터, 워터펌프·서모스탯, 배기 매니폴드(열 차단판 한 장만), 엔진 마운트 2/4, 센서·접지 스트랩. 엔진이 "매끈한 장난감 덩어리"로 보이는 이유.
6. **호스·선·클램프가 거의 없음**: 라디에이터 호스 2줄(클램프 0), 굵은 배선 관 1줄, 진공·히터·PCV·증발가스·브레이크 파이프 0, 커넥터·클립 0.
7. **차체가 한 덩어리**(Shell 1장): 문 4·펜더·트렁크·거울·손잡이·램프가 붙어 있고, 헤드램프는 흰 띠, **앞 깜박이·옆 표시등 없음**, 문 안 열림, 실내는 블록 2개.
8. **차 밑이 "파이프 틀 + 격자판"처럼 보임**: 서브프레임이 굵은 둥근 관(진짜는 눌러 만든 철판 틀), 검은 직사각 판 6장이 바둑판(진짜는 모양 있는 큰 덮개), 오일팬이 덮개 없이 다 드러남.
9. **허브 가운데가 빔**: 바퀴 떼면 구동축 끝 + **액슬 너트(294 N·m)** 가 있어야 하는데 없음. 너클·EPB 모터·TPMS 센서도 없음.
10. **연결이 헐거움**: 배터리 고정쇠 브래킷 모양 없음 + 받침이 다리 1개로 서 있음, 에어박스 뚜껑 걸쇠 2 없음, 퓨즈박스 뚜껑·퓨즈 없음, 휠 너트가 둥근 단추(진짜 육각 21 mm, 크기도 반지름 0.275 vs 0.20).

## 3. 새로 만드는 3D가 꼭 가져야 할 것 (체크리스트)

**공통 원칙 (사용자 규칙 "캐주얼 그림체 + 구성은 진짜")**
- [ ] **한 부품 = 한 메시 = 부품 id 하나**(이 문서 2장에서 "뭉개짐"인 줄은 전부 따로).
- [ ] **떼면 그 밑의 다음 층이 진짜로 보임**: 코일을 빼면 **플러그 구멍**, 배터리를 빼면 **받침 + 접지 단자 + 배선 끝**, 에어필터를 빼면 **통 속 빈 칸**, 커버를 빼면 코일, 라디에이터를 빼면 **콘덴서 뒷면 + 팬 슈라우드 자리**.

## 4. 플레이어가 한눈에 "부족하다"고 느끼는 것 (사용자 눈 시험)

**A. 휑한 곳**
- 엔진룸 **맨 앞**: 진짜는 큰 검은 덮개판인데, 우리는 라디에이터 윗면 + 가로대만 보임(게임 화면 `engine_v26.jpg` 아래쪽 띠).
- **보닛 안쪽 면**: 진짜 = 검은 단열 패드 + 클립 + 리브, 우리 = 평평한 검은 판(게임 화면 위쪽 전체가 그냥 검정).
- **바퀴집 안**(바퀴 떼면): 스프링·쇼바·너클·액슬이 없어 검은 구멍.
- 엔진 **앞 아래**, 방화벽 **와이퍼 모터 자리**, 변속기 위 **ECM·ATF 쿨러** 자리 — 진짜는 빽빽한 곳이 비어 있음.

**B. "덩어리"로 보이는 곳**
- 변속기 = **매끈한 둥근 통**(리브·플러그 없음), 엔진 흡기 = **검은 도넛 4개**, 에어박스·퓨즈박스 = **매끈한 검은 상자**(걸쇠·글씨·퓨즈 없음).
- 배터리 받침 = **다리 하나에 올라선 판**.
- 차 밑 서브프레임 = **굵은 둥근 파이프 틀(롤케이지 같음)**, 바닥 덮개 = **바둑판 6장**.
- 엔진 커버 = **납작한 직사각 타일**(진짜는 조각 덮개), 게다가 코일이 커버 뒤로 드러남.

**C. 있어야 할 호스·선이 없음**
- 호스 클램프 0, 굵은 하네스 1줄, 진공·PCV·히터·브레이크 파이프 0, 커넥터·클립 0, 접지 스트랩 0, 에어컨 배관 1줄.
- 진짜 사진(diagrams/23)은 작은 선·관·클립 수십 개가 겹쳐 보임 → **우리는 큰 모양 7~8개만 보여서 비어 보임**.

**D. 질감·색이 평평함**
- 게임 화면에서 엔진·변속기가 **크림색 점토**처럼 보임(`engine_v26.jpg`). 3D 검수 렌더(은색·진회색·검정)와 다름 — **게임 조명·재질 때문인지 확인 못 함**(wr-builder lighting 쪽 일).
- 라벨·경고 스티커·글자·볼트 머리·클립이 없어 "장난감 매끈함". 휠 너트도 둥근 단추.
- 타이어 옆면 글씨 없음, 차체는 단색 + 틈 선만(손잡이 홈이 작음).

**E. 크기·비율**
- 휠 너트 원 0.275 vs 진짜 0.20(의도한 키움이라 사용자는 "단추처럼 크다"고 느낄 수 있음).
- 에어박스가 진짜보다 작아 보임(눈대중, 확인 못 함).
- 머플러가 하체 시안보다 작음(README에도 적힘).

**F. 깜박이·램프**
- 앞이 **흰 띠 1줄**(깜박이 없음 — 사용자 지적 맞음), 뒤는 빨간 띠. 렌즈·반사판·전구 없음.

**G. 못 만지는 것**
- 눈에는 보이지만 누르면 아무 일 없는 것이 약 63줄(덩어리). 사용자가 "이게 부품이야?" 하고 누르면 반응이 없음 = "부족하다"의 직접 원인.

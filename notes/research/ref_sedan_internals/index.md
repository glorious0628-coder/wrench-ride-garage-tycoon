## 1. 엔진룸 (위에서, 앞 = 아래)
| 부품 | 자리 | 모양 |
|---|---|---|
| 라디에이터 + 콘덴서 | 맨 앞, 그릴 바로 뒤 가로로 꽉 | 얇은 판 + 가는 핀 줄무늬. 위에서는 윗변·라디에이터 캡·위 호스 연결부만 |
| 냉각팬 | 라디에이터 **뒤**(엔진 쪽) | 검정 둥근 슈라우드 + 팬 1~2개. 위에서는 슈라우드 윗변만 |
| 엔진 | 가운데, **가로**(실린더 4개가 좌우로 한 줄), 약간 오른쪽 | 회색 블록 + 헤드, 위에 밸브커버 + **점화코일 4 일렬**, 앞 또는 뒤에 흡기 매니폴드(검정 플라스틱) |
| 트랜스액슬(변속기) | 엔진 **왼쪽 끝**(운전석 쪽), 엔진보다 낮게 | 은색 알루미늄 종 모양 + 몸통. 그 위에 배터리 받침 |
| 배터리 | **왼쪽 앞**, 트랜스액슬 위 받침 | 상자 + 손잡이 + 빨강(+)·검정(−) 단자 + 고정쇠 |
| 퓨즈·릴레이 박스 | 배터리 바로 옆(뒤쪽) | 검정 뚜껑 상자 |
| 에어클리너 박스 | 왼쪽(배터리 뒤 또는 옆), 흡기 덕트 → 엔진 스로틀바디 | 검정 상자 + 주름 덕트 |
| 벨트 구역 | 엔진 **오른쪽 끝**(조수석 쪽, 차 오른쪽 펜더 쪽) | 서펜타인 벨트 + 크랭크 풀리 + 발전기(위) + 텐셔너 + 에어컨 컴프레서(아래). 위에서는 발전기·벨트 위쪽만 |
| 냉각수 보조탱크 | 오른쪽 앞(라디에이터 옆) | 반투명 흰 통 + 분홍/초록 물 |
| 워셔액 통 | 오른쪽 앞 구석(펜더 쪽) | 반투명 통 + 파란 뚜껑(목만 보이는 차도 많음) |
| 브레이크 부스터 + 마스터실린더 | **왼쪽 방화벽**(운전석 앞) | 큰 검정 원판 + 은색 실린더 + 작은 반투명 통(노란/검정 뚜껑) |
| 스트럿 타워 | 좌우 펜더 안쪽 뒤 | 차체색 둥근 돔 + 위 너트 3 |
| 카울 | 맨 뒤(앞유리 아래) | 검정 플라스틱 그릴판 + 와이퍼 축 |
| 오일 딥스틱 / 주입구 | 엔진 앞쪽 / 밸브커버 위 | 노란 고리 / 둥근 캡 |
| 배기 매니폴드 | 요즘 4기통은 엔진 **뒤쪽**(방화벽 쪽)이 많음, 열 차단판으로 덮임 | 은색 열판 |

## 2. 하체 (아래에서 올려다봄)
| 부품 | 자리 | 모양 |
|---|---|---|
| 앞 서브프레임 | 앞바퀴 축 바로 뒤, 좌우를 잇는 큰 틀 | 검정/진회 강철 사다리 모양, 볼트 4~6로 차체에 |
| 아래 컨트롤암 2 | 서브프레임 양 끝 → 너클 아래 | L자 강철 팔 |
| 스티어링 랙 | 서브프레임 위(뒤쪽) 가로 | 긴 원통 + 양 끝 고무 부트 + 타이로드 → 너클 |
| 스태빌라이저 바 | 서브프레임 따라 가로, 양 끝 링크 → 스트럿 | 가는 굽은 봉 |
| 드라이브샤프트 2 | 트랜스액슬(왼쪽)·엔진 아래에서 좌우 앞바퀴로 | 봉 + 양 끝 등속조인트 고무 부트(주름). **오른쪽이 더 김**(중간 베어링 있는 차 많음) |
| 오일팬 | 엔진 바닥 | 은색/검정 납작한 통 + 드레인 플러그 |
| 트랜스액슬 아래 | 엔진 왼쪽 바닥 | 은색 알루미늄 |
| 배기 | 엔진 뒤 → **촉매**(앞) → 가운데 터널 따라 파이프 → 공명기 → 뒤 **머플러**(뒷범퍼 아래, 가로 통) → 꼬리관 1~2 | 은색 파이프 + 열 차단판, 고무 걸이 |
| 연료탱크 | **뒷좌석 아래**, 뒤축 앞 | 검정 플라스틱 큰 판 모양 + 철 끈 2 |
| 바닥 언더커버 | 앞 엔진 아래·옆 바닥 | 넓은 검정/회색 플라스틱 판(요즘 차는 많이 덮음) |
| 뒤 서스 | 뒤바퀴 축: 토션빔(가로 U자 빔) 또는 멀티링크(서브프레임 + 팔 여러 개) | 중형 세단은 멀티링크가 많지만 캐주얼 게임엔 토션빔이 더 잘 읽힘(car_spec: 토션빔 또는 멀티링크) |
| 바퀴 안 | 너클 + 허브 + **디스크**(은색 원판) + **캘리퍼**(바퀴 중심 뒤쪽 위, 색 있는 덩어리) + 쇼바/스프링(앞: 스트럿이 위로 쭉, 뒤: 따로 쇼바+스프링) | |
| 4WD 아님 | 03 사진은 AWD 판이라 가운데 **프로펠러 샤프트·뒤 디퍼렌셜**이 있음 → **우리 FF 세단엔 없음** | |

- 엔진룸 확대 시안: 위 1번 표 그대로(왼쪽 = 배터리·변속기·에어박스·마스터실린더, 오른쪽 = 벨트 구역·냉각수·워셔). 위에서 보면 화면 오른쪽 = 차 왼쪽.

## 3. 우리 게임에 가져올 것 / 피할 것 (중요도 순)

1. **시대 공통 요소만 섞어 원본 차를 만든다.** 이유: 한 모델의 얼굴은 트레이드 드레스 위험이 크다. 크기 **M**.
2. **한 차에서 앞얼굴, 엠블럼, 글자 하나만이라도 베끼지 않는다.** 이유: 라디에이터와 그릴이 가장 알아보기 쉬운 부분이다. 크기 **S**.
3. **시대별 정비 미니게임을 만든다.** 이유: 시대마다 고치는 방법이 달라서 반복이 지루하지 않다. 크기 **L**.
4. **시대 구분 장치는 점화·시동·전기로 정한다.** 이유: 핫튜브 → 트렘블러 코일 → 마그네토 → 배터리 점화 → 전기 시동 순서로 이어지고, 아이도 이해하기 쉽다. 크기 **M**.
5. **희귀 역사 차는 "공통 요소 + 고유 기계 하나" 방식으로 만든다.** 예를 들어 수평 단기통, 앞바퀴 구동, 공랭 후방 엔진 중 하나를 기계 특징으로 쓴다. 이유: 겉모습을 베끼지 않고도 정비 재미를 준다. 크기 **M**.
6. **시대마다 색 팔레트를 고정한다.** 이유: 검정(1910–20), 투톤 파스텔(1950), 올리브(1940) 같은 색은 특정 회사 것이 아니다. 크기 **S**.
7. **Robux는 도장, 바퀴 모양, 장식에만 쓴다.** 이유: 하우스 룰(pay-to-win 금지). 크기 **S**.
8. **피할 것:** 실제 연도와 모델명을 그대로 쓰는 것, 실제 차 이름의 말장난, 실제 숫자(예: 정확한 슬롯 수)를 그대로 복사하는 것. 크기 **S**.

## 4. 수리 미니게임용 역사 사실 (표)

| 주제 | 사실 (요약) | 미니게임 아이디어 |
|---|---|---|
| 핫튜브 점화 | 1880년대 엔진에서 외부 버너로 관을 달궈 혼합기를 점화함. 타이밍 조절이 어렵고 바람에 약함. | 버너 불꽃 조절, 관이 식으면 시동 실패 |
| 트렘블러 코일 | 진동 접점이 윙윙거리며 스파크를 연속 발생시킴. Model T는 실린더마다 코일 박스가 있었음. | 접점을 닦고 간격을 맞추기, 소리로 고장 진단 |
| 크랭크 시동 | 점화 시기를 늦추지 않으면 되튕김(킥백)으로 손목이 다칠 수 있음. 전기 시동은 1912년 Cadillac이 널리 알림. | 타이밍 레버를 먼저 늦추고 돌리기 |
| 카바이드 램프 | 카바이드에 물을 떨어뜨려 아세틸렌 가스를 만들어 태움. 1910년대 후반까지 많이 사용. | 물 방울 속도 조절, 노즐 청소 |
| 6볼트 시스템 | 1950년대 중반까지 대부분 6볼트. 케이블이 굵고 접지 불량에 약함. 양극 접지가 흔했음(차마다 다름, 불확실). | 접지선 점검, 배터리 단자 청소 |
| 기계식 로드·케이블 브레이크 | 4륜 유압이 1920년대에 퍼지기 전에는 로드와 케이블이 쓰임. 늘어나서 좌우 불균형이 생김. | 좌우 조정 너트를 균형 있게 맞추기 |
| 발전기 vs 교류발전기 | 직류 발전기는 1960년대 초까지 주류, 이후 알터네이터로 교체. 발전기는 공회전에서 충전이 약함. | 1950년대는 충전 램프가 느리게 꺼지는 고장 |
| 진공 와이퍼 | 흡기 진공으로 움직여서 가속하면 느려지거나 멈춤. | 가속과 와이퍼 속도 연동 |

**연도 불확실:** 12볼트 전환 시기(1955–56 중심), 알터네이터 보급(1960년대 초), 4륜 유압 보급(1920년대 중반~30년대)은 회사마다 다릅니다.

# 사용자 새 부탁 (10-22 11:40) — 게임 안에서 "AI 티" 안 나게

## 사용자 말 (그대로)
"얌 그리고 AI 티 나면 안 된대 ㅋㅋㅋㅋ 뭐라고 하는 사람들이 있대! 게임 내부에서 AI 티 안 날 방법도 연구하자."

## 왜 중요한가
- 로블록스 플레이어(특히 댓글·디스코드)는 "AI slop"에 민감 → 썸네일·아이콘에서 AI 느낌이 나면 누르기 전에 떠나고, 들어와서도 "AI 게임"이라고 낮게 봄.
- 우리 게임은 그림(Codex/GPT 이미지)·효과음·음악(ElevenLabs)·영어 글(AI가 씀)을 많이 씀 → 어디서 티가 나는지 먼저 알아야 함.

## 메인이 아는 흔한 'AI 티' (출발점일 뿐 — 조사로 확인·보태기)
- **그림**: 번들번들 플라스틱 광택, 작은 곳이 녹아내린 듯 뭉개짐(볼트·글자·손가락), 이상한 손, 깨진 글자, 그림마다 그림체·조명이 다름(같은 게임인데 따로 노는 느낌), 지나친 디테일 소음, '똑같은 AI 얼굴', 가운데 몰린 구도·방사형 빛, 과한 채도, 3D 게임 안에 갑자기 매끈한 2D 일러스트.
- **글(영어 원문·한국어)**: 긴 줄표(—), "Let's dive in"·"embark"·"unleash"·"journey" 같은 말, 너무 매끈하고 뻔한 소개글, 모든 단어 대문자 시작, 이모지 남발, 세 개씩 늘어놓기.
- **소리·음악**: 다 비슷한 AI 음악 느낌, 소리 끝이 뭉개지거나 울렁거림, 알아들을 수 없는 가사·목소리.
- **3D**: 녹은 듯한 덩어리 메시, 그림자가 구워진 텍스처(우리 3D는 Blender로 직접 만들어 덜하지만 확인).
- **게임 전체**: 이름·간판·벽화 글자가 실제 글꼴이 아닌 그림 글자, 서로 안 맞는 UI 그림 세트.

## 할 일 (wr-gamer)
1. **조사**: 플레이어·개발자가 실제로 무엇을 보고 "AI 같다"고 하는지 — Roblox DevForum, Reddit(r/roblox, r/robloxgamedev, r/gamedev), 유튜브·X 댓글, 기사. 로블록스 쪽 규칙(AI 콘텐츠 표시 의무 등)이 있으면 그것도. 출처 링크 필수, 다운로드 X.
2. **우리 게임 점검**: 처음 켜는 순간부터(로딩·아이콘·썸네일 후보·간판·벽화·UI 그림·영수증·글·효과음·음악·3D·손님) 하나하나 'AI 티 점수'(없음/조금/심함) + 사진 + 이유.
3. **고치는 법**: 항목마다 구체적으로(예: 썸네일은 게임 안 실제 장면 기반, 그림체 기준 한 장 + 색 판 고정, 글자는 그림 말고 진짜 글꼴로, 영어 글은 humanizer 기준으로 다시, 음악은 …) + 어느 세션 일인지 + 공개 전/후.
4. GPT 2라운드로 내 판정 반박 받기(`notes/gpt/wr-gamer/ai_look_decision.md`).

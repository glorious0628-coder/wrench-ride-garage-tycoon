## 메인 방향 (내 판단 — 세부는 wr-design이 GPT 토론으로)
### A. 모든 부품 따로 (장식 덩어리 없애기)
- 목표: **진짜 정비사가 떼는 것이면 게임에서도 하나하나 따로 뗄 수 있다.** 장식 덩어리를 부품으로 쪼갬. 겉 → 속 **층**으로: 차체(보닛·범퍼·펜더·문·트렁크/해치/테일게이트·거울·그릴·**헤드램프/테일램프/깜박이**·와이퍼·유리) → 엔진룸(엔진 커버·에어박스/필터·흡기·배터리+받침+고정쇠·통 3개·라디에이터+팬+호스·발전기/벨트/텐셔너·시동 모터·점화코일/플러그·오일 필터/드레인 플러그 …) → 차 밑(배기 토막·머플러·열 차단판·연료탱크·드라이브샤프트·컨트롤암·타이로드·스태빌라이저·스트럿/쇼바/스프링·서브프레임) → 바퀴(타이어·휠·밸브) → 브레이크(패드·캘리퍼·브래킷·디스크·호스) → 높은 레벨: 엔진·변속기 통째(호이스트).
- 부품마다: **조이는 것(볼트·나사·클립·호스 밴드·커넥터 …) 종류·수 / 먼저 떼야 하는 것 / 맞는 공구 / 무게·드는 법**. **데이터만 늘리면 부품이 늘게**(코드 하나, 표 여러 줄).
- 폰에서 단순하게(메모리 규칙: 화면에 동시에 뜨는 것 최소): 부품을 누르면 "필요한 공구 아이콘 + 먼저 뗄 것"만.
### B. 맞는 도구
- 조이는 것 종류 → 공구: 소켓·라쳇, 드라이버, 플라이어(호스 밴드), 트림 클립 도구, 토크 렌치, 브레이커 바 + 녹 제거 스프레이, 오일 필터 렌치 + 받이통, 멀티미터, 임팩트, 스프링 압축기, 엔진 호이스트, 미션 잭 … **틀린 공구는 안 됨**(또는 아주 느림 — 설계가 정함). 레벨로 하나씩 열림 = 성장 신호(wr-gamer 'Lv4부터 성장 신호 0' 숙제와도 이어짐).
### C. 레벨 오를수록 어려운 차
- 차 난이도 ★1~★5 같은 단계: ★1 겉 부품(배터리·타이어) → ★2 한 층 아래 → ★3 깊은 곳(라디에이터 = 범퍼·팬 먼저, 발전기 = 벨트 먼저) → ★4 녹슨 볼트·고장 여러 개·숨은 고장(스캐너·멀티미터 진단)·픽업/밴처럼 구조가 다른 차 → ★5 시대 차·엔진 내리기·여러 계통. 보상도 함께 커짐. 첫 1시간은 쉽게(지금 규칙 그대로), 레벨이 올라도 **쉬운 차가 가끔 섞여** 리듬 유지.
### D. 순서
1. wr-carbook 조사(진짜 분해 순서·조이는 것·공구·"진짜로 어려운 차" 이유) + wr-design 설계 `docs/design/full_teardown.md`·`car_difficulty.md` v0.1(GPT 2라운드) — **지금 시작**.

3. wr-art 공구 시안 6면 → 3D(메인/도우미) · **3D 차는 처음부터 다시**(세단부터): 부품마다 따로 만든 메시 + 볼트·클립 자리, 옛 덩어리 자르기 X. 그 전에 부품별 분해도 시안(6면 대신 '분해도 + 부품 한 장씩')이 필요한지 wr-design·wr-art가 정함.

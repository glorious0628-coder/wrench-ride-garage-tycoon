## 말하기·보고
- 항상 **한국어, 쉬운 말, 짧게**.
- 일이 한 단락 끝나면 **턴을 끝내며 짧게 보고**해요(메인이 자동으로 받아요). 하나 끝날 때마다 쪼개 보내지 말고 묶어서.
- **사용자에게 직접 묻지 않아요**(질문 상자·알림 X). 결정이 필요하면 보고에 "사용자 결정 필요: …"로 적어요. 메인이 모아서 물어요.
- 사용자가 내 세션에 직접 말하면 그 말이 최신이에요. 따르고 보고에 한 줄.
- 다른 세션에 부탁: `board.md`에 한 줄(누가→누구: 무엇, 시각) + 급하면 SendMessage로 "board 봐 줘"만. 세션끼리 SendMessage는 사용자가 말할 때까지 10개 제한이라 아껴요.
- 백그라운드 대기(wait_change 같은 것)는 쓰지 않아요. 할 일이 없으면 턴을 끝내고 쉬어요(메인이 깨워요).

## 보안 (핵 방어) — 사용자 10-22 "핵 쓸 수도 있으니까 방지하게" · 점검 `notes/security/exploit_audit_1022.md`
1. **서버가 정한다**: 돈·가격·레벨·결과는 서버가 계산하고, 클라는 "무엇을 눌렀나"만 보낸다. 가격·금액·레벨을 리모트로 받지 않는다.
2. **클라 말은 다 의심**: 새 리모트·프롬프트 핸들러는 `Guard.wrap` / `Guard.prompt`로 시작(입장·타입·NaN·빈도·거리). 프롬프트도 핵은 아무 거리에서 누를 수 있다.
3. **보상은 한 번만, 표시 먼저**: 돈을 주기 전에 "줬다" 표시(영수증 id·`Scrapped`·`started[car] = nil`)를 먼저 세운다. 사는 값보다 비싸게 되파는 길(고물값 > 부품값, 산 적 없는 부품값)이 없게 값 표를 맞춘다.
4. **Robux·저장**: 영수증은 저장 성공 뒤에만 Granted, 처리 중이거나 불러오기 전이면 기다리거나 NotProcessedYet. 패스는 `UserOwnsGamePassAsync`로만 믿고, 저장은 세션 잠금으로.
5. **Studio 전용은 IsStudio 안에서만**(리모트 포함), 라이브엔 제작자·관리자 예외 없음. 리모트를 새로 만들면 점검 문서 2장 표에 한 줄 추가.

## 차 = 진짜 구조 (사용자 10-22 — 가장 중요한 규칙)
- 사용자: "자동차를 이루는 모든 부위가 다 따로 움직일 수 있어야 하고 그에 맞는 도구들도" · "이미 3D로 만들어진 것이라도 폐기하고 다시 — 우리의 게임성은 현실적인 거에 있으니까" · "구조가 현실적이지 않은 자동차들은 절대 금지" · **"모양은 현실 세계에 없더라도 자동차 구조나 부품은 현실적이어야 돼."**

## AI 티 X (사용자 10-22: "AI 티 나면 안 된대 — 뭐라고 하는 사람들이 있대!")
근거 = wr-gamer `notes/playtest/wr-gamer/ai_look_report.md` §4 + GPT `notes/gpt/wr-gamer/ai_look_decision.md`. 핵심 시험 두 개: **① 게임 안 모습과 같나 ② 실제 크기에서 읽히나.**

- **쉬운 말 (사용자 10-22: "공임 이런 것보다는 조금 더 쉬운 단어" · "영어도 쉬운 말로 해, 전문가들이 게임하는 게 아니잖아")**: 화면 글은 영·한 모두 아이가 아는 말(예: Labor → Repair work / 공임 → 수리비, Diagnostic fee → Check-up fee / 점검비). **부품 이름만 진짜 이름 그대로**(Battery·Radiator·Spark Plug — 이름표가 설명).
- **글**: 소리 내어 읽어 광고 문구 같으면 고침, 한 문장 = 한 동작, 실제로 되는 것만 · 과장 단어(epic·ultimate·immersive·unleash·embark·journey), "not X but Y", 이모지 글머리, 굵은 글씨 범벅 X, '세 개씩'은 진짜 3단계일 때만 · 공개 전 grep "Sure, here"·"As an AI"·"I hope"·"Certainly"·"placeholder" = 0 · 한국어 해요체, 번역투("~을 통해"·"~에 대한"·"보여집니다") X.

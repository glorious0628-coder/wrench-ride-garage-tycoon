## 1. 높이선 (Y)
> 실제 SUV 4대의 보닛·창 높이 mm 자료는 조사에 없어요(확인 못 함). 아래는 **세단 B 높이선 + 차고 차이**로 정한 제안 — 3D 회색 1차 때 메인이 옆모습으로 다시 판단해요.

## 3. 모델 구조 — 세단과 다른 곳만
```

├─ Chassis                      (세단과 같은 역할, 모양만 SUV)
├─ Body
│   ├─ Shell                    (지붕 레일·검은 덧판 포함 — 덧판은 같은 메시 안 다른 재질)
│   ├─ Glass
│   ├─ Hood                     ①
│   ├─ Bumper_F / Bumper_R      ①
│   └─ Liftgate                 ① (세단 `Trunk` 대신, 알파 이후 고치는 부품)
├─ MechanicalParts              (세단 프로토 14개 그대로 + 아래 추가)
│   ├─ LiftgateStrut_L / _R     ① 새 부품(car_roster 공용 — 해치백·왜건·미니밴과 같은 메시)
│   └─ (AWD만) RearDiff         ① 새 부품(뒤 차동기어 + 커플링 뭉치), Driveshaft는 장식
```

## 4. 부품 자리 (차 안 좌표, 피벗)

## 5. 장식 (② 보이는 부품)
- 세단 9덩어리 그대로(엔진룸 4덩어리는 §4 규칙으로 옮김), **하체 덩어리는 Y +0.2**(지상고 차이).
- `Deco_FrontSubframe`·`Deco_RearAxle`: 스프링·쇼바를 위아래로 길게(바퀴가 높음).
- **`Deco_AWD`**(AWD만, 삼각형 1,200): 앞 트랜스액슬 옆 **동력 인출 장치(PTU)** → 바닥 터널 따라 **프로펠러 샤프트**(가운데 받침 베어링 1) → 뒤 차동기어(RearDiff ①) → **뒤 구동축 2**(등속조인트·부트). 하이브리드식 '뒤 전기 모터만' AWD도 실제로 있지만(RAV4 하이브리드 — 가운데 축 없음) **우리 SUV는 가솔린 커플링식 하나로**(RAV4 가솔린·CR-V 공통).
- `Deco_Underbody`: 연료탱크 자리는 세단과 같음(뒷좌석 아래), 배기 파이프는 AWD면 프로펠러 샤프트 옆으로 비켜 감.
- 지붕 레일·덧판은 Shell 안(고치는 부품 X).

## 8. 3D 순서 (세단과 같게)
1. 회색 모양: Shell(높이선 §1) + 바퀴 2.98 → 메인이 옆·앞모습으로 판단(세단 회색 1차처럼).
2. 엔진룸·바퀴 안은 **세단 메시 재사용**(옮기기만) → 새로 만들 것 = Shell·Glass·Hood·Bumper_F/R·Liftgate·LiftgateStrut·(AWD) RearDiff·Deco_AWD·더 긴 스프링/쇼바·SUV용 Chassis.
3. 색·재질(그림체 B, 덧판 = 검은 무광 플라스틱).

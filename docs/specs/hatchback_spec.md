## 한 줄 결정: **세단 차대 그대로 + 트렁크 엉덩이만 잘라냄**
- 실제로 Civic·Mazda3 해치는 **휠베이스·폭이 같은 이름 세단과 같고 뒤만 짧아요**(Civic −124 mm, Mazda3 −200 mm) [hatchback.md §1, 출처 1·3]. carbook 한 줄 요약도 "세단에서 트렁크 엉덩이를 잘라 내고, 지붕을 뒤 끝까지 끌고 내려온 차".
- 그래서 **앞바퀴 앞쪽 전부(엔진룸·보닛·앞유리)·바퀴·브레이크·바닥·뒤 서스펜션 = 세단 것 그대로**, 바뀌는 건 **C필러 뒤(지붕 뒤 끝·해치·뒤 범퍼)** 와 얼굴(앞 범퍼·보닛 모양·램프).
- 다르게 보이는 건 **실루엣(짧은 엉덩이 + 지붕 끝 해치 + 뒷유리 와이퍼)과 얼굴**로 — 사용자 "같은 디자인의 차가 연속으로 오지 않으면 좋겠어. 색만 다른 것도 x". 색만 바꾼 세단이 되지 않게 §2 '반드시 다를 것'.
- 10/27 게임에 넣는 일정이라 새로 만들 메시를 가장 적게(§6).

**반드시 다를 것 (색만 다른 세단처럼 안 보이게)** — car_roster §2-4 + carbook §5:
1. 옆에서: **트렁크 턱이 없음** — 지붕이 뒤 끝까지 가서 해치로 내려옴, 뒤 오버행 짧음(2.8).

3. 앞에서: 세단과 다른 **오리지널 얼굴**(그릴·램프 모양) — wr-art-cars 시안 그대로.

## 3. 모델 구조 — 세단과 다른 곳만
```
CarModel (CarType = "Hatchback")
├─ Chassis                      (세단 것을 뒤에서 0.8 자름)
├─ Body
│   ├─ Shell                    (해치 포함 — 공개 땐 안 열림, 틈만. SUV 리프트게이트와 같은 방식)
│   ├─ Glass                    (뒷유리 = 해치 유리 포함)
│   ├─ Hood                     ① 해치백 자기 메시(모양만 새로, 경첩·크기·볼트·받침 구멍은 세단과 같은 자리)
│   ├─ Bumper_F                 ① 해치백 자기 메시(얼굴), 피벗·볼트 = 세단
│   └─ Bumper_R                 ① 해치백 자기 메시, 피벗이 0.8 앞으로
├─ MechanicalParts              (세단 프로토 14개 그대로 — 머플러만 자리 이동)
├─ Moving   (BrakeCaliper_XX — 세단 메시)
└─ Decor    (세단 9덩어리 재사용 + Deco_RearWiper 새로)
```
- 세단 `Body/Trunk`(알파 부품) 슬롯은 **안 만들어요**(없는 부품은 슬롯 X). 나중 해치 = `Body/Liftgate` + `LiftgateStrut_L/R`(SUV와 같은 이름·같은 스트럿 메시, §7).

| **`Deco_RearWiper`** (새, 늘 보임) | 뒷유리 가운데 와이퍼 팔 1 + 날 1, 쉴 때 뒷유리 아랫단을 따라 가로로 누움 | 피벗 = 와이퍼 축 ⓒ(뒷유리 아래 끝 가운데 쪽 (0, 4.4, +6.65) 안팎 — 시안). 삼각형 300 안. 세단 `Decor_Wipers`처럼 속성 `Rest` |
- 삼각형: 차체(Shell·Glass·Chassis)는 세단보다 작게, 장식은 세단 그대로 + 와이퍼 300 → 세단과 같은 예산 안.

| `Hatchback_Decor_Shell` | 겉(§1·§2 높이선, 해치 틈, 뒷유리 와이퍼 축 구멍) |

`Decor_EngineTop` · `EngineLower` · `Transaxle` · `EngineBay`(v2 + 통) · `BatteryStand` · `HoodProp` · `FrontSubframe` · `RearAxle` · `Interior` · `Dash` · `Levels` · `Wipers` · 바퀴 `Wheel_*`(TypeSets라 `Hatchback_Wheel_*`로). 공용(앞글자 없음)은 그대로: Battery · Radiator · Muffler · BrakePads · BrakeCaliper · Hub.
- **휠 무늬는 다르게(권장, GPT 1라운드)**: `Hatchback_Wheel_*` = 같은 크기·같은 너트 자리·같은 허브면, **살 모양만 세단과 다르게**(시안 A·B의 5살 휠) — 옆에서 '다른 차'로 보이는 값싼 차이. 시간이 모자라면 세단 휠 그대로(이름만 복사).
- **주의(GPT 1라운드)**: CarLook은 다른 차종 템플릿으로 **대신 찾지 않아요** — `Hatchback_` 이름 복사본을 하나라도 빼먹으면 그 덩어리는 **블록 대역으로 보임**. bake 뒤 위 목록이 다 있는지 확인.

## 9. 코드 (wr-dev 참고 — `CarParts.Types.Hatchback`)
- `slotsWith({ Bumper_R = Vector3.new(0, 1.64, 7.4), Muffler = Vector3.new(0.3, 0.8, 6.8) }, CarParts.WheelCenters)` — 나머지 슬롯은 세단 그대로.

## 한 줄 결정: **뼈대부터 다른 차 — 새로 만들 게 가장 많음, 그래서 공개 땐 '세단과 같은 고장'만**
- 세단과 다른 것(carbook §0·§3, 풀사이즈 3대 공통): **사다리 프레임** 위에 캡·짐칸을 얹음, **세로배치 V8 + 뒷바퀴굴림(4WD는 트랜스퍼 케이스로 앞도)**, 앞 **더블 위시본(A암 위·아래) + 코일오버**, 뒤 **통 차축 + 판스프링**(F-150·Silverado 공통 — Ram 코일은 한 차만이라 X), 긴 구동축 + U조인트, **너트 6개** 바퀴.
- 공개(10/27 게임에) 때 고장은 **세단과 같은 종류만**: 배터리·바퀴·브레이크(+범퍼, Lv5 라디에이터, Lv9 보닛 — 세단과 같은 열림). 픽업만의 고장(판스프링·U조인트·배기 매니폴드)은 **공개 뒤** — 그래도 3D에서 그 부품을 **이름 붙은 따로 덩어리**로 만들어 두면 나중에 떼어 낼 수 있게(§5).
- 겉: 4도어 크루캡 + 따로 떨어진 짐칸(틈) + 내려 여는 테일게이트, 큰 휠 + 두툼한 타이어, 높은 보닛, 뒤 범퍼 밑 사각 히치, 짐칸 밑 스페어, 옆 아래로 보이는 프레임(car_roster §2-2). **피할 것**: C자로 감싼 헤드램프(F-150), 2~3단 쌓인 램프(Silverado), 큰 글자·십자 그릴(Ram), 모든 로고.
- **구동은 4WD 하나로**(SUV를 가솔린 커플링 AWD 하나로 정한 것처럼) — 앞 디퍼렌셜·앞 구동축이 보여야 '트럭 밑' 같음. 실제 트럭엔 2WD도 있지만 **우리 게임 픽업 구성은 4WD 하나**(2WD 변형 안 만듦).

## 3. 모델 구조 — 세단과 다른 곳만
```
CarModel (CarType = "Pickup")
├─ Chassis                      (충돌용 상자 — 캡+짐칸 바닥 높이, §9)
├─ Body
│   ├─ Shell                    (캡 + 짐칸 + 테일게이트(닫힘) + 펜더 — 프레임은 Decor)
│   ├─ Glass
│   ├─ Hood                     ① 픽업 자기 메시
│   ├─ Bumper_F                 ① 픽업 자기 메시(프레임 뿔에 붙는 큰 범퍼)
│   └─ Bumper_R                 ① 픽업 자기 메시(발판식 뒤 범퍼, 히치는 Decor)
├─ MechanicalParts              (세단 프로토 14개와 같은 이름 — 자리만 다름, §4)
├─ Moving   (BrakeCaliper_XX — 세단 메시, 디스크 둘레에 맞춘 자리)
└─ Decor    (세단과 같은 이름 9덩어리 = 속은 트럭 것 + 새 Deco_Frame, §5)
```
- 세단에 없는 '새 슬롯'은 공개 땐 **안 만들어요**. 나중 고장 부품 이름(car_roster §3 공용 표와 맞춤): `LeafSpring_L/_R`, `UJoint_Front/_Rear/_Center`(구동축 U조인트), `ExhaustManifold_L/_R`, `RearDiff`(SUV AWD와 같은 이름), `Tailgate`, `SpareWinch`.

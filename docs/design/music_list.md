## 0. 정한 것 (모든 곡 공통)
- **목소리 X**(노래·허밍·말·환호 전부). ElevenLabs에서 '연주곡만(Instrumental)' 켜고, 판정 AI가 Singing·Speech·Vocal을 들으면 버림.
- **프롬프트에 실제 가수·곡·밴드·레이블·상표 이름 X** — 장르·악기·빠르기·분위기로만. (detroit.md 아이디어 T: 옛 소울 '느낌'의 오리지널 곡 — 레이블 이름은 안 씀)
- **분위기 근거**: 미국식 동네 정비소 + 모터 시티 모티브 도시 Gearport(`notes/research/car_knowledge/detroit.md` — 차 공장 마을, 옛 소울·R&B 음악 도시), 게임 기준 '따뜻하고, 손맛 있고, 틀려도 괜찮은'(`game_textbook.md` §2), 캐주얼, 아이들도 즐기는 밝은 톤. 무섭지 않게(할로윈도 연령 설문 Fear '없음' 유지).
- **곡 수는 적게**(사용자: "너무 복잡해 보인다" → 화면처럼 소리도 단순하게): 상황 2개 = 곡 3개(낮 A·B 번갈아 + 할로윈 밤). 늘리는 건 공개 뒤.
- **효과음과 안 싸우게**:
  - 음악은 효과음 아래 약 **12 dB**(게임 Volume 0.2 안팎, 효과음은 0.35~0.8).
  - 낮 음악엔 **종·글로켄슈필·벨·경적 같은 금관 짧은 '빵'·카우벨·우드블록·딸깍 퍼커션 X** — 게임 신호(deskBell 딩, 정산 금전등록기 딩, 렌치 딸깍, 경적)와 헷갈림. 드럼은 부드럽게(브러시·작은 킥), 하이햇 '칙칙' 세게 X.
  - **폰 스피커**: 150 Hz 아래 깊은 베이스에 기대지 않기(sfx_list 규칙과 같음) — 가운데 소리(일렉 피아노·기타·오르간)가 곡을 끌고 감.
  - 큰 순간(시동 성공·정산 카드·레벨업 카드·Ella 장면)엔 음악을 **잠깐 낮춤**(아래 §3 wr-dev 부탁).
- **소리 크기 맞추기**: loop 곡은 **−16 LUFS**(평균 크기), 피크 −1 dBTP. 징글은 −14 LUFS. 그다음 게임 Volume으로만 조절.
- **loop 이음매**: 곡 앞뒤의 시작·끝(인트로·아웃트로)을 잘라 내고 **마디 경계(박자 수)에 맞춰** 자른 뒤, 끝 0.3~0.5초를 앞에 겹쳐 이음(`tools/music_loop.py`). 이음매 검사 = 앞뒤 크기 차·튐(ffmpeg/숫자).
- **라이선스(10-21 확인)**: ElevenLabs Music 약관(2026-10-09 판) — Creator 플랜 = '영화·TV·라디오·**Studio Games** 빼고 상업 OK', 출처 표시 필요 없음. Studio Game = 수익 내는 게임 중 **Indie Game이 아닌 것**. Indie Game = 게임 누적 수익 **50만 달러 미만** + 만든 쪽 연 게임 수익 100만 달러 미만 → **우리 게임은 인디 = OK**. 넘으면 60일 안에 더 높은 플랜(그 전에 배포된 건 계속 OK). 사용자가 유료일 때 만든 곡만 씀. 플랫폼의 AI 표시 규칙은 따름. (출처 `https://elevenlabs.io/eleven-music-model-specific-terms`)

## 2. 만들기·검수 순서 (wr-sound)
1. ElevenLabs Music(`elevenlabs.io/app/music`, v2.5)에서 항목마다 **2~4개**. 길이 **2분**(앞뒤를 잘라 55~85초 loop을 만들 여유, 1분 = 900 크레딧). **'가사' 스위치 끔(= 기악)** — 글을 넣으면 저절로 켜지니 만들기 직전에 다시 확인.
2. 받은 파일 → `art/music/raw/<키>_<n>.mp3|wav`.
3. `tools/music_loop.py`: 박자 찾기(librosa) → 인트로·아웃트로 빼고 **마디 경계로** 자르기 → 끝을 앞에 겹쳐 이음 → −16 LUFS·−1 dBTP → `art/music/<키>_<n>.ogg` + 이음매 숫자.
4. 판정 AI(`tools/music_judge.py` — 곡을 10초 조각 여러 개로 나눠 AST·CLAP 평균): 장르 태그(Soul·Funk·R&B / Waltz·Lullaby·Music box 쪽), **목소리 0**(Singing·Speech·Vocal music), 무서운 음악(Scary music) 낮게, 원하는 말과의 점수.
5. 소리 그림(`tools/sfx_spectro.py`)으로 이음매 앞뒤·센 퍼커션·저음 비율 확인.
6. 1등 + 예비 → `art/music/review_music.md` → board(메인 2차).

## 3. 다른 세션 부탁 (board로)
- **wr-dev — 음악 재생기**: `SoundService` 아래 `SoundGroup` 둘(`Music`·`SFX`), 음악은 화면 소리(위치 없음)·stereo. 1번↔2번 번갈아(곡 사이 4~8초 쉼), 곡 바꿀 때 1.5초 크로스페이드. 할로윈 밤 = 3번(자정 장면 시작에 0.5초 페이드아웃, 아침 뒤 1번 2초 페이드인). 큰 순간에 잠깐 낮추기(시동 성공·정산 카드·레벨업 → 음악 30%, 0.3초 내려가고 1초에 걸쳐 돌아옴) — 손으로 Tween 하거나 `Music` 그룹에 `CompressorSoundEffect`(SideChain = `SFX`)로 자동.
- **wr-ui — 설정 창 2줄**: **Music** 켜기/끄기 · **Sound effects** 켜기/끄기(지금 Settings.luau 'Later rows (sound…)' 자리). 크기 슬라이더는 안 넣음(단순하게, 켜기/끄기면 충분). 기본 = 둘 다 켬. 저장은 언어처럼(wr-dev). 키 `set.music` "Music"/"음악", `set.sfx` "Sound effects"/"효과음".
- 업로드·id 연결은 메인 2차 뒤(`Sounds.luau`에 `music = {...}` 칸 — wr-dev가 정함).

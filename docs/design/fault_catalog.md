# 고장 카탈로그 (fault_catalog) — v0.4 (wr-carbook 검수 9건 + 05·06·10 반영) (wr-design, 2026-10-20)

> 실제 정비 기준으로 **증상 → 원인 부품 → 진단(눈·소리·도구·스캐너) → 고치는 법 → 게임 연출**.
> 부품 이름 = `docs/specs/car_spec.md`. 손님 말 = **영어 원문**(미국 손님 말투) + 한국어 번역.
> 숫자(확률·돈)는 제안이에요. Config는 wr-dev 몫.

---

## 0. 규칙 (고장이 '추리'가 되게)

1. **손님 말은 증상만** 말해요(원인 X). 예: "It won't start, just clicks." — 배터리? 단자? 시동모터?
2. **한 증상 = 후보 2~3개**. 진단 도구로 좁혀요. 정답이 바로 보이면 재미없고, 너무 숨기면 짜증 → **Lv1은 눈으로 바로 보이는 것 위주**, 레벨이 오르면 '헷갈리는 짝' 추가.
3. **오진 벌점은 가볍게**: 멀쩡한 부품을 바꾸면 부품값만 날리고(헌 부품은 되팔 수 있음), 손님 별점 −0.5. 돈을 크게 뺏지 않아요.
4. **정확한 진단 보너스**: 바꾼 부품이 전부 진짜 고장이면 "Spot On!" 팁 +15%.
5. 차 한 대 고장 수: Lv1~5 = 1개, Lv6~15 = 1~2개(가끔 숨은 고장 1개 추가), Lv16+ = 2~3개. (기획서 6장 '2~5개'는 폐차 복원 차에만.)
6. **오진 함정 비율·Scanner 규칙·변형 가중치·연속 방지**는 `alpha_scope.md` §2가 기준(Lv1~2 0% · Lv3~5 5% · Lv6~15 10%, Scanner 색 = 부품 Condition이지 원인 확정이 아님).

### 진단 방법과 해금
| 방법 | 쓰는 법 | 해금 |
|---|---|---|
| 눈 (Look) | 부품에 마우스 올리면 상태가 보임(녹·금·마모·새는 자국) — 바퀴 뒤·차 밑은 떼거나 올려야 보임 | 처음 |
| 소리 (Listen) | 시동 걸기·브레이크 밟기(직원 NPC가 운전석에서)·차 흔들기 → 소리 위치에 작은 파동 표시 | 처음 |
| 대시보드 경고등 | 운전석 들여다보면 켜진 등(배터리·엔진·온도·브레이크·타이어 압력) | 처음 |
| Tire Gauge / Tread Gauge | 공기압·트레드 깊이 숫자 | Lv1 |
| Battery Tester (Multimeter) | 전압 숫자(시동 끈 채: 12.6 V 이상 = 꽉, 약 12.4 V = 3/4, 약 12.2 V = 반, 12.0 V 이하 = 방전 / 시동 중 약 13.5~14.5 V = 정상 충전) | Lv2 |
| Mechanic's Stethoscope (청진기) | 엔진룸·하체에 대면 가까울수록 소리가 커짐 → 소리 찾기 놀이 | Lv4 |
| **Scanner** (색 점검 — 지금 코드 이름) | 들고 부품을 탭하면 초록·노랑·빨강(기획서 6장 '점검 돋보기') | 처음 |
| OBD Reader | `OBD_Port`(운전석 무릎 아래)에 꽂으면 고장 코드(P0xxx 등)와 짧은 설명 — 처음 주는 'Scanner'와 헷갈리지 않게 이 이름(실제 정비 용어 'code reader') | Lv6 (기획서) |
| Pressure Tester | 냉각수를 채우고 캡 자리에 펌프로 압력(Camry 103 kPa) → **게이지 바늘이 떨어지면** 새는 것, 새는 자리에 **방울**이 맺힘 | Lv8 |
| Test Drive (시운전) | 정비소 앞 짧은 길 한 바퀴 — 떨림·쏠림·소리 다시 확인 | Lv5 (재미 보강안) |

## 1. 프로토타입 부품 (14개: Hood, Bumper_F/R, Battery, Wheel×4, BrakePads×4, Radiator, Muffler)

### 1-1. Battery (배터리)
| ID | 증상 (손님 말) | 진짜 원인 | 진단 | 고치는 법 | 게임 연출 |
|---|---|---|---|---|---|
| BAT_DEAD | "It won't start. Just goes click-click-click." (시동이 안 걸려요. 딸깍딸깍만 해요.) | 배터리 방전·수명 끝 | 눈: 실내등·헤드라이트 희미 / **테스터 12.0 V 이하**(이 고장의 단서는 코드보다 전압) — 빠른 따다닥 = 배터리, '딱' 한 번·무소리 = 시동모터·스위치 쪽(나중 `StarterMotor` 짝) | 교체(또는 충전기 10분 — 수명 남았을 때만) | 시동 시도 때 딸깍 소리 + 계기판 깜빡 |
| BAT_CORROSION | 위와 같은 말 또는 "Sometimes it starts, sometimes it doesn't." (될 때도 있고 안 될 때도 있어요.) | **단자 부식**(흰·초록 가루) — 배터리는 멀쩡 | 눈: 단자에 흰 가루 / 테스터는 12.5 V 정상 → **헷갈리는 짝** | 단자 풀고 **와이어 브러시로 닦기**(미니게임: 문지르기) → 다시 조이기. 교체하면 오진 | 단자에 하얀 결정 데칼, 닦으면 반짝 |
| BAT_OLD | "It cranks really slow in the morning." (아침에 시동이 느릿느릿 걸려요.) 또는 손님이 "Check everything?" | 오래돼서 부풀거나 액이 샘 | 눈: 옆면 불룩 / 날짜 스티커가 5년 넘음 / 테스터 12.2~12.4 V | 교체 | 부푼 메시(스케일 X +5%) |

- 순서 실수(+ 단자 먼저 풀며 차체에 닿음) = 작은 불꽃 + "앗!" 말풍선, 벌점 X.
- 나중 헷갈리는 짝: **ALT_FAIL**(발전기) — 배터리를 새로 넣어도 며칠 뒤 다시 방전 → "단골 손님이 또 옴" 이야기로 연결(§3).

**도색 순서 (실제 정비소 순서를 게임용으로 줄임)**: 세척 → 샌딩 → 프라이머 → **베이스(색)** → **클리어 코트**(반짝이는 투명 층, 긁힘·자외선을 막음) → 광내기. 클리어를 빼먹으면 색이 탁하고 금방 벗겨짐(별점 −) — 실제 공정은 세척·탈지 → 샌딩 80→180→320~400 → 마스킹 → 프라이머 → (실러) → 베이스 2~3번 → 2K 클리어 2번 → 건조 → 물사포 1500→3000 → 광내기(carbook `11_body_paint.md` 출처 [7]~[10][28]).

## 3. 손님·이야기와 묶기 (재미 보강안과 연결)
- **헷갈리는 짝을 '다시 온 손님'으로**: 배터리만 바꾸고 보낸 BAT_DEAD 손님이 사실 ALT_FAIL이었다면, 이틀(게임 시간) 뒤 다시 와서 "It died again!" — 그때 제대로 고치면 **단골**(재방문 손님, 팁↑). 처음에 맞췄으면 바로 단골. 벌이 아니라 이야기.
- **손님 이름(영어 원문, 서양 동네 느낌, 실제 유명인 X)**: 단골 처음 2명 = **Mrs. Rosa Delgado**(동네 꽃집, 오래된 세단, 다정함) · **Tyler**(배달 밴 기사, 늘 급함). 그 밖: Grandpa Walt(시대 차 수집가), Priya(통학 해치백), Coach Dunn(픽업), Mia & Leo(남매 — 자전거 대신 처음 산 차). 돈 표시 `$1,250`.
- **손님 성격별 말투**: 급한 사람("Is it gonna take long?"), 아는 척하는 사람("It's definitely the battery." — 틀릴 때 있음), 할머니 클래식카 주인(시대 차, era_cars.md).

## 4. 시대 차 고장 (자세히는 era_cars.md)
크랭크 시동 안 걸림(점화 시기), 기화기 막힘, 드럼 브레이크 조정, 구동 벨트 미끄러짐(재질은 근거 확인 전까지 '가죽'이라 적지 않음), 6 V 배터리, 전기차 배터리 모듈 불균형·고전압 안전 절차.

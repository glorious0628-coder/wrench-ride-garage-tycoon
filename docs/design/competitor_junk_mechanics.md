## 2. 기능 (팬 위키·가이드 — 비공식)
- 고물상 4종에서 부서진 차 사기(등급이 높을수록 희귀차, 유료 새로고침) → 부품 7개(엔진·변속기·라디에이터·배터리·디스크·타이어·휠)를 **상태 %로 85~100%까지** 고치기 → 도색 → 구매자 3명(흥정되는 Juan / 즉시 싸게 Rick / 고급차만 Mr. Lupin)에게 팔기 → 후반: 튜닝(터보·ECU·기어), 경매(10/3), 바디킷.
- 업데이트: 8/5 · 8/30 · 9/20 · 10/3 · 10/10(핼러윈) — 대략 **2~4주**, 설명엔 '매주'.
- 진단 미니게임 여부·공동 작업 여부: **확인 못 함**.

## 3. 좋은 점 (배울 것)
1. **루프가 한 줄로 설명됨** — "사서, 고치고, 판다"(설명 둘째 줄). 첫 화면에서 할 일이 바로 보임.
2. **업데이트 리듬과 이름 태그** — 이름 앞 태그로 '새것 있음'을 목록에서 보여 줌(우리도 공지 방식 참고: update_roadmap).
3. **구매자 성격 3명** — 판매에 선택이 생김(우리 flip_loop 바이어 3종과 같은 방향 — 맞게 가고 있음).
4. **편의 위주 패스** — 잭·인벤토리·VIP(우리 monetization C안과 비슷한 가격대: 179~399).

## 4. 불만·약점 (신호 — 직접 인용은 못 찾음)
- 좋아요 88.2%·즐겨찾기 비율이 같은 그룹 중앙값보다 낮음(BloxBunny — 비공식), 평균 13분 → **오래 붙잡지 못함**.
- 가이드의 초보 경고: **즉시 판매(Rick)가 너무 쌈** → 초보가 손해 봄.
- 수리가 '상태 % 올리기'에 가까워 보임(확인 못 함) → 같은 일 반복 느낌 가능.
- "Fix It Up!이 베꼈다" 논란 영상 — 이 장르는 **비슷해 보이면 '베낀 게임'** 소리를 들음.

## 5. 우리가 이길 두 곳 (tycoon_analysis)
| 곳 | 그들 | 우리 | 근거 문서 |
|---|---|---|---|
| **① 첫 3분의 '원인 발견 → 시동 성공'이 더 분명하고 빠르게** | 첫 일 = 고물상에서 차를 사서 % 올리기 → 판매(첫 '고침' 시각 확인 못 함) | 들어오자마자 손님 차, **15~25초에 첫 손댐**, 딸깍딸깍 단서 → 스캐너 → 배터리 → **2분 안팎에 '부릉'**(추정, Metrics로 재기) | tutorial_script v0.2 §1b |
| **② 세 번째 차에서도 새 문제** | 같은 부품 % 올리기 | 3번째 차 = **용의자 카드 추리**(펑크 vs 브레이크), 부품마다 **증상·원인·결말 변주**, 밈 차 | tutorial_script §4, fault_catalog §1b, car_variety |
- 그 밖에 다른 점: **손님 정비가 먼저**(복원은 Lv8 — 정직하게 표시, store_page), **친구만 같은 정비소**(server_model — 12명 공용 서버와 다름), 진짜 같은 부품 구성(볼트·순서).
- 피할 것: 그들의 용어·구조를 그대로(고물상 등급·구매자 이름 패턴 등) — '베꼈다' 소리. 즉시 판매가 너무 싼 함정(우리 flip_loop: 즉시 판매 0.8× + 판매 버튼 회색·이유 표시로 미리 앎).

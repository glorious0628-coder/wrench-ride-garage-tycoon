- **대기 줄**: wr-dev가 이미 넣음(1명, 주차 칸에 코를 정비소로, '빵'·손 흔들기, 베이 빔 → 바로 들어감). 남은 것 = **손님이 다 고쳤을 때 미리 문 앞에 와 있기 + 정산 카드 바로** (§1-2).

## 1. 대기 줄

### 1-1. 이미 된 것 (wr-dev 10-22, `CustomerService` "the line") — 이 문서와 같음, 그대로 둠
- 베이가 다 차면 다음 손님 **1명**이 `RoadIn → EntryCurb → LaneEast → 칸 앞 차로`에서 **뒤로 넣어** 주차 칸(`Places.parkingSpots()` 중 모든 `ApproachSpot`에서 옆으로 10칸+ 떨어진, 베이 가운데에 가장 가까운 칸 — 베이 1개면 Parking5 (18, 0, −56), 2개+면 Parking2 (−18, 0, −56))에 섬. 서면 `lineHonk` '빵' 1번 + `line.wait.1` + 손 흔들기, 8~12초마다 또 흔들기, 3번에 1번 `line.wait.2`.
- 줄에선 보닛 프롬프트·인내심 시계 X(베이에 선 순간부터). 튜토리얼 차는 들어갈 때 `refit`으로 다시 맞춤. 닫힘·`hold`·아무도 없음 → 줄 손님 집에 감.
- 옛 차가 후진해 차로에 닿는 순간 베이 빔 → 줄 차가 바로 들어감(`CarParkSpeed` 12), 내려서 바로 증상(인사·3초 기다림 X). 떠나는 손님은 계산대 안 들르고 걸음 16.

## 2. 길가 짧은 일 (WIPER_BLADES · WASHER_FLUID)

### 2-1. 공통 규칙
| | 규칙 |
|---|---|
| 자리 | **`CurbJob.CarSpot`(30, 0, −56) 코 +Z**(= Parking6 자리 — 줄은 이 칸을 고르지 않지만 `lotSpot()`에서 확실히 빼기) + 옆 **`CurbJob.SupplyRack`**(진열대) + **"QUICK SERVICE" A자 간판**. 베이를 안 씀, `maxCars`에 안 셈. 차 = 세단만(SUV는 와이퍼·통 메시 아직 X) |
| 언제 | 베이 일 **Hand car back** 때 셈: 정비소마다 **베이 일 2~3대(무작위)마다 1번** + 지난 길가 차가 떠난 지 **240초 이상**. 정비소당 **동시 최대 1대**. 혼자면 약 10~15분에 1번 |
| 레벨 | **워셔액 Lv3**: 튜토리얼 끝(Lv3 카드) 뒤 **일반 차 2대째 Hand back에 꼭 1번**(첫 만남 보장), 그 뒤 위 규칙. **와이퍼 날 Lv4**(Lv4 카드에 한 줄). 둘 다 열리면 지난번과 다른 것 |
| 안 오는 때 | 서버에 튜토리얼 중인 사람 있음(새 친구 튜토리얼을 막지 않게) · `hold`(Ella 장면) · `GateService.closed` |
| 누구 일 | **한 사람에게만**. 혼자면 나. 친구 서버 = 돌아가며(가장 오래 안 받은 사람, 도착 때 작업 화면 안에 있는 사람은 건너뜀). 다른 사람에겐 프롬프트 X, 차 위 이름표 `curb.tag`. **60초 동안 안 시작하면 누구나**(먼저 누른 사람 것) |
| 안 하면 | **150초** 동안 아무도 시작 안 하면 손님 `curb.bye` + 손 흔들고 떠남 — **벌 X**(별점·평판·돈 그대로) |
| 중간에 가기 | 15칸 밖으로 가면 **멈춤, 한 단계도 안 잃음** — 돌아오면 그 단계부터. 베이 차 와서 가도 OK. 시작 뒤 **120초** 안 돌아오면 손님이 웃으며 떠남, 돈 X·**벌 X** |
| 돈·평판 | 끝내면 **워셔액 +$20 · 와이퍼 +$30**(부품값 뺀 순수익, 화면엔 이 금액만), **평판 +1**. 팁 X, 협동 몫 X. 큰 정산 카드 X → 작은 돈 팝 + 영수증 줄 "Quick jobs ×N" |
| 부품 | **진열대에서 나옴**(실제 미국 퀵 정비소·부품 가게처럼 와이퍼 날 상자·워셔액 갤런 통 진열). 카운터에 갈 필요 X, 진열대까지 가지러 가기 X(1분 일에 심부름 X) — 진열대 = 어디서 났는지 보여 주는 장식 |
| 폰 | **꾹 2번**(두 일 다 같은 손 리듬), 프롬프트는 **한 번에 하나**(PromptUI 카드, 큰 꾹 버튼, 단계가 바뀌면 글만 바뀜). 작은 캡·클립·날 끝을 정확히 누르기 X. `MaxActivationDistance` 10, 시선 검사 X |

### 2-2. 와이퍼 날 (WIPER_BLADES, Lv4) — 하는 시간 ≈ 8초
| 단계 | 플레이어 | 게임 | 소리 |
|---|---|---|---|
| 도착 | — | 칸에 서서 시동 끔, 손님 내려 운전석 옆. 워셔를 한 번 뿌림 → 와이퍼 2번 → **유리에 줄무늬**(닳은 날 `WiperWorn`). 말풍선 `curb.say.Wipers` | `washerSpray` |
| 1 | **"Change wipers"** 꾹 0.6초 (앞유리 아래 가운데) | 와이퍼가 **정비 위치**로 올라감(`Wipers = "service"`) → 0.5초 뒤 유리에서 들림(`"lifted"`) | `wiperMotor` |
| 2 | **"Swap blades"** 꾹 0.8초 (같은 자리) | 운전석 닳은 날 톡 빠짐 → 새 날 '딸깍' → 0.3초 뒤 조수석도 '딸깍'(빠진 날은 떨어지며 사라짐) | `bladeSnap` ×2 |
| 끝 | — | 와이퍼 쉼 자리로 → 시험 뿌리기 + 2번 닦기 → **유리 깨끗**. 손님 `curb.good.Wipers` + 점프 → +$30 팝 → 차에 타 '빵빵' 하고 떠남 | `washerSpray` → `reward` → `cheer` |
- 실제(캠리 사용설명서): 시동 끄고 45초 안 레버 2초 → 와이퍼가 유리 위로 올라옴 → 팔 고리 잡고 들기 → 날 교체. 게임은 레버를 1번 꾹에 묶음.

### 2-3. 워셔액 (WASHER_FLUID, Lv3) — 하는 시간 ≈ 8초
| 단계 | 플레이어 | 게임 | 소리 |
|---|---|---|---|
| 도착 | — | 손님이 워셔를 누름 → **펌프 '윙'만, 안 뿜음**(실제 = 통이 빔). 말풍선 `curb.say.Washer` | `washerWhirr` |
| 1 | **"Top up washer"** 꾹 0.6초 (보닛 앞) | 보닛 열림(작업 화면 X) | `hoodOpen` |
| 2 | **"Pour"** 꾹 1.5초 (워셔 캡 위 — 프롬프트는 크게, 캡은 정확히 안 눌러도 됨) | 손에 **파란 갤런 통** → 캡 쪽으로 기울여 물줄기, 꾹 동안 통 안 액이 줄어듦 → 다 차면 **스스로 멈춤**(넘침·실패 X) | `pourGlug`(꾹 동안 반복) |
| 끝 | — | 통 사라짐 → 보닛 닫힘 → 노즐 2개 **파란 부채꼴 물줄기** + 와이퍼 2번 → 손님 `curb.good.Washer` + 점프 → +$20 → '빵빵' 떠남 | `hoodClose` → `washerSpray` → `reward` → `cheer` |
- 손에 들기: 통을 캐릭터에 **Tool로 쥐여 주면** 로블록스 기본 팔 자세(`toolnone`)가 나와 애니메이션을 따로 안 만들어도 됨, 붓기 = Grip 기울이기. 우리 공구 줄과 부딪혀 안 되면 **캡 위 0.5에 60° 기울어진 통**(대체).
- 실제: 엔진 끈 상태에서 캡 열고 **워셔액만**(사용설명서: 뜨겁거나 켜진 엔진엔 넣지 않기 — 알코올). 손님이 내리며 시동을 끄니 '끈 상태'는 맞음. '식을 때까지 기다리기'는 1분 일이 막히지 않게 길가 일엔 X(베이 `WASHER_EMPTY`에서만).
- 워셔 캡은 엔진룸 장식 v2에 **구워진 한 메시**(따로 안 열림) → 통 주둥이가 캡을 가림. 따로 여는 캡 메시는 공개 뒤.

## 8. 경제 확인 (`econ_sim.py` + 길가 일 얹기, 200회 × 20시간)
| | 줄 없음 | 대기 줄 | 줄 + 길가 일 (혼자) | 줄 + 길가 일 (4명) |
|---|---|---|---|---|
| Lv3 / Lv4 / Lv6 | 16분 / 34분 / 1h26 | 15분 / 31분 / 1h23 | 15분 / 30분 / 1h23 | 6분 / 10분 / 26분 |
| Lv1~5 돈/시간 | $3,013 | $3,098 (+3%) | $3,122 | $3,148 |
| 길가 일 수(20시간) | — | — | 38번 · 26분(시간의 2.2%) | 179번(4명 합) · 1인 31분 |
| 길가 일 돈 비율 | — | — | **1.1%** | **1.0%** |
- 길가 일 1분당(걷기 포함 0.6·0.8분): 워셔 $33 · 와이퍼 $38 ≤ 베이 Lv1~5 $38 · Lv6+ $60. 평판 1분당 1.3~1.7 < 베이 2.6.
- **지름길이 될 수 없음**: 오는 횟수가 베이 일 수에 묶여(2~3대에 1번 + 240초) 아무리 빨리 해도 돈의 약 1%. 대기 줄은 빈 시간만 줄여서 Lv6까지 약 3분 빨라짐 — 레벨표 고칠 정도 아님.

## 9. 시험 (공개 전 — 폰 + 1명/4명)
- `Metrics`에 두 개: **베이 빔 → 다음 일 시작 초**(목표 ≤ 5) · **길가 차 도착 → 끝 초**(목표 ≤ 45, 안 한 비율도).
- 4명이 베이 넘김하는 동안 길가 일이 와도 넘김이 늦어지지 않는지, 이름표·프롬프트가 헷갈리지 않는지, 베이가 빈 채 10초 넘게 있는지(→ 줄 2명). 늦어지거나 헷갈리면 **줄이기**: 이름표 없애고 누구나, 와이퍼도 꾹 1번.

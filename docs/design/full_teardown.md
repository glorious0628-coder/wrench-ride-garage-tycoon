## 0. 한 줄 결정
1. **진짜 정비사가 떼는 것 = 게임에서도 따로 뗌.** 장식 덩어리 방식은 끝 — 3D는 **세단부터 처음부터 부품마다 따로**(해치백·픽업도 처음부터 이 방식). 옛 3D는 새 3D가 **덩어리 단위로** 들어올 때까지만(wr-dev §4).
2. 부품마다 **조이는 것의 '종류'가 진짜**(볼트·나사·클립·호스 밴드·커넥터·걸쇠…), **종류가 공구를 정함**. 개수는 줄임: **가림 부품 2~4개, 고장 난 주인공 부품 최대 6개**(바퀴 너트 5·6 예외).
3. **맞는 공구를 가져야 함**(없으면 "Lv3 Trim Tool" 자물쇠 = 성장 신호). 가진 공구는 **기본 = 조이는 것을 누르면 맞는 공구를 저절로 듦**(이름·손동작·소리로 '이건 트림 도구'가 보임), **설정 'Pick tools myself'** = 공구 칸 5개에서 직접 고름(틀린 공구 = 안 됨).
4. 공구는 **레벨마다 하나씩**: 기본 손 공구는 그 공구가 필요한 첫 일과 같이 **공짜 + 카드 한 장**, 빠른 공구만 삼.
5. 3D는 전부 따로, **'뗄 수 있음'은 레벨·묶음별로 켬**. 아직 못 떼는 부품은 **눌렀을 때만** "Lv 11" 한 줄(엔진룸 가득 자물쇠 X), 빛나는 건 **지금 일에 닿는 부품만**.
6. **부품 = 표 한 줄**(wr-dev 부품 그래프) — 매주 묶음은 데이터 줄 + 3D만.

## 1. 원칙
- **그래프가 기준**: 먼저 떼야 하는 것(`needs`)은 정비 매뉴얼 순서를 바탕으로 하되, **게임에 맞게 줄인 것은 줄였다고 적음**(예: 진짜 캠리 라디에이터 = 헤드라이트·범퍼 빔·보닛 잠금·에어클리너까지 떼고 위로 뺌 → 게임 = 위 덮개·호스 2개만. 3D·코드는 이 표를 따르고 매뉴얼의 긴 사슬을 따로 만들지 않음). 끼울 땐 **같은 `needs`**라 거꾸로 순서가 저절로(wr-dev §2-2).
- **'부품'이 아닌 것**(약속 — "모든 게 움직인다"가 끝없어지지 않게): ① **용접된 차체 판**(지붕·쿼터 패널·바닥·방화벽·스트럿 탑) = Shell, 판금 일은 따로 ② 시트 천·바닥 매트 같은 **덮인 겉면** ③ 엠블럼·작은 몰딩·선 클립 같은 **작은 장식** ④ 엔진 속(피스톤·밸브 — 복원 ★5 '엔진 분해'는 따로). → **'부품' = 진짜 정비소가 한 덩어리로 떼거나 바꾸는 것**(부품 번호가 따로 있는 단위). 렌즈 + 하우징처럼 메시가 여러 개여도 **떼는 단위 하나**.
- **진짜 종류, 줄인 개수**: 진짜 앞 범퍼 커버 = 클립 9 + 나사 8 + 볼트 4 + 걸쇠 12 + 커넥터(diagrams 02) → 게임 = **클립 1 + 볼트 1 + 나사 2**(세 종류 다 남김).
- **가림 부품은 들고 다니지 않음**: 고장 아닌데 길을 막아 뗀 부품(덮개·커버·호스)은 차 옆 **'벗겨 둔 부품 매트'**에 저절로(이름표). **다시 끼우기 = 빈 자리 탭 → '착' → 조이는 것 종류마다 꾹 한 번**(클립 줄 '톡톡', 밴드 '찰칵', 볼트 '딱' — 종류가 다른 손맛은 남기고 하나하나 반복은 없앰, GPT r2). **고장 난 주인공 부품**은 하나하나 풀고 하나하나 조임 + 카트(헌 것 ↔ 새 것) — 지금 카트 규칙 그대로.
- **액체도 진짜**: 냉각수·오일은 받이통에 빼고(`Fluid:*`) → 다시 채움(붓기 꾹). 안 빼고 아래 호스를 빼면 웅덩이(벌 X, 닦기 한 번).
- **센 볼트**(100 N·m 넘음: 캘리퍼 받침 107·스트럿 너클 290·액슬 너트 294 — diagrams 05·15·18): 손 렌치로 "끙…" → **브레이커 바 또는 임팩트**.
- **녹(★4 차)**: 갈색 볼트 + 녹 가루 → **녹 제거 스프레이**(칙 → 2초) → 브레이커 바/임팩트. 진짜로 녹이 단골인 곳 = 배기 스터드·머플러 클램프·디스크·캘리퍼(08[14][27], 02[18][21]).

## 4. 공구 — 고르는 법 · 목록 · 열림
### 4-1. 고르는 법 (GPT r2 + wr-dev §2-5)
- **기본: 저절로 듦** — 조이는 것을 누르면 **가진 공구 중 맞는 것**을 손에 쥠(0.2초 바꾸는 동작 + 공구 이름 한 줄 + 그 공구 소리). 공구가 바뀌는 게 늘 보이고 들려서 '이 클립엔 트림 도구'를 배움. 폰 화면은 지금처럼 단순.
- **처음 보는 조이는 것 종류**: 첫 번 한 번만 작은 카드 "Clips come off with the Trim Tool" + 공구가 크게 한 번 반짝.
- **설정 `Pick tools myself`(끄면 기본)**: 작업 화면 공구 칸 5개(① 소켓 ② 드라이버 ③ 플라이어 ④ 트림 ⑤ 진단)에서 직접 고름 → 틀린 공구 = 안 됨(§5).
- **안 가진 공구**: 두 방식 모두 안 됨 + "Needs: Trim Tool — Lv 3"(자물쇠) = 다음 목표. 실제로는 그 레벨에 공구가 일과 같이 오니 손님 일에선 거의 안 생김(복원 차·폐차장에서 미리 보는 정도).
- 같은 칸 안에선 **가진 것 중 가장 좋은 것**(손 렌치 → 라쳇 → 임팩트, 센 볼트면 브레이커 바, 점화 플러그면 플러그 소켓). 진단 칸(스캐너·테스터·청진기·멀티미터)은 진단 단계에서 지금처럼.

## 8. 3D를 처음부터 다시 — 순서·규칙
**순서**
1. carbook `sedan_teardown.md` → 이 §2 표 v0.2(묶음 ① 부품 확정본을 **먼저** — 10/23).
2. **분해도 시안 묶음마다 1장**(wr-art, 그림체 B): ① 엔진룸 위(위에서, 층마다) ② 앞·뒤 끝(범퍼 커버·빔·램프) ③ 바퀴·브레이크(바퀴 → 캘리퍼 → 받침 → 디스크 → 허브) ④ 차 밑(덮개·배기·벨트). **부품마다 6면 X**(수십 장). 겉모습은 지금 차 시안(깜박이 새로 — wr-art-cars) 그대로. 이 결정 = wr-design 제안 → 메인·wr-art 확정.
3. **3D 세단(메인 + 도우미) — 묶음 순서 ①→②→③→④**, 묶음 하나 = 그 덩어리 안의 **모든** 부품(뗄 수 있음이 나중인 것도 메시는 따로).
4. 굽기 → 덩어리 스위치(`LiveLumps`) → 메인 검수 뒤 켬. 옛 덩어리 잘라 쓰기 X.
5. 그다음 SUV(처음부터), 해치백·픽업도 이 방식(hatchback_spec·pickup_spec 맨 위 메모 — 그 안의 '장식 덩어리 표'는 '무엇이 있어야 하나' 목록).
**규칙 (3D 도우미 — wr-dev §4 '새 3D 약속'과 같음)**
- **떼는 단위 하나 = GLB 노드 하나 = 부품 id**(렌즈 + 하우징처럼 메시 여러 개 OK — GPT r1). 피벗 = 끼워진 자리(차 축), 좌우 짝 = 한 메시 180°(car_spec §0).
- 조이는 것 = 빈 점 **`F_<기호>_<n>`**(예 `F_C_1`, `F_H_2`, +X = 빠지는 방향, 속성 `Size`·`Torque`). 볼트 머리는 메시에 넣지 않음. `Grip_L/R`, 열리는 것 `Hinge`, `_Lite` 판.
- 부품을 떼면 그 뒤 **다음 층이 진짜로** 보여야 함(car_spec §5 규칙).
- 삼각형: 베이 차 최악 ≤ 70k(메인 결정 그대로), 닫힌 차 ≤ 25k, 멀리 Lite ≤ 8k — **부품 하나하나는 더 가볍게**, 같은 부품 4개 = 같은 메시, **구역 하나 = 색표 텍스처 1장**(wr-dev §3-1).

## 9. 데이터 (wr-dev 부품 그래프에 그대로 — 이름은 그 계획 것)
```lua
-- Cars/Sedan.luau (사람이 적는 것 = needs·kind·zone·lump·unlock·holds 종류/수. 자리는 3D에서 생성)
Radiator = {
	kind = "Radiator", zone = "EngineBay", lump = "Deco_EngineBay", unlock = 7,
	needs = { "Hood:Open", "RadiatorCover", "RadiatorHose_Upper", "RadiatorHose_Lower" },
	holds = { { f = "Bolt", n = 2, mm = 10 }, { f = "Connector", n = 1 } },
	detach = "Pop", faultable = true, refit = "full", -- 주인공 부품 = 하나하나. 가림 부품은 refit = "group"
}
RadiatorHose_Lower = {
	kind = "RadiatorHose", zone = "EngineBay", lump = "Deco_EngineBay", unlock = 5,
	needs = { "Hood:Open", "Fluid:Coolant" },
	holds = { { f = "HoseClamp", n = 2 } }, detach = "Pop", faultable = true, refit = "group",
}
```
- `refit = "group"` = 빈 자리 탭 → '착' → **조이는 것 종류마다 꾹 한 번**(§1). 같은 부품이 그 차의 고장이면 `"full"`로 바뀜(코드가 정함).
- `retainer = true`(표의 ⊙) = 고정쇠·작은 덮개·캡 — 깊이에 안 셈(배터리 고정쇠를 따로 떼도 배터리는 ★1).
- 깊이(`PartGraph.depth`) = car_difficulty §2 정의(먼저 떼는 **부품의 개수**, 사슬 길이 X).
- 고장(`Faults.Variants`) = 부품 id에 붙음. 새 고장 줄: `AIRFILTER_DIRTY`(Lv1 ★1) · `BATTERY_CLAMP_LOOSE`(Lv3 함정) · `RAD_HOSE_LEAK`(Lv5 ★2) · `RAD_LEAK`(코어, Lv5 → **Lv7**) · `TURN_SIGNAL_OUT`(Lv2, 묶음 ②) · `TAIL_BULB_OUT`(Lv4, ②) · `OIL_CHANGE`(Lv3, ④) · `BELT_WORN`(Lv6, ④) · `ALT_DEAD`(Lv8, ④) · `HEADLIGHT_CRACKED`(Lv8, ②) · `MISFIRE_COIL`/`MISFIRE_PLUG`(Lv11, ①) — 손님 말·진단은 fault_catalog §2(다음 판에 옮김).

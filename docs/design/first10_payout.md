## 1. 첫 10분 — 숫자로 본 지금 상태
| | 지금 코드 | 판정 |
|---|---|---|
| 평판 | 고장 1개 +10 · Spot On +3 · Calm +2 → 1고장 차 **최대 15**, `GarageLevels = {0, 15, 45, 80…}` | |
| 차 1·2 | `NoPatience` → 늘 Calm(+2) → 최저 **12** (Spot On 놓치면) | 차1이 12면 **Lv2(15)를 못 넘음** ✗ (GPT 지적) |
| 차 3 | 인내심 시계 있음(Calm 420초), 용의자 카드(브레이크? 타이어?) | 괜히 패드를 바꾸거나 7분 넘으면 −3/−2 |
| Lv3(45) | **차 3대가 전부 Spot On + Calm일 때만** 딱 45 | 하나만 놓쳐도 튜토리얼 끝에 Lv3 X → 결말이 '실패'처럼 보임 ✗ |

## 2. 고칠 것 (짧은 제안 3개)
### ① 레벨 문턱 숫자만 바꾸기 (S, wr-dev Config 한 줄) ✅ 결정
`Config.GarageLevels = { 0, **12**, **34**, 80, 120, 230, … }` (Lv4부터 그대로)
- 차1 최저 12 → **차1 끝에 늘 Lv2**.
- 차1+차2 최고 30 < 34 → **차3 전엔 Lv3 X**.
- 12 + 12 + 차3 최저 10 = 34 → **세 대를 고치기만 하면 늘 차3 끝에 Lv3**. 멀쩡한 부품을 바꿔도 Spot On만 잃고 결말은 안 깨짐 → 교체 금지 코드 필요 없음(GPT 2R 동의).
- 숫자는 플레이어에게 안 보임(HUD = 레벨·막대만). 대가: Lv3가 평판 11 빨라짐, Lv4(80)까지는 그만큼 김(+약 3대, 괜찮음).
- 버린 안: 차3 인내심 없애기(늦고 + Spot On 놓친 경우를 못 막음), 튜토리얼 끝 보너스 평판(왜 받았는지 설명할 새 규칙이 생김).

### ② 차 3 끝 = 기쁨의 순간 (S~M, wr-dev + wr-ui) — 새 숫자 X, 있는 것만 차례로
1. 정산 카드(§3 줄 카드) → **Nice!**
2. **Lv3 카드** — Lv2 카드(`newLevelCard`) 그대로 재사용: "Garage Level 3!" + 새 키 `tut.newJob3` **"New job: Bumpers" / "새 일: 범퍼"** + Nice!
3. 카드를 닫으면 **바로** 이름 창(`NameWindow.open`) — 지금의 독립 6초 타이머 대신 **창 닫힘 신호로 차례 잇기**(Lv2 카드 10초 타이머와 겹침 방지).
4. "Paint it!" 성공 → **카메라 1.5초 진짜 간판으로**: 새로 칠해진 간판에 내 이름이 반짝 + 소리(wr-sound: 붓 '쓱' 또는 levelUp 재사용) → 돌아옴.
   - 이름 창을 X로 닫으면: 카메라 X, 간판 반짝임·소리만.
   - 친구 정비소(주인 아님): 이름 창·카메라 둘 다 X, 간판 바뀌는 게 보이면 충분.
- 창은 한 번에 하나씩만(정산 → 레벨 → 이름). 사용자 "너무 복잡해 보인다" → 같은 화면에 겹치지 않게.

### ③ 그 뒤 할 일 — 자동 목표 띄우지 않기 (S, wr-ui)
- "Next: buy the Ratchet" 같은 목표 줄은 X(빽빽함). 대신 **장비 상점에서 Ratchet Wrench 칸만 눈에 띄게**(이번에 처음 열린 칸 = 'NEW' 표시 정도, 이미 있는 잠금 해제 모양 재사용). 돈은 이미 충분.
- 래칫 = '누른 채 쓸기' → 볼트 반복이 줄어드는 첫 성장(공부 노트 §3 CMS 불만 '볼트 하나하나'와 연결).

## 3. 정산 카드 줄 (wr-ui 화면 · wr-dev 데이터) ✅ 결정
지금: 카드엔 제목 + 합계 + "SPOT ON!"만. 서버가 `lines`를 이미 보내는데 화면에서 안 씀(순서 parts → labor → tip → spotOn → first → star).

### 줄 순서 (진짜 인보이스 순서 = 공임 먼저)
| 묶음 | 줄 (EN / KO) | 규칙 |
|---|---|---|
| 일한 값 | **Labor** / 공임 — 고장 2개 이상이면 `Labor ×{n}` / `공임 ×{n}` | 맨 위(제일 큰 값, "내가 한 일") |
| | **부품 이름 줄** — `part.<Kind>` 그대로(Battery / 배터리, Wheel ×2 / 바퀴 ×2) | 종류마다 한 줄, 2개 이상만 `×n`. 협동이면 **내가 산 부품만**. 3종류 넘으면 `Parts ×{n}`로 묶기 |
| ─ 점선 ─ | 작은 머리 **Bonus** / 보너스 | 보너스가 하나도 없으면 점선·머리 다 숨김 |
| 보너스 | **Spot On!** → **Star pattern** → **Tip** → **First job bonus** | 첫 일 보너스는 한 번뿐 → 맨 끝에 제일 크게 '펑' |
| 합계 | **Total** / 합계 — 크게, 세어 올라감 | = 실제 받은 돈(`paid[p]`)과 꼭 같게 |
- **넣지 않는 것**: 소모품·폐기물·세금 줄, 산 부품값 빼기, 협동 몫 %(이미 내 몫 금액만 — 제목에 "Team pay"), **0원 줄**, "on the house $0" 장식 줄, 차 정보(연식·주행거리) 머리줄, Hours flagged, **"+15 Rep" 글자**(새 숫자 — GPT 지적, 동의).
- 평판 신호는 **카드가 닫힌 뒤 HUD 평판 막대가 차오름**(이미 있는 0.5초 채움 — 시점만 카드 닫힘 뒤로). 레벨이 오른 출고는 **레벨 배지 바뀜**이 주 신호(막대는 새 레벨 시작점으로).

### 언제 줄 카드를 보여 주나
- **튜토리얼 3대** + 그 뒤엔 **처음 나오는 줄 종류만 한 번씩**(실제로 남는 건 첫 Star pattern · 첫 협동 Team pay 둘뿐). 그 밖엔 지금 짧은 배너(제목 + 합계 + SPOT ON!) 그대로 — 매번 줄이 튀어나오면 느리고 복잡.
- 줄은 0.15초 간격으로 하나씩 → Total이 세어 올라감 → 읽을 시간(약 1.5초) → **Nice!로 바로 닫기**(고정 6초 X). 줄마다 작은 '틱' 소리는 wr-ui·wr-sound 판단.

### wr-dev 데이터 고칠 것
- `pay.parts` 합계 한 줄 → **부품 종류별 줄** `{ key = "part.<Kind>", n = 개수, money = … }`(내가 산 것만 — `BoughtBy`로 이미 나눔).
- `pay.labor`에 `n = fixed`.
- 줄 순서 = 위 표(labor → parts → spotOn → star → tip → first).
- 협동 반올림: 줄마다 `floor(x × share)`라 줄 합 ≠ `mine`일 수 있음 → **나머지를 Labor 줄에 더해** 줄 합 = Total 맞추기.
- 새 Locale 키: `pay.bonus` "Bonus" / "보너스", `pay.total` "Total" / "합계", `pay.laborN` "Labor ×{n}" / "공임 ×{n}", `pay.partN` "{part} ×{n}" / "{part} ×{n}", `pay.partsN` "Parts ×{n}" / "부품 ×{n}", `tut.newJob3` "New job: Bumpers" / "새 일: 범퍼".

## 4. 오늘의 영수증
- wr-ui 결정(`notes/gpt/wr-ui/receipt_decision.md`) 그대로: 폰 5줄 **Cars fixed → Earned → Reputation(+Lv) → Spot On → New 또는 Customer**. 이미 '일 → 돈 → 성장 → 보너스' 순서라 정산 카드와 같은 원칙.
- 같은 원칙 확인: 빼기 줄·세금·Hours flagged·차 정보 줄 X. Spot On 위 점선은 목록이 더 분명해질 때만(wr-ui 판단, 필수 X).

## 5. 검사 질문 5개 (game_textbook)
1. 기대: 첫 손님 → 바로 Lv2, 3대 끝 → 늘 Lv3 + 내 이름 간판 ✓
2. 따뜻함·틀려도 괜찮음: 패드를 괜히 바꿔도 결말은 그대로(Spot On만 잃음), 빼기 줄 X ✓
3. 서툴러도: 늦어도 Lv3는 옴, 창은 하나씩, Nice!로 바로 닫기 ✓
4. 글 없이 반응: 줄이 하나씩 튀어나옴·합계 세어 올라감·막대 참·간판 반짝 ✓
5. 정비소가 자란다: 새 숫자 X — 돈·레벨·간판만 ✓
- 크기: ① S · ② S~M · ③ S · 정산 줄 카드 M(wr-ui) + 데이터 S(wr-dev).
- 사람 시험 1 뒤 확인: Metrics로 차별 시간(Lv2 시각·Lv3 시각) → 13.5분 넘으면 차2·3 단계 줄이기 검토.

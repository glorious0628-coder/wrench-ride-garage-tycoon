## 0. 한 줄 결정
1. **직원 = 혼자 노는 아이의 '친구 자리'**. 내 손맛 일은 안 뺏음 — 직원은 **★1~★2 차만, 다른 베이에서**. ★3 이상은 늘 플레이어.
2. **뽑을 때 돈(Hire)이 많을수록 능력치 높은 사람** — 지원자 3명 카드(싸고 서툼 · 보통 · 비싸고 잘함). 카드에 **"Hire: $700"**과 **"Gets 30% of each job's labor"**를 따로 보여 줌(GPT r1 — 비싼 사람도 몫은 같다는 걸 숨기지 않음).
3. **월급 = 그 직원이 끝낸 일 공임의 30 %**(모든 직급 같음 — '끝낸 일에서만 받음'은 진짜 정액 시간 방식의 모양, **30이라는 숫자는 게임 균형값**) → 놀 때·내가 나가 있을 때 **돈이 안 나감**(마이너스 X).
4. **교육비 = 돈 + 직원이 잠깐 빠짐(교육 중)** → 끝나면 막대 +1 / 새 일 하나. 일 20건 + 그 직급 일이 다 열리면 **직급 오름**(맡는 일 넓어짐, 몫 그대로).
5. 직원도 **진짜 부품·공구 순서대로** 일함(내 차와 같은 그래프 — '알아서 다 함' 버튼 X). 가게에 없는 공구가 필요한 일은 안 맡음.
6. **게임 돈만**(Robux로 직원·능력치 X). 접속 중에만 일함(자동 수입 X).
7. **주인이 일해야 직원도 다음 차를 받음**(GPT r1·r2 — '직원만 굴리고 구경' 막기): **최근 3분 안에 정비소 일을 했을 때만** 직원이 새 차를 맡음. 정비소 일 = 정비(볼트·부품·진단) · 손님 응대 · 부품 구매 · 꾸미기 · 손님 차 운전(맡기·시운전·배달). **걷기·메뉴 열어 두기만은 안 셈**. 아니면 **맡은 차만 끝내고** 쉼.
8. **직원 일 평판 = 0 %** — 레벨은 내 손이 올림, 직원은 돈만.

- economy Lv15 'AI 정비사 고용 $3,000 · 25 % 운영비' 줄은 지움 → 이 문서.

## 2. 직급 (진짜 이름 — carbook §1·§6-1)
| 직급 (EN) | 한 | 맡는 일 | 진짜 근거 |
|---|---|---|---|
| **Lube Tech** | 윤활 기술자 | ★1만: 바퀴·에어 필터·배터리·전구·와이퍼·(오일 교환 생기면) 오일 | 시급 $14~17, 첫 자리 |
| **Service Tech** | 정비 기술자 | ★1~★2: + 패드·호스·벨트·뒤 쇼바·퓨즈 | $16~32, 혼자 브레이크·서스 |
| **Senior Tech** | 선임 기술자 | ★1~★2 빠르게 + **'Help' 받기**(§5) | $30~45, 후배 지도 |
- **★3 이상·진단 두 단계·녹(★4)·복원·시대 차 = 플레이어만**(Master Tech는 없음 — 그게 플레이어).
- 몫은 **모든 직급 30 %**(GPT r1: 승진하며 몫이 오르면 가게 몫이 줄어 '손해'로 먼저 보임). 직급 차이 = **맡는 일**과 뽑는 값. 30 %는 진짜 '기술자 임금 ≤ 공임 매출 35~40 %'(carbook §6-5) 안이지만 정답 근거가 아닌 게임값. 부품값 이익·팁은 가게(플레이어) 것.
- 'C/B/A-tech' 같은 공식 정의 없는 이름 X(carbook §1). ASE 이름·로고 X → 배지는 **'Brakes Certified'** 같은 우리 이름.

## 3. 뽑기 — 지원자 3명 (돈 ↔ 능력치)
- 게시판 탭 → **카드 3장**(이름 · 얼굴 · 막대 2 + 할 수 있는 일 · Hire 값 · 몫 30 % · "Hire"). 카드는 **게임 안 하루(정비소 문 닫을 때)마다 새로**, 마음에 안 들면 그냥 기다림(새로 고침 돈 X).
- **능력 3가지**:
  | 능력 (EN / 한) | 보이는 법 | 뜻 (게임) | 근거 |
  |---|---|---|---|
  | **Speed / 속도** | 막대 1~5칸 | 일 하나 걸리는 시간 (1칸 = 내 보통 속도의 2.0배 → 5칸 = 1.2배) | 정액 효율 61~92 %+ (carbook §5) |
  | **Care / 꼼꼼함** | 막대 1~5칸 | **직원이 스스로 실수를 알아채 한 단계를 다시 하는 횟수·시간**(1칸 = 일 3건 중 1건쯤 한 단계 다시 → 5칸 = 거의 없음). 다시 할 때는 **직원 손동작으로 보임**(밴드를 다시 집어 옮김·볼트를 다시 조임) — 손님·사장은 안 멈춤 | 진짜 comeback(3 %·6 %) = '실수가 실제로 생긴다'는 근거, 빈도는 게임값 |
  | **Know-how / 솜씨** | **막대 대신 "Can do: wheels · batteries · pads" 목록**(GPT r1 — 안 보이는 막대 X) | 칸마다 그 직급 일이 이름으로 하나씩 열림 · 다 열리면 승진 조건 | 직급·자격 (§1·§2) |
  - **직원은 늘 내 보통 속도보다 느림**(5칸도 1.2배) → 내가 직접 하면 늘 더 빠르고 팁도 내 것.
- **Hire(뽑는 값, 한 번)** — 지원자 능력 합에 비례(같은 직급 안 '시급 범위'를 한 번 값으로):
  | 직급 | 싼 카드 (합 4) | 보통 (6) | 비싼 카드 (8) |
  |---|---|---|---|
  | Lube Tech (Lv6) | **$300** | $700 | $1,200 |
  | Service Tech (Lv10) | $1,500 | $2,500 | $4,000 |
  | Senior Tech (Lv16) | $4,000 | $6,500 | $10,000 |
  - 첫값 기준: Lv6 혼자 시간당 돈 약 $4,500(econ_sim) → 싼 카드 = 약 4분 일한 돈, 비싼 카드 = 약 16분. **시뮬로 맞춤**(§8).
- **싼 사람 + 교육 vs 비싼 사람**(GPT r1 계산 요청 — **한 가지 성장 길의 예**, 모든 능력이 같아진다는 뜻 X): Lube 싼 카드(Speed 1·Care 1) $300 + 교육 4번(1→2 $140 · 2→3 $280 × 두 능력) = **$1,140 ≈ 비싼 카드 $1,200**(Speed 3·Care 3 쯤) → **싼 길 = 시간(교육 4번)·키우는 재미, 비싼 길 = 바로 씀**. 시뮬로 어느 쪽도 함정이 아닌지 확인.

## 4. 일하는 모습 (진짜 순서, 글 없이 보임)
- 직원은 **손님 줄에서 내가 안 고른 차를** 맡음: 손님 카드에 작은 직원 얼굴 + "Sam will take this" → 내가 먼저 누르면 내 것(내가 늘 먼저). ★3 이상은 직원 얼굴이 안 붙음. **내가 최근 3분 안에 정비 동작을 안 했으면 새 차를 안 맡음**(맡은 차는 끝냄).
- 차를 직원 베이로 몰고 → **잭 → 스탠드 → 바퀴 너트 별 순서 → 부품 → 카트 OLD/NEW → 끼우기 → Final check** — 내 차와 같은 `PartGraph.path`·같은 공구·같은 소리(wr-dev '자동 분해 봇' 재사용 + 걷기·손동작). 내가 보면 **배우는 장면**(이 볼트는 이 공구).
- 머리 위 작은 진행 막대 하나만(글 X). 끝나면 손님이 직원에게 손 흔들고 감 + 돈이 정비소 HUD로 날아옴(돈 날기 재사용).
- ~~Double-check(노란 ?)~~ — **뺌**(GPT r2: 드물고 안 가도 풀리면 할 일이 아니라 기다림). 꼼꼼함은 위 Care처럼 **직원이 다시 하는 손동작·시간**으로만 보임.
- 돈: 손님 공임 × 0.7 가게로 / 0.3 직원에게(화면엔 "Shop +$84 · Sam +$36" 한 줄 — 오늘의 영수증에도).
- **평판 0 %**(GPT r1 — 50 %면 ★1이 많은 Lv6 앞뒤에서 레벨이 너무 빨라짐). 시뮬로 괜찮으면 나중에 **올리는 건 선물**(내리는 건 빼앗기 — README)이라 0에서 시작.

## 5. 'Help' — 진짜로 두 사람이 하는 단계
- 진짜 정비엔 **"누가 브레이크를 밟아 줘"**(액슬 너트 E1·브레이크 공기 빼기) · **"같이 들어"**(엔진 크레인·변속기·앞유리) 같은 두 사람 단계가 있음.
- 순서(GPT r1): **먼저 친구에게 부탁**(친구 화면에 "{name} needs a hand" + 길 표시) → 친구가 없거나 10초 안에 안 오면 **"Call Sam"** 버튼 → 직원이 와서 그 단계만(몫 X). **친구와 하면 더 좋음**: 둘이 같이 움직이는 장면 + 그 단계가 더 빠름(직원은 걸어오는 시간만큼 느림).
- 공개 직후 일엔 이런 단계가 거의 없음 → 이 버튼은 **★4~★5 업데이트(공기 빼기·액슬 너트·엔진 내리기·앞유리)가 올 때** 같이 켬. 직급 상관없이 아무 직원.

## 6. 교육 (돈 → 능력 +1)
- 직원 카드의 **"Train"** 하나 → 고르기(Speed / Care / Know-how) → 값 표시 → 탭.
- **교육 = 진짜처럼 '일에서 빠지는 시간'**: 직원이 가방 메고 'Training' 차에 타고 감 → 돌아옴. **첫 교육 = 1분**(효과를 바로 봄 — GPT r1 "돈 냈더니 없어졌다" 막기), 그 뒤 **5분**(내가 나가 있어도 시간은 감, 돌아오라는 알림·보상 X). 돌아오면 "Sam is back: Care ★★★" + Know-how면 **새로 맡는 일의 차를 바로 다음으로**. 교육 중엔 그 베이 빔.
- 값(첫값): 다음 칸 = **그 직급 Hire 보통 값 × (지금 칸 ÷ 5)**. 예: Lube Tech Care 2 → 3 = $700 × 0.4 = **$280**, 4 → 5 = $560. 같은 능력 5칸이 끝.
- **새 일이 안 열리는 Know-how 교육은 안 팖**(버튼 회색 + "Knows every Lube Tech job — ready to promote!").
- 진짜 근거: 가게는 1인 연 40~100시간 교육, 하루 $200~1,800(carbook §4·§6-4).
- **직급 오르기 = 자격 배지**: 그 직급에서 **일 20건 + 그 직급 일이 다 열림** → "Promote to Service Tech?" 카드 = **"New jobs: brake pads · hoses · rear shocks"**(새로 맡는 일이 먼저 보임) + 배지('Brakes Certified' 액자가 사물함에 — 진짜 '시험 + 실무 경력' 모양). 승진은 공짜, **몫 그대로**. 승진하면 Know-how 목록은 새 직급 첫 줄부터. (Service → Senior 승진은 **Lv15**부터 — economy v0.5, Senior 지원자 카드는 Lv16.)
- 직원은 **안 떠남**(carbook §6-4). 'Let go'(내보내기)는 카드 아래 작은 글씨 + 확인 한 번, 돌려받는 돈 X.

## 8. 숫자 균형 (econ_sim으로 맞출 것 — 첫값의 목표)
- **목표**: 혼자 + 직원 1명 = 혼자보다 **방장 시간당 돈 +25~35 %**, **레벨 속도 그대로**(평판 0 %). 친구와 비교는 `CoopShare`(같은 차를 같이 고칠 때 1인 몫)로 하지 말고 **시뮬의 '방장에게 실제로 들어오는 돈'**으로(GPT r1). 친구가 와도 방장 돈이 줄지 않아야 함.
- Hire 회수: 보통 카드가 **약 30~50분 일하면** 본전.
- 시뮬: scratchpad `money_sim*.py`처럼 econ_sim CONFIG에 `staff = { count, speed, care, share = 0.3, rep = 0, maxStar = 2, idleStop = 180 }` → 결과로 §3·§6 값 고침.
- **monetization v2와 겹침**: Pay Boost ×1.5는 **플레이어 공임·팁만**(직원 몫 X) · 봉투 돈으로 직원 뽑기 가능(게임 돈이라 OK, 하루 상한 그대로).

## 9. 데이터·코드 (wr-dev — 공개 뒤)
- 저장: `staff = { { id, name, look, rank, speed, care, know, jobs, trainingUntil, trainedOnce } … }`(최대 3).

# 기대 배신 막기 + 좋은 속임수 값 (feel_guards) — v0.1 (wr-design, 2026-10-21)

> game_textbook v0.2 법칙 1(기대와 배신)·3(좋은 속임수)에서 GPT가 짚은 3개 + 좋은 속임수 값. 관련: alpha_scope §2(생성기·Scanner 규칙), fault_catalog, tutorial_script, flip_loop.

## A. 기대 배신 3개 → 설계로 막기

### ⓐ Lv3 첫 함정 차 — "스캐너는 빨간데…가 아니라, 다 초록인데 고장"
첫 차가 가르친 규칙(스캐너 빨강 = 고칠 것)이 처음 깨지는 순간. **설명문이 아니라 플레이로** 납득시킴.
| 장치 | 내용 |
|---|---|
| **첫 함정 고정** | 플레이어의 **첫 함정 = BAT_CORROSION**(배터리는 멀쩡, 단자 부식) — 그 플레이어가 Lv3 된 뒤 **두 번째 손님**(레벨 업 직후 첫 차엔 함정 X 규칙 그대로), Regular 손님(Hurry X) |
| **손님 말이 모순을 알려 줌** | "It's clicking again… but I just bought a new battery!" (또 딸깍거려요… 배터리는 새로 샀는데!) |
| **눈에 보이는 단서** | 보닛 열면 **단자에 하얀 가루가 반짝**(파티클, 큼직하게) |
| **스캐너** | 배터리 **초록** + 그 옆 작은 꼬리표 **"Part: OK — check the connections"**(부품은 괜찮아요 — 연결을 봐요) |
| **테스터(Lv2에 샀으면)** | "Battery reads fine — check the terminals." |
| **처음 한 번만 배너** | **"The Scanner shows how worn a part is — not dirty or loose connections."**(스캐너는 부품이 닳은 정도만 보여 줘요 — 더럽거나 헐거운 연결은 아니에요.) |
| **고친 뒤** | Clean terminals → 시동 '부릉'(ⓑ) → Spot On! + 숨은 업적 "It's the Connection!"(retention_social §5 숨은 업적에 추가 제안) |
| 그 뒤 함정 | 같은 3단 신호: **손님 말의 모순 + 눈에 보이는 단서 + 스캐너 초록 꼬리표** — 모든 함정(MUF_HANGER·TAILPIPE_VAPOR·BATTERY_CLAMP_LOOSE·연료 캡 등)에 같은 규칙 |

### ⓑ 정산 전에 **증상이 사라지는 순간** 먼저
"고쳤는데 결과가 안 보임"을 막음. 마지막 볼트를 조이면(그 고장이 다 고쳐지면) **정산보다 먼저 '증명 순간'**을 자동으로 2~3초:
| 고장 | 증명 순간 (자동) |
|---|---|
| 배터리·단자·발전기 | 시동: **딸깍(전) → 부릉(후)**, 헤드라이트 켜짐, 계기판 깜빡임 멈춤 |
| 브레이크 패드·디스크 | 브레이크 밟기: **끼익/드르륵(전) → 조용(후)** |
| 타이어 | 차가 **기울었다가 똑바로**, 쉬익 소리 멈춤 |
| 라디에이터 | **김이 멈추고** 온도계 바늘이 가운데로, 웅덩이 마름(서서히) |
| 머플러 | 시동: **우르릉(전) → 조용한 공회전(후)**, 덜렁거림 멈춤 |
| 범퍼·보닛 | 판이 **'딸깍' 제자리**, 틈이 고르게 |
| 함정(단자·걸이·캡) | 위와 같은 그 증상의 증명 순간 |
- 고장이 여러 개면 **마지막 하나를 고친 순간**에 모두 한 번에.
- 지금 코드: 전후 비교는 Job Card 버튼(+ 튜토리얼 첫 두 일만 자동) → **모든 일에서 자동 1회**, 버튼은 다시 듣기.

### ⓒ 복원 — "다 고쳤는데 왜 못 팔아?" 를 **사기 전에** 보여 주기
| 장치 | 내용 |
|---|---|
| **감정 카드(사기 전)** 맨 위 줄 | 타이틀 도장 + **"Can sell: Showroom ✓"** 또는 **"Can sell: Dealer only until it passes State Inspection"** 또는 **"Parts & scrap only (JUNK)"** |
| **필요한 것 줄** | "Needs: State Inspection" · "Needs: Showroom (Garage Lv 9)" 처럼 잠긴 것만, 자물쇠 아이콘 |
| **복원 베이 체크리스트** | 필수 작업 + **판매 조건**(검사)까지 한 목록, 다 차면 큰 초록 **"Ready to sell!"** |
| 판매 버튼 | 조건이 안 됐으면 **누를 수 없는 회색 + 이유 한 줄**(눌러서 실패 X) |
- flip_loop §1-1(타이틀)·§3(복원)에 이 줄들을 넣음(아래 board).

## B. 좋은 속임수 값 (몰래 돕기 — 정답은 안 알려 줌)
| 속임수 | 값 | 메모 |
|---|---|---|
| **같은 차에서 두 번 오진** | 오진 2번째 → 그 고장의 단서를 **더 분명하게**: 소리 +50%, 반짝·웅덩이 진하게, 손님이 한마디 더("It's that clicking again..."). 3번째 → 그 **구역**(엔진룸 왼쪽 등)만 살짝 빛남(부품 X) | 오진 = 멀쩡한 부품을 바꿈 |
| **같은 고장 연속 막기** | 같은 종류 **3연속 금지**, 같은 변형 직전 2대 안 X(alpha_scope §2-2 그대로) | 지금 `FaultService.roll` 균등 추첨 → 코드 필요 |
| **첫 폐차 감정 보장** | 플레이어의 **첫 폐차장 방문** 때 10자리 중 **하나는 반드시 '살 만한 차'**: CLEAN, 고장 2개, 예상 이익 ≥ $1,200, 숨은 고장 없음. 폐차장 사장 힌트 "That blue one by the gate's a good deal." | Lv8 확정 시대 차 의뢰(Starlane)와 별개 |
| **첫 복원 등급** | 첫 복원은 필수 작업을 다 하면 **최소 Bronze**(외관·청결 점수 바닥 60%) | 실패 연출 X |
| **첫 함정** | 위 ⓐ 고정(BAT_CORROSION, Regular, 레벨 업 직후 X) | |
| **같은 손님 반복 실망 막기** | 직전 출고에서 별 3 이하였던 단골은 다음 방문 때 **쉬운 고장**(Lv 기준 1개) | 단골 이야기 회복 |
- 하지 않는 것: 확률 팔기, 아깝게 실패한 연출, 시간 한정 압박(monetization v1·game_textbook 3).

## C. 검사 질문 5개
1. 기대: 첫 함정에서 "스캐너가 틀렸다"가 아니라 "스캐너는 부품만 본다"로 기대를 고쳐 줌 / 복원은 사기 전에 팔 수 있는지 앎 ✓
2. 따뜻함·틀려도 괜찮음: 오진이 늘수록 도움이 늘어남(벌 X) ✓
3. 보정: 두 번 틀리면 단서가 커짐, 팔 수 없는 버튼은 처음부터 회색 ✓
4. 눈에 보이는 반응: 증명 순간(소리·김·기울기)이 정산보다 먼저 ✓
5. 정비소가 자란다: 새 숫자 X(꼬리표·체크리스트는 그 자리 안에서만) ✓

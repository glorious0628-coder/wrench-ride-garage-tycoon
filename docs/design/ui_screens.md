# 첫 15분 튜토리얼 + 화면(UI) 목록 — v0.2 (wr-design, 2026-10-20 밤, GPT 1라운드 반영)

> 나중에 UI 세션이 이 파일로 화면을 만들어요. 화면 글자 = **영어 원문**(한국어는 Locale 번역). 새 이모지 X(▯로 깨짐) — 아이콘은 그림으로.
> 그림체 B(둥근 캐주얼), 유튜브 배울 점: UI는 멈춰 있지 않게(버튼 눌림 % 배율 + 탄력, 창은 페이드·슬라이드), 바뀌는 글자 = Studio 글자 + 테두리, 폰 화면을 처음부터 같이 확인.

## 1. 첫 15분 튜토리얼 흐름

원칙(GPT 토론 fun_r1·r2): 긴 설명 X, **차가 단서를 줌**, 첫 수리는 반드시 성공, 5분 안에 "와"(시동 성공 + 손님 환호), 매 단계 화면에 **할 일 한 줄 + 화살표 1개**만. 건너뛰기 버튼 있음("Skip tutorial" — 두 번째 계정·다시 하는 사람용).

| 시간 | 장면 | 화면에 뜨는 것 (영어 원문) | 끝나는 조건 |
|---|---|---|---|
| 0:00 | 정비소 앞에서 시작. 낡은 세단이 덜컹거리며 들어와 Bay 1에 섬. 손님 **Mrs. Rosa Delgado** 내림 | 말풍선: "Oh, thank goodness! My car won't start — it just goes click-click-click." / 할 일: **"Talk to the customer"** + 손님 위 화살표 | 손님 Prompt |
| 0:20 | 작업 카드 생김 | Job Card(두 줄): "Rosa's Sedan · Won't start (clicking)" / 할 일: **"Try to start it"**(운전석 Prompt) → 딸깍딸깍 + 계기판 깜빡(차가 주는 단서) | 시동 시도 |
| 0:45 | 보닛 열기 → 진단 | **"Open the hood"** → **"Check the battery with the Scanner"**(지금 코드 Locale `tip.first`와 같은 규칙: **Scanner를 들고 부품을 탭 = 진단**) → 배터리 빨강 | 배터리를 Scanner로 탭 |
| 1:15 | 첫 진단 성공 | 작은 배너 "Found it! Dead battery." | 자동 |
| 1:25 | 부품 상점 | **"Buy a new battery"** · 상점은 배터리 1줄만 크게 | 구매 ($90, 시작 $600) |
| 2:00 | 떼기 — **한 줄로 묶음** | **"Disconnect: − first, then +, then the clamp"** → 볼트 3개가 **차례대로 하나씩만** 반짝(− 먼저 — 실제 순서는 그대로 배움) → **"Lift it out"**(두 손) | 헌 배터리 듦 |
| 2:40 | 내려놓고 끼우기 | 헌 배터리는 **아무 데나 내려놓기**(고물통은 출고 뒤 선택 보너스) → **"Put the new one in"** → 스냅 → **"+ first, then −, then the clamp"** | 볼트 3개 조임 |
| 3:20 | 시동! | **"Start it up!"** → 부릉! 헤드라이트 켜짐 + **그 자리에서 바로 "click-click → vroom" 전후 소리 비교**(2초) | 시동 성공 |
| 3:40 | 출고 + 정산 (첫 판만 큰 축하) | 손님 환호·춤 / Payout 카드: Parts $117 · Labor $120 · Fast tip $80 · **First job bonus $150** · Spot On! +15% → 합계 약 **$500**(표시는 Config 계산 그대로) · Rep +15 → 같은 카드 아래 줄에 **Garage Level 2!**(창 두 개 연달아 X) | 카드 닫기 |
| 4:10 | 선택 보너스 | 작은 배너 "Toss the old battery in the scrap bin for $15" + 화살표(안 해도 진행) | — |
| 4:30~8 | 두 번째 차: 첫 **추리** | 손님 Tyler(급함): "My brakes are squealing!" / **"Try the brakes"**(끼익 단서) → **"Raise the lift"**(Wheel 높이) | 리프트 올림 |
| 8~11 | 바퀴 → 패드 | **"Loosen the 5 lug nuts"**(손 렌치 클릭 — 바퀴 손맛은 프로토 핵심이라 유지, 한 개 0.32초) → **"Roll the wheel off"** → **"Unbolt the caliper (2)"** → **헌 패드 vs 새 패드 나란히** → **"Swap the pads"** → 다시 끼우기는 **"Hold to tighten all"** 한 동작(첫 패드 일만) | 바퀴 다시 끼움 |
| 11~13 | 비교·출고 | 브레이크 밟기 → **끼익 → 조용** 바로 비교 | 출고(이번부터 정산은 **짧은 배너**) |
| 13~15 | 다음 궁금증 | 세 번째 손님 말풍선만: "Something's rattling under my car…" / 할 일 칸 "What could it be?" + 작은 목표 **"Reach Garage Level 3"**(Rep 45 = 세 번째 일로 닿음) | 튜토리얼 끝(이후 화살표 X) |

- 실패해도 막히지 않게: 30초 동안 진행이 없으면 화살표가 다시 깜빡 + 할 일 줄이 흔들림. 틀린 부품을 사도 "Hmm, that's not it." 한 줄 + 되팔기 가능.
- 협동으로 시작하면: 방장 화면 그대로, 친구에게도 같은 할 일 줄(누가 해도 진행). 정산은 "Team pay $X each"(Config.CoopShare 계산 그대로).
- 바뀐 점(GPT 1라운드, 동의): 배터리 단계를 한 줄로 묶음, 고물통은 필수 경로에서 뺌, 시동 순간 바로 전후 비교, 정산+레벨업을 한 카드로, 첫 시동 목표 3~4분. **내가 지킨 것**: 바퀴 너트 5개·캘리퍼 2개는 그대로 클릭(GPT는 한 동작으로 묶자 했지만, 로드맵 1의 핵심 손맛이 '바퀴·패드 탈부착'이라 — 대신 다시 조이기만 한 동작).

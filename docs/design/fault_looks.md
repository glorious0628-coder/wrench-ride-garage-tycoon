## 0. 규칙
1. **고장은 보이게, 원인은 내가 찾게** — 모습은 단서지 답이 아님(손님 말 = 증상만, fault_catalog §0).
2. **고친 전후를 같은 화면에서**: 헌 부품이 카트에서 새것 옆에, 통 수위가 눈앞에서 차오름, 꺼진 등이 켜짐(GPT r1 — 첫 15분엔 고장 종류보다 이게 먼저).
3. 짧은 일(1~2분)과 큰 일(배터리·패드)을 섞음. 짧은 일의 재미 = **빨리 끝나는 손맛 + 손님 반응**, 돈은 작게.
4. 실제 규칙과 어긋나는 연출은 X(예: 빨간 오일 **압력**등 = 단순 오일 부족 표시가 아님 → OIL_LOW 단서로 안 씀).

## 3. 고장이 아닌 '보이는 단서' 장치 (공통)
- **차 밑 웅덩이**(바닥 데칼): **색 맞히기 퀴즈로 만들지 않음** — 색 + **자리** + 냄새 꼬리표 + 웅덩이가 커지는 속도를 같이(carbook ②-3 [22]). 세단 고정:

| 색 | 무엇 | 자리 |
|---|---|---|
| 갈색~검정 | 엔진오일 | 엔진 아래 |
| **분홍**(캠리) | 냉각수(단 냄새) | 엔진 아래·앞 |
| 빨강 | 변속기액(ATF) | 가운데 |
| 파랑 | 워셔액(호스 빠짐) | 차 앞 아래 |
| 거의 투명~연노랑 | 브레이크액 | **바퀴 근처**(안전 — 바로 고침) |
| **투명한 물** | **에어컨 물방울 = 정상** | **앞좌석 아래쯤** — 한 번 배우는 사건("It's just A/C water. No repair needed.") |
- 캠리는 전동 스티어링이라 파워스티어링액 웅덩이 없음, FF라 뒤 차동기어 오일 없음(다른 차종 손님용으로 미룸).
- **배기 연기**: 추운 날 흰 김 = 정상(이미 있음), 데운 뒤에도 진한 흰 연기 = 냉각수(나중), 파랑 = 오일(나중), 검정 = 연료 과다(나중) — 08_exhaust.
- **배터리 단자 부식**(BAT_CORROSION 데칼): (+) 쪽 **파랑·초록**, (−) 쪽 **흰·회색** 두 가지 [21], 닦으면 반짝.
- **'아무것도 안 고치는' 정답 6개**(carbook ②-5) — 함정 차례로 씀: ① 투명 물 = 에어컨 ② 추운 아침 흰 김 ③ 브레이크액 조금 내려감 = 패드만큼 정상 ④ 아침 TPMS = 공기만 ⑤ 흰 'Maintenance Required' = 알림 ⑥ 한 방향만 번지는 와이퍼 = 겨울용 워셔액.

## 4. Final check 덤 (작은 일 발견)
- work_view §2d **Final check**에서 가끔 작은 일이 보임: **Lv3+ 약 10%, 차당 1개, 급한 손님(Rush) 제외**, Lv6+ 숨은 두 번째 고장과 같은 차엔 안 겹침.
- 실제 근거: 타이어 가게들이 공기압·배터리·와이퍼·브레이크를 **무료 눈 점검**하고 고칠 게 보이면 견적을 냄 [15] → Final check 덤과 같은 흐름.
- 수락 전에 **할 일 + 보수**를 보여 줌("Washer's almost empty — top it up? +$15 · ~20 s"), 거절해도 별점·팁 깎지 않음.
- 보수(부품값 뺀 순수익): 워셔액 **+$15**, 와이퍼 **+$25**, 전구 **+$20**, 타이어 공기 **+$10**(실제로 거의 무료 — 대신 손님 반응·별점 +). 기본 공임 $120보다 작게(작은 일이니까).
- 코드는 **사람 시험 뒤**(교과서 결정: 새 보상 루프는 시험 뒤).

## 5. 크기 (wr-dev)
- 시험 전 A 3개 = **M×3** + 전후 비교 연출(카트에 나란히, S).
- 시험 뒤 B: 하나하나는 M이지만 **같이 넣으면 L** — 새 부품 슬롯(WasherTank·Wiper·Bulb·Dipstick·AirFilter), 상점·정산, 스캔 구역 연결(§2d 구역표에 추가), 작업 카드 문구, 수리 전후 상태 저장, 폰에서 작은 전구·못 집기(GPT r1).
- 3D/빌더 — **먼저 넣을 3개(carbook 제안)**: ① 냉각수·브레이크액 통(이미 있음)에 **F/L·MAX/MIN 줄 + 높이 바뀌는 안쪽 액** ② **바닥 웅덩이 데칼**(투명 물 포함) ③ **와이퍼 팔·고무 + 보닛 워셔 노즐 2 + 분사 FX**(제일 흔한 덤 일인데 지금 없음). 그 밖: 와이퍼 2단, 방향지시등 소켓·전구, 딥스틱, 필터 2단, 눌린 타이어, 못, 웅덩이 데칼 4색.
- 소리(wr-sound): 워셔 '푸쉭'·물줄기, 와이퍼 '딸깍', 전구 소켓 돌림, 공기 '쉬익', hyperflash 빠른 똑딱.

## 0. 왜 보강이 필요한가 (한 줄씩)
- 가장 가까운 경쟁작 Roblox **"Fix It Up!"**(폐차 수리→판매): 최고 동접 1.7만, 하지만 **평균 15분·좋아요 85%** → 같은 수리 반복이 약점.
- PC **Car Mechanic Simulator**: 분해·조립 손맛과 '배우는 느낌'이 칭찬, 불만은 반복·스토리 없음·초반 돈 느림·정적인 경매.
- 유튜브 배울 점: 알고리즘은 **세션 길이·재방문·수익**을 봄, 친구 요소가 퍼지는 힘, 80% 익숙 + 20% 새로움, 킹피스 반면교사 = **할 게 떨어지는 구조**.
- → 우리 답: **매번 다른 수수께끼(진단) + 짧은 손맛 + 같이 하면 더 신남 + 모으기(시대 차)**.

## 3. 수익화 — 기획서 상품 판정 (사용자 결정 필요)
| 기획서 상품 | 판정 | 대안 |
|---|---|---|
| 골드 전동 공구 패스 (해체 50% 단축) | pay-to-win | **골드 외형·이펙트·소리만**. 속도 업그레이드는 플레이로 모두가 같은 최고 속도까지 |
| 폐차장 VIP 레이더 (희귀 확률 증가) | pay-to-win | 이미 나온 매물의 **위치·상태 미리보기 표시**, 레이더 스킨. 확률은 모두 같게 |
| 견인차 즉시 호출 | 경계선 | 모두에게 짧은 기본 대기. 유료 = 견인차 외형·등장 연출 |
| 대형 카캐리어 (2~3대) | pay-to-win | 적재량은 게임 안 업그레이드. 유료 = 캐리어 외형·도색 |
| 커스텀 간판 & 네온 쇼룸 | OK (치장) | 그대로 |

**새로 팔 것 (외형·편의만, 시간당 돈·속도·확률에 영향 X)** — 예상 판매 순위(데이터 없는 가설, 출시 뒤 구매율로 바꿈): ① **차 도색 무늬·특수 마감**(기본 색은 무료로 충분히) ② **정비소 테마·간판·네온**(친구가 방문해서 봄) ③ **공구 스킨·이펙트·소리**. 그 밖에: 출고 연출·경적, 복원차 전시 받침대·명판, 사진용 차고 배경, 정비사 옷·이모트, 대기실 주크박스(개인 음소거 필수), 싼 첫 구매 'Starter Look' 묶음.
- 개인 서버: Roblox 기본 기능 그대로. 협동·희귀 차 얻기를 개인 서버 구매에 묶지 않음.
- 친구 초대 보상: 작은 외형 1회만(반복 초대 유도 X).
- 꾸미기 일부는 Cash로도 살 수 있게(유튜브 배울 점: 돈 안 써도 목표).
- 외형만으로 유지비가 충분한지는 지금 단정 못 함 → 처음엔 상품 몇 개만, 제작비·구매율을 재면서 늘림.

## 4. 첫 15분 흐름 (제안)
| 시간 | 경험 |
|---|---|
| 0~2분 | 고장 세단 도착, 손님 한 문장 + 눈에 보이는 단서, 보닛 열기 |
| 2~5분 | 배터리 1개 수리 → 시동 성공 → 손님 환호·첫 보상(첫 장비를 바로 살 만큼) |
| 5~8분 | 두 번째 차: 후보 2개, 소리·계기판으로 고르는 첫 추리 |
| 8~11분 | 리프트로 패드 또는 머플러 — 다른 자리·다른 동작 |
| 11~13분 | 출고 확인, 전후 비교 소리, 친구와 함께 확인 |
| 13~15분 | 다음 차의 수상한 증상 + 작은 목표 공개(이미 배운 기술로 풀 수 있게) |

## 5. 15분 이후 (1~5시간) — 새 장비를 계속 주기보다 '아는 작업에 새 단서·다른 원인·다른 결말'
(레벨마다 새 일, 30~45분마다 새 장소는 제작량이 너무 큼 — GPT 지적 받아들임)
| 시간 | 먼저 열 경험 |
|---|---|
| 15~45분 | 패드·머플러로 작업 자리 바꿈. 첫 단골이 다시 와서 앞 수리를 기억 |
| 45~90분 | 짧은 시운전 + 첫 헷갈리는 짝(배터리 vs 단자 — 눈으로 구별 가능) |
| 1.5~3시간 | Roadside Call(#18) |
| 약 3시간 | 폐차장 + 첫 확정 복원차(시대 차 1대 — era_cars), 세척·숨은 발견물 |
| 3~5시간 | 두 단계 진단 고장(발전기 등), 전시·쇼룸 판매, (베타) 선택형 흥정 |

## 5. 프로토타입에 넣을 것 (3개)
1. 진단 추리 간단판(#1) — 배터리·타이어·패드 중 한 고장, 첫 수리는 반드시 성공.
2. 손맛(#2) + 극적 첫 출고(#3) + 전후 비교(#4).
3. 협동 간단판(#5) — 다른 작업 동시, 모두 보상, 두 손 부품 혼자도 가능.

# 업데이트 리듬 로드맵 (update_roadmap) — v0.2 (wr-design, 2026-10-22 밤 — 매주 표, 해치백·픽업 포함) · v0.1 (2026-10-21)

> tycoon_analysis: 조사 = **2주~1달 작은 업데이트**가 유지에 좋음, 폐차 수리 장르는 반짝하고 내려옴(Fix It Up!·Repair a Car), 유튜브 배울 점 = 킹피스 반면교사(업데이트 공백·밸런스 망치기). retention_social §7: **2~4주마다 수정·작은 변형**, 새 차는 **다 만든 뒤 날짜 공지**, 얻은 것 너프 X.
> 날짜는 **공개(게시) 날짜 = D**를 기준으로 셈(아직 미정). 큰 결정(새 루프)은 사람 시험 결과를 보고.

## 1. 원칙
- **한 업데이트(매주) = 하나의 주인공 + 작은 것 2~3개**(공지에 한 줄로 말할 수 있게: "New: Couch Car! + 3 new brake problems").
- 주인공 순서: **같은 차의 새 문제(변주) → 밈 차 → 변형 키트 → 새 차종 → 시즌**(싸고 빨리 '새 문제'를 주는 것부터 — 차체 늘리기 전에 변주).
- 매 업데이트에 **버그 수정·밸런스**(econ_sim으로 확인) 포함, 이미 얻은 것 줄이지 않기.
- 공지: 게임 안 작은 배너 + 게임 페이지 'Updates' + (있으면) 경험 알림 주 1회 이하(retention_social §4).

## 3. 미리 쌓아 둘 것 (업데이트 재고)
- 고장 변주: 부품마다 2~3개(fault_catalog §1b) → 업데이트 2~3번 분량.
- 밈 차 10종(car_variety §3) → 한 번에 1~2종씩 5번 분량.
- 변형 키트: 2차 묶음(앞범퍼 +1, 휠 +2, 스티커 +2).
- 시즌 외형: 겨울·핼러윈·여름 각 3~5개.

## 4. 검사 질문 5개
1. 기대: 업데이트마다 "새 문제/새 차"가 하나 분명히 — 공지 한 줄 ✓
2. 따뜻함: 얻은 것 너프 X, 한정 압박 X ✓
3. 보정: 2주가 버거우면 늘리되 4주 공백 X ✓
4. 눈에 보이는 반응: 주인공은 늘 '보이는 것'(새 차·밈 차·새 증상) ✓
5. 정비소가 자란다: 새 차·새 변주가 정비소 일감을 넓힘 ✓

> 도구: `py tools/econ_sim.py --players N --runs 300 --hours 22 [--grade-rep B,S,G] [--market $] [--team-bonus x]` — 그림 X, 숫자만. economy v0.2 · alpha_scope v0.3 · flip_loop v0.2 숫자를 파일 맨 위 `CONFIG`에 복사(어떤 숫자로 돌렸는지 그 파일이 기록).
> 원본 출력: `notes/sim/v2_code_p1·p2·p4.md`(지금 코드 값), `v2_prop_p1·p2·p4.md`(제안 값), `v2_prop_tb_*`(팀 보너스 시험). 처음 판(v1, `base_*`·`fliprep_*`)은 가정이 틀려서 참고만.

## 1. 시뮬 가정 (v2)
| 항목 | 값 | 근거 |
|---|---|---|
| 일 1건 시간 | 고장 1개 5.0분 + 하나 더마다 2.6분, × 아이마다 다른 속도(로그정규 σ 0.35) | 튜토리얼·fun_boost '5분/건' |
| 장비 속도 | Ratchet 0.92 · Impact 0.85 · 유압 리프트 0.95 · OBD 0.95 · 테스터 0.97 | 추정(측정 필요) |

| 손님 기분 | **실제 걸린 시간**으로 Calm/Restless/Upset(Regular 7·11분, Hurry 5·8분) | alpha_scope §1-1 (GPT 지적: v1은 시간과 무관하게 뽑았음) |
| 함정 | Lv3~5 5% · Lv6+ 10% — 부품 이익 없음 | alpha_scope §2-4 (GPT 지적) |

| 복원 | 복원 베이를 사면 손님 7건마다 1대, 40분 × 속도 차이. 등급 Bronze 25% / Silver 55% / Gold 20%, 타이틀 CLEAN 70%(매입 $700) / SALVAGE 30%(매입 $420, 값 ×0.65), 부품 $550, 쇼룸(Lv9+) 흥정 +4% / 그 전엔 즉시 판매 ×0.8 | flip_loop §1-1·§6 |
| 협동 | 차마다 따로 돌아감, 한 차에 k명이면 k^0.75배 빠름, 동시 차 수 = alpha_scope 상한표, 공임·팁 몫 CoopShare, 복원은 **2명까지만** 빨라지고 나머지는 손님 일 계속 | GPT 지적 반영 |

## 5. 프로토 Play에서 먼저 잴 것 (GPT 권장)
1. 레벨별 차 1대 **입고 → 인도 실제 시간** + 손님 기분·팁(시뮬의 5.0분·Calm 비율 확인)

## 1. 한 줄
**보닛을 연다 → 0.5초 만에 카메라가 엔진룸 위로 다가간다 → 화면엔 차·공구 칸·나가기·작업 카드만 → 부품을 손가락(마우스)으로 꾹 눌러 풀고, 끌어서 빼고, 끌어다 '착' 끼운다.**

## 2. 작업 구역 (Zone)
| 구역 | 들어가기 | 카메라(첫값, wr-ui가 조정) | 알파 |
|---|---|---|---|
| **EngineBay** | 보닛을 여는 순간 **자동 — 항상**(✅ 사용자 결정). 나갔다가 보닛이 열린 차에 다가가면 Prompt **"Work on engine"** | 엔진룸 앞쪽 위 비스듬히 약 40°, 엔진룸 전체가 화면 가로 약 80% | ✅ MVP |
| **Wheel**(FL·FR·RL·RR 한 틀) | 그쪽(앞/뒤)을 **잭 스탠드로 받친 뒤**(Lv1, §2b) 또는 리프트 `Wheel` 이상(Lv6) → 바퀴 앞 Prompt **"Work on wheel"** | 바퀴 정면 조금 위, 바퀴 + 캘리퍼가 화면 가운데. 잭이면 쪼그려 앉아, 리프트면 서서 | ✅ MVP |
| Bumper(앞·뒤) | 범퍼 앞 Prompt | 정면 | 그 뒤 |
| **Under**(차 밑) | 스탠드에 얹힌 차 문턱 옆 Prompt **"Slide under"** → 누움판에 누워 미끄러져 들어감(Lv1~) / 리프트 `Under`(Lv6)면 걸어 들어가 **서서** | 차 바닥을 올려다봄, **정거장 3곳**(§2c) | MVP 다음 — **시험 뒤 첫 큰 새 일 = Oil Change(Lv3)**부터 씀, Muffler(Lv6)·뒤 Shock(Lv13)이 뒤따름 |
- 카메라 자리 = 차 모델 안 어태치먼트 **`WorkCam_EngineBay`, `WorkCam_Wheel_FL`…**(car_spec·suv_spec에 추가 — 3D/빌더) + 캐릭터가 서는 자리 **`WorkStand_<Zone>`**(서버 리치 검사 기준, Config.ReachDistance 9 안).
- 전환: **0.5초** 부드럽게(들어갈 때·나갈 때 같음), 그다음 **카메라 고정**. 첫판엔 돌려 보기·확대 **X**(멀미·손가락 혼선 줄이기 — GPT r1). 대신 **막힌 부품만 짧은 시점 이동**: 예) 배터리 고정쇠가 가려지면 그 볼트를 누르는 동안 0.3초 살짝 옆으로.
- 들어가 있는 동안: 캐릭터 이동 멈춤, 다른 사람 눈엔 **보닛에 상체 숙인 자세**(바퀴 = 쪼그려 앉기). 화면 UI = **공구 칸 · Exit · 작업 카드(접힘) · Cart 버튼**만(HUD 돈·레벨은 작게 위 구석, 나머지 숨김).
- 나가기: **Exit 버튼(늘 같은 자리)**, PC는 Esc. 이동 키 **한 번으로는 안 나감**(0.5초 누르고 있으면 나감 — 실수 막기, GPT r1), 보닛을 닫으면 나감. 나갈 때 **구역·단계를 기억** → 다시 'Work on …' 하면 바로 그 화면.

## 2b. 차 들기 — 플로어 잭 + 잭 스탠드 (Lv1 기본 장비)
> 근거: carbook `under_car_work.md` §1(토요타 매뉴얼: 평평한 바닥 + **고임목 항상**, 잭 = 앞/뒤 **가운데 아래**, 스탠드 = 문턱 아래 **앞바퀴 뒤·뒷바퀴 앞**(= car_spec `LiftPoint_*`), **"잭만으로 받친 차 밑에서 일하지 말 것"**).
- ✅ **사용자 결정(10-21)**: Lv1 정비소엔 리프트가 없고 **플로어 잭 1 + 잭 스탠드 2 + 누움판 1**(기획서 5장 원안 '수동 잭', garage_growth I단계 창고와 맞음). **유압 리프트(Lv6 $2,400)** = 차를 높이 올리고 **서서** 일함 — 빠르고 편한 업그레이드, 정비소가 벽돌 건물로 자라는 순간(garage_growth II)과 같이 옴.
- **올리기 3동작**(약 10초): ① 앞 또는 뒤 **잭 자리 탭**(차 밑 가운데 빛나는 동그라미) → 잭이 굴러 들어가고 **반대쪽 바퀴에 고임목이 자동**으로 놓임 ② **Pump 꾹**(딸깍딸깍, 차가 1.5초 동안 올라감) ③ **스탠드 자리 2곳 탭**(크게 빛남 + 자석, 스탠드 '착') → 차가 스탠드에 살짝 내려앉음 '쿵'.
- 높이 = 지금 리프트 `Wheel` 값 **1.8** 그대로(차 바닥 2.3 — 바퀴가 뜨고 누움판이 들어갈 틈).
- **첫 번(Tyler)**: 잭 자리 **한 번 탭** → 고임목 → 잭 → 펌프 → 스탠드가 **3초 동안 차례로** 보이는 연출(내가 눌렀다는 손댐 + 순서를 눈으로 봄). **두 번째 바퀴 일부터** 3동작 직접 + 작업 카드 한 줄 "Now you do it: jack → pump → stands"(자리가 순서대로 빛나는 게 주된 안내). 익숙해지면 연출은 짧게, 펌프·스탠드 손맛만 남김(GPT r2 — 반복 지루함).
- 받친 쪽만 열림: **앞 스탠드 = 앞바퀴 2개 + 차 밑 Front 정거장**, 뒤 스탠드 = 뒷바퀴 + Rear 정거장. 앞뒤 다 받치려면 스탠드 4개(**'Jack Stands ×2' $300 — Middle 일이 생길 때 상점에 나옴**, 그전엔 안 보임).
- **내리기** = 버튼 하나 **"Lower car"**(잭이 다시 받침 → 스탠드 빠짐 → 내려감, 자동 0.8초).
- **안전(진짜 구성, 다치는 연출 X)**: 잭만 올린 상태에선 "Work on wheel"·"Slide under"가 회색 + **"Place the jack stands first"**. 고임목은 자동이지만 늘 보임(부품 백과 "Did you know?"에 매뉴얼 규칙 한 줄).
- **높이 바꾸기 잠금(협동)**: 누가 이 차의 **어느 작업 화면에든 있거나 부품을 들고 있으면** 올리기·내리기·스탠드 바꾸기 전부 보류 — 버튼 위에 그 친구 얼굴 + "Bob is under the car" / "Bob is working on the engine"(이유가 바로 보이게, GPT r2).

## 2c. 차 밑 누움판 작업 화면 (Under View)
- 들어가기: 스탠드에 얹힌 차 문턱 옆 Prompt **"Slide under"** → 캐릭터가 누움판(creeper)에 누워 **0.6초** 미끄러져 들어감(바퀴 구르는 소리) → 카메라가 차 바닥을 올려다봄.
- 이동: 자유 이동 X — **정거장 3곳**(폰에서 조이스틱과 작은 볼트 누르기가 겹치지 않게, 멀미 줄이기). 화면 위·아래 화살표 탭 = 누움판이 **0.4초** 굴러 옆 정거장으로. 손 닿는 범위 = 그 정거장 안.

| 정거장 | 머리 위에 보이는 것 (carbook §2 — 3D 하체 장식과 맞음) | 일 |
|---|---|---|
| **Front** | 엔진 아래 덮개, 앞 서브프레임, 아래 팔 2, 랙·부트, 스태빌, 구동축 | **Oil Change (Lv3 — 시험 뒤 첫 큰 새 일)**: 엔진 아래 덮개 작은 문 **나사 4** → (위에서) **주입구 캡 먼저** 열기 → **드레인 플러그** 풀기(기름 받이 놓기, 갈색 오일 졸졸) → **새 와셔** 끼우고 조이기 → **오일 필터** 돌려 빼고 새것 → 나와서 위에서 **새 오일 붓기** → 딥스틱 Low~Full 확인(carbook common_jobs_visible ①-3, 05_engine). 하체 점검(나중) |
| **Middle** | 배기관(앞 관·촉매·공명기) + 은색 열 차단판, 검은 바닥 덮개, 연료탱크 + 쇠끈 2 | (나중) 가운데 배기관 — 앞뒤 4스탠드일 때만 열림 |
| **Rear** | 뒤 서브프레임·팔, 스프링·쇼크, **머플러 + 고무 걸이 2** | **Muffler**(Lv6), 뒤 Shock(Lv13) |

- 조작은 §3 그대로(빼는 부품만 빛남, 볼트 꾹 0.4초, 끌기/탭→탭, 자석 '착'). **머플러(8 kg, 두 손)**: 고무 걸이 2를 손으로 빼고 볼트 2 → 끌어 내리면 **가슴 위로 받는 0.6초** → 누움판 옆 바닥에 내려놓음 → 나와서 카트로.
- 나가기: Exit / 정거장에서 아래 화살표 끝 = 미끄러져 나옴(0.6초).
- **리프트(Lv6) 판**: 같은 정거장 3곳, 카메라 = **서서 올려다봄**, 정거장 이동 0.2초, 손 닿는 범위 넓음, 리프트 효과(2배 빠름)는 작업 한 건의 체감 시간으로 확인(GPT r1). 리프트를 산 뒤 누움판을 억지로 쓰게 하지 않음 — 리프트가 다른 차에 쓰일 때(협동 베이) 누움판이 남는 쓸모.
- **하체 장식 보임 규칙**(car_spec §5): 지금 "리프트 `Under`·`Wheel`에서만" → **"차가 `Wheel` 높이 이상(리프트든 스탠드든)일 때"** — 같은 상태 하나를 읽음.
- **3D 고증 1개(메인 3D 결정)**: 실제 캠리 엔진 밑 = **검은 덮개 2장 + 오일 교환용 작은 문(나사 4개)**, 지금 3D는 은색 오일팬이 그대로 보임 → 덮개 추가 추천. 작은 문을 여는 조작은 **Oil Change 일이 들어올 때**(그전엔 장식).

## 2d. 스캔 먼저 → 구역 표시 (Scan → Check here)
- **매 차 작업 카드 첫 줄 = "Scan the car"**(사용자 요청 — 스캔이 늘 첫 단계). Scanner를 손에 들 필요 없이 **작업 카드의 Scan 버튼**(차 가까이면 켜짐) → **1.0초** 스캔 빛이 차 위를 앞에서 뒤로 쓸고 지나감 + 삐-삐 소리(wr-sound).
- 결과 = **구역만**: 그 구역 테두리가 **중립색(흰·하늘)**으로 빛나고 위에 **"Check here"** 동그라미(문제 구역이 아니라 '확인할 구역'). 작업 카드엔 **위에서 본 작은 차 지도**에 같은 구역 불. 표시 탭(가까우면) = 그 구역 Prompt로 바로.
- 상태색(초록·노랑·빨강)은 여전히 **구역 안에서 부품을 하나씩 Scanner로 탭해야** 나옴(Inspect.luau의 '클릭한 부품만 색' 원칙 그대로 — 구역 빛은 상태색과 다른 색).
- **구역 판정 = 고장 계획(fault plan)의 slot 기준**, Condition 색 기준이 아님 → 함정(단자 부식: 배터리는 초록)도 보닛 구역은 켜짐 → 들어가서 "다 초록인데?" → 더 보고 증상 시험(feel_guards ⓐ 그대로).

| 슬롯 (지금 CarParts) | 구역 |
|---|---|
| Battery · Radiator | **EngineBay** |
| Wheel_FL/FR/RL/RR · BrakePads_같은 쪽 | **Wheel_같은 쪽**(네 방향까지 — 사용자 요청. 추리는 바퀴 안 타이어 vs 패드) |
| Muffler | **Under (Rear)** |
| Hood · Bumper_F · Bumper_R | **Body_Front / Body_Rear**(바깥 차체 — 작업 화면 없이 지금 방식, 범퍼 구역은 나중) |
| (새 짧은 일 — fault_looks) | 그 부품의 구역(워셔액 = EngineBay, 와이퍼 = Body_Front …) |
- **건너뛰어도 막지 않음**: 손님 말·소리로 바로 구역에 가도 됨, 스캔 안 했다고 벌 X.
- **Final check**(출고 전 스캔, 1.0초): 고친 구역에 초록 **✓**, **숨은 두 번째 고장**(alpha_scope §2, Lv6+ 10%)은 **이때 처음** 새 "Check here"로 나타남 → "Want me to fix that too?"(처음 스캔엔 안 보여 줌 — 발견의 재미). Final check를 안 해도 출고는 됨(숨은 고장 보너스만 놓침). 진짜 정비소의 출고 전 점검.
- **업그레이드 = 수고 줄이기만**: Lv5 **Bay Scanner**($800 게임 돈, 베이 벽에 다는 장치 — 정비소가 자라는 게 벽에 보임) = 차가 베이에 들어오는 순간 **자동 스캔**(같은 "Check here"만). 계통 이름·의심 부품 수 같은 '정답 좁히기'는 안 함(GPT r1 — 후보가 적은 구역에선 정답이 샘).
- 차 밑 Rear = 지금 머플러뿐 → 구역이 곧 부품. 그래도 MUF_HOLE·MUF_HANGER(고무 걸이 함정)·MUF_SHIELD 조치가 달라 추리는 남음. 구역을 보자마자 '머플러 교체'로 뛰지 않게 **글 없는 단서**(덜렁거림·배기음·멀쩡한 머플러 초록)를 꼭(GPT r2).
- 튜토리얼 Rosa: Try to start(딸깍) → 작업 카드 **"Scan the car"**(Scan 버튼 통통) → 보닛에 "Check here" → 보닛 열기 → 작업 화면. +약 3~5초.
- 서버: `Remotes.Scan`(리치 검사) → 차의 fault plan slot → 구역 목록(CarParts 슬롯에 `zone` 칸 추가) → 클라이언트 표시. Final check = 같은 Remote + 숨은 고장 포함. 크기 **S~M**. (구현 때 맞출 것: Muffler 해금이 지금 `math.huge`로 꺼져 있음, Bay Scanner는 장비 목록에 새로.)

## 3. 직접 조작 (폰·PC 같은 규칙)
| 하는 일 | 입력 | 반응 | 서툴러도 되게 |
|---|---|---|---|
| 부품 보기 | 손가락 대기 / 마우스 올리기 | **빼는 부품만 빛남**(장식·배선 X — 교과서 1), 이름 꼬리표 | 빛나는 범위 = 부품보다 조금 큼 |
| 상태 보기 | Scanner 고르고 부품 탭/클릭 | 상태색 + 꼬리표(feel_guards) | |
| 볼트 풀기·조이기 | 렌치 고르고 볼트를 **꾹 누르기** — 누르는 동안 렌치가 돌고, 0.4초 채우면 **'딱'**(wr-sound) + 볼트 툭 | 손 떼면 멈춤, **진행 남음** | **탭도 됨**(= 0.4초 자동 진행, 꾹이 어려운 아이), 볼트 터치 범위 넓게(지금 34 px × 폰 1.6 ≈ 54 px → 60 px 첫값) |

- **'부품 아무 데나 누르면 다음 볼트'(자동 순서)는 튜토리얼과 설정 `Assist: On`에서만**. 평소엔 볼트 위치·단자 순서(− 먼저 풀고 + 먼저 조임)를 손으로 배우게(GPT r1 — 늘 켜면 배울 게 없어짐). 순서 틀림 = 지금처럼 불꽃만, 벌 X.

## 6. 협동
- **한 구역 = 한 번에 한 사람**. 이미 누가 쓰는 구역의 Prompt = "Bob is working here" + 친구 얼굴(회색).
- 다른 구역은 동시에 OK: **한 명은 엔진룸, 한 명은 앞 왼쪽 바퀴, 한 명은 뒤 오른쪽 바퀴** — 각자 자기 작업 화면.
- 같은 차의 다른 사람이 한 일은 내 화면에도 보임(부품 빠짐·볼트 돌아감) — 서버가 진짜 부품을 움직이니 자동.
- 구역 밖 친구: 카운터에서 부품 사 오기(카트로 자동 배달 = 같이 하는 이유), 시동 걸어 보기, 시험 주행.
- 차 밑(Under)도 한 구역 = 한 사람: **한 명 누움판(Rear 머플러), 한 명 보닛 위, 한 명 앞바퀴** OK.
- **차 높이 바꾸기 잠금**: 누가 어느 작업 화면에든 있거나 부품을 들고 있으면 올리기·내리기·스탠드 바꾸기 보류(§2b — 카메라·손 닿는 거리·부품 위치가 어긋나지 않게).
- 같은 구역 2명 + 부품별 잠금은 사람 시험에서 요구가 나오면(GPT r1·r2 같은 결론).

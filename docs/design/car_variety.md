# 차 디자인 다양성 + 밈 자동차 (car_variety) — v0.2 (wr-design, 2026-10-21)

> ⚠️ **사용자 규칙(10-22)**: "모양은 현실 세계에 없더라도 자동차 구조나 부품은 현실적이어야 돼" · "구조가 현실적이지 않은 자동차 절대 금지" → **겉은 자유, 속은 진짜**: 밈 차(욕조·소파·장난감…)도 겉 껍데기만 재미있고, 그 아래는 진짜 차대·엔진·변속기·브레이크·바퀴·서스가 제자리에(부품 이름·떼는 순서·공구 = full_teardown 그대로). 변형 키트도 겉만 바꿈.

> **사용자 결정(10-21)**: ① 밈 자동차 = **추천 5개 그대로**(Bathtub Car · Couch Car · Squeaky Toy Car · Duct Tape Special · Bubble Wrap Wagon) — 사람 시험 때 Couch Car는 **스프링 고장 코드가 생기기 전까지 Inside-Out Umbrella Car로**. ② 차 다양성 = **"이 정도면 좋아"**(앞범퍼 2 · 휠 3 · 소품 2 · 6색 × 단색/투톤/줄무늬 = 차종당 18가지 + 차종 늘리기). 시안(밈 차 5장·변형 키트)은 메인이 순서 정해 wr-art에, **코드·3D는 사람 시험 뒤**.

> 사용자: "차들이 디자인이 비슷한 것 같애. 디자인이 다 달라야 재밌지 않아? 밈 자동차도 있고".
> 토론: GPT 2라운드 `notes/gpt/wr-design/variety_r1_*`, `variety_r2_*`. 트림 차이 고증 = wr-carbook에 부탁(board) — ⓒ 표시는 그 결과로 확인.
> **사용자 결정 원칙**: 밈 차는 '손님 차 종류'라 새 루프는 아니지만, **코드·3D는 사람 시험 뒤**, 설계·후보 고르기는 **지금**. 밈 차 후보는 메인이 사용자에게 보여 주고 고르게 함(§3).

## 0. 순서 — '다 다르다'는 느낌은 이 순서로 생김
1. **차종 실루엣**(멀리서 높이·짐칸·지붕선) — 가장 큼. car_roster 순서 **그대로**: 세단 → SUV → **픽업** → 배달 밴 → 해치백 → 미니밴 → 왜건(픽업을 당기면 세로 엔진·후륜 축·판스프링을 한꺼번에 새로 만들어야 함 — SUV가 시험에서 세단과 안 구별될 때만 다시 봄).
2. **색 + 무늬**(투톤·줄무늬) — 메시 그대로, 싸고 크게 읽힘.
3. **얼굴·휠·소품** — 가까이서.
4. **밈 차** — 가끔 나오는 웃음.

## 1. 같은 차체 변형 키트 (첫 묶음 — 세단·SUV 먼저)
| 조각 | 첫 묶음 | 3D 크기 | 메모 |
|---|---|---|---|
| 앞범퍼 얼굴 | **2종**(기본 · 스포티) | M(`Bumper_F` 메시 2벌) | 같은 볼트·SnapAttachment 자리(교체 부품 규칙 그대로) |
| 휠(림 메시만) | **3종**(강철+휠캡 · 5스포크 · 2톤) | S(타이어·디스크·캘리퍼 공용) | 먼 차는 단순 메시(Detail/Lite) |
| 소품 | **2종**(루프랙 · 작은 스포일러) — **차마다 최대 1개** | S | 폰 성능 |
| 도색 | **6색 × (단색 · 투톤 · 줄무늬) = 차종당 18가지 겉** | S(텍스처) | **색마다 굽지 않음** — 차종별 투톤·줄무늬 **마스크 1장씩 재사용**(투명 ColorMap을 차체 색 위에 얹는 방식, Roblox SurfaceAppearance), 512px부터 확인 |
| 스티커 | 공용 도안 1~2개, 차마다 최대 1개 | S | |
| 헤드라이트 | **모양 교체 X** — 같은 외곽 안에서 **렌즈 무늬·발광 색만** | S | 보닛·펜더·범퍼 경계를 다시 맞추는 비용이 큼(GPT) |
| 손때 | 녹·찌그러짐·스티커 자국(텍스처) | S | 손님 차 성격(폐차는 더 많이) |
- 손님마다 무작위 조합, **단골은 늘 같은 조합**(Rosa = 오래된 세단 + 강철 휠, Tyler = 흰 밴).
- 트림 고증(ⓒ, carbook 부탁 중): 실제 세단·SUV에서 '등급마다 다른 것'(그릴 무늬·휠 크기·크롬 vs 검정 장식·루프랙 유무 등) → 우리 2얼굴·3휠·2소품이 그 공통 패턴과 맞는지 확인.

## 2. 차종 다양성
- car_roster v0.2 그대로(7종, 공용 부품 표). 다양성 효과: SUV(높이·리프트게이트) → **픽업(열린 짐칸 — 가장 큰 변화)** → 배달 밴(높은 상자) → 해치백(짧은 뒤) → 미니밴(미닫이문) → 왜건.

## 3. 밈 자동차 — 사용자에게 보여 줄 후보
규칙: **우리 오리지널만**(실제 영화·캐릭터·브랜드 홍보차·음식점 간판 X), **웃긴 겉모습 → 진짜 증상 확인 → 진짜 부품으로 고침**(교과서 '따뜻하고 손맛 있고 틀려도 괜찮은'). 밈 소품 자체는 고치지 않음(웃음용).

### 3-1. 첫 시험 5종 (GPT와 고름)
| 차 (영어) | 겉모습 (차종) | 손님 첫 말 (영어 / 한국어) | 진짜 고장 → 수리 | 고친 뒤 (영어 / 한국어) | 크기 |
|---|---|---|---|---|---|
| **Bathtub Car** | 픽업 짐칸에 오리 띄운 욕조 | "My duck says we have a flat. He's usually right." / 우리 오리가 펑크래요. 얘 보통 맞아요. | 물방울 소리에 가려진 **펑크 쉬익 소리** 찾기 → 타이어(TIRE_FLAT) | "The duck was right. Again." / 오리가 또 맞았네요. | M |
| **Couch Car** | 미니밴 뒷좌석 자리에 푹 꺼진 소파 | "My couch is comfy. Why is my car sitting down?" / 소파는 편한데, 왜 차가 주저앉아요? | 차 뒤가 실제로 낮고 긁힘 → **뒤 스프링 처짐**(Spring) | "Great! Only the couch sits down now." / 좋아요! 이제 소파만 주저앉네요. | M |
| **Squeaky Toy Car** | 좌석에 삑삑이 장난감 가득 | "Something squeaks when I brake. My toy denies it." / 브레이크 밟으면 삑 소리가 나요. 장난감은 아니래요. | 장난감 소리는 함정, 브레이크 밟을 때 소리 = **패드 마모**(PAD_WORN) | "I owe the toy an apology." / 장난감한테 사과해야겠어요. | S |
| **Duct Tape Special** | 은색 테이프 범벅 | "The tape said it could handle the bumper." / 테이프가 범퍼는 자기가 맡겠대요. | 테이프 들추면 **범퍼 고정부 부러짐**(BUMPER_HANGING) → 범퍼 | "Okay, the bumper wins." / 알았어요, 범퍼가 이겼네요. | S |
| **Bubble Wrap Wagon** | 왜건이 뽁뽁이로 포장됨 | "I hear pops, but why is my steering wheel dancing?" / 뽁뽁 소리는 그렇다 쳐도, 핸들은 왜 춤춰요? | 소리 말고 **떨림** 단서 → **휠 불균형**(WHEEL_IMBALANCE) → 밸런서 | "The bubbles can pop. The wheel can chill." / 뽁뽁이는 터져도 돼요. 바퀴는 이제 얌전해요. | S |
- **지금 코드로 첫 시험을 하면**(GPT가 코드 확인): `Faults.luau`에 **스프링 고장이 아직 없음** → Couch 자리는 **Inside-Out Umbrella**(아래)로 바꿔서 시험. 머플러 고장은 `Config.FaultUnlock.Muffler`가 아직 무한대(유압 리프트 뒤) — Mystery Rattle은 그 뒤.
- 차종 의존: Bathtub = 픽업, Couch = 미니밴, Bubble Wrap = 왜건 → **그 차종이 생긴 뒤**에만. 세단·SUV만 있을 땐 Squeaky Toy·Duct Tape·Inside-Out Umbrella부터.

### 3-2. 나중 5종
| 차 | 겉모습 | 진짜 고장 | 크기 |
|---|---|---|---|
| **Inside-Out Umbrella Car** | 앞에 뒤집힌 우산이 매달림 | **매달린 범퍼**(우산 치우는 게 수리의 전부가 아님) | S~M |
| **Mystery Rattle** | 트렁크에 수상한 깡통 소품 | 소품은 멀쩡 → 차 밑 **머플러 고무 걸이**(MUF_HANGER) | S |
| **Trampoline Roof** | 지붕 위 작은 트램펄린 장식 | 출렁임 = **뒤 쇼바 오일 샘** — 트램펄린 고치면 오진 | M |
| **Snowglobe Van** | 밴 안에 반짝이 눈가루 | 풍량 약함 → **실내 공기 필터** 교체(필터 고장 추가 필요) | M |
| **Clown-Horn Hatch** | 장난감 나팔 소리 경적 | **경적 커넥터**가 장난감에 꽂힘 → 원래 경적에(경적 부품 추가 필요) | S~M |
- 1라운드에서 뺀 것(이유): 피자·머스터드·아이스크림 트럭(홍보차·특정 차 연상), 과전압 노래(사실 틀림), 당김 시동 미니카(현대 정비와 충돌 — 시대 차로), 몬스터 바퀴·너무 긴 리무진(리프트·베이 전용 제작 큼 — 보류).

### 3-3. 등장·기록 (새 루프가 되지 않게)
- **Lv3부터, 손님 12~15명 중 1명**, 같은 밈 차 연속 X, 첫 시험은 4~5종만.
- 처음 고치면 **사진 벽 한 칸**(기존 도감·차 기록 안) + 짧은 정비 메모 + **작은 장식 스티커 1개**. 새 화폐·밈 전용 과제·보상 배율 X.
- 웃음 + '틀려도 괜찮아': 밈 소품이 주는 가짜 단서(오리 소리·장난감 삑삑)는 **오진 함정과 같은 규칙**(feel_guards 3단 신호) — 틀리면 단서가 더 분명해짐.

## 4. 게임 교과서 검사 질문 5개
1. 기대: 밈 차를 보면 "웃긴 차네 → 근데 뭐가 고장이지?" — 결국 진짜 정비로 끝나서 기대가 배신되지 않음 ✓
2. 따뜻함·손맛·틀려도 괜찮음: 가짜 단서로 틀려도 단서가 커짐, 손님 대사가 웃음으로 마무리 ✓
3. 보정: 밈 소품은 상호작용 X(헷갈림 줄임), 진짜 부품만 스캐너 색·Prompt ✓
4. 눈에 보이는 반응: 고친 뒤 소리·떨림·차고가 바뀜(증명 순간) + 웃긴 한마디 ✓
5. 정비소가 자란다: 새 숫자 X — 사진 벽·스티커로 '우리 정비소 이야기'가 쌓임 ✓

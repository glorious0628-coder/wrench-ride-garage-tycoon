## 1. 폐차 감정 (Junkyard)
- 마당 `WreckSpots.Spot1..10`. 산 자리는 **2~4분 뒤 새 폐차**로 채움, 안 팔린 매물은 20분마다 일부만 바뀜(보던 차가 갑자기 사라지지 않게 '일부').
- 차 고르는 확률: 일반 손님 차종(era_cars §4 순서대로 열림) 97% · 시대 차(Rare 이상) 3%(Lv8 확정 의뢰 뒤부터). Barn Find(Lv11 단서)는 따로.
- **감정 = 짧은 추리** (30~60초): 핵심 단서 2~3개만
  1. **둘러보기**(무료, 바로): 녹·찌그러짐·유리·타이어가 감정 카드에 체크.
  2. **보닛 열기**(무료): 엔진룸 부품 색(Scanner 색 규칙과 같음).
  3. (선택, 좋은 매물에만) **시동 시도**(배터리 연결) 또는 OBD Reader — 숨은 고장 1개가 풀림.
- **감정 카드**(구매 버튼 옆): 매입가 · **예상 추가 수리비 "$0~250"** · **예상 판매 이익 범위**("Est. profit $1,200~2,000"). 숨은 상태가 좋으면 '득템'(이익↑), 나쁘면 **이익이 줄어들 뿐**(일반 차 숨은 고장 추가비 최대 $250 — '사기당했다' 느낌 X).
- 값: 일반 $500~900(보이는 손상에 따라), 상태 좋은 것 ~$1,200, 시대 차는 가치 배수(era_cars §2).

### 1-1. 타이틀 도장 (미국 차 서류 — 감정 카드 맨 위에 도장 하나)
| 도장 | 뜻 | 게임 규칙 | 시세 배수 |
|---|---|---|---|
| **CLEAN** | 도장 없음 | 그대로 | 1.0 |
| **SALVAGE** | 보험사가 전손 처리(수리비가 시가의 약 70% 넘음) | 싸게 삼(매입가 약 −40%). 다 고친 뒤 **'State Inspection'**(시운전 + 안전 부품 점검, 사무실 창구)을 통과하면 **REBUILT**로 바뀜. 통과 전엔 쇼룸 X(즉시 판매만) | 통과 뒤 0.65 |
| **REBUILT** | 샐비지를 고쳐 주 검사 통과 | 그대로 팔 수 있음 | **0.65**(실제: KBB fair의 60~70%) |
| **FLOOD** | 침수 | 아래 침수 단서. 전기 고장이 숨어 있을 확률 ↑ | 0.6 |
| **JUNK** | 부품·고철용만, 다시 못 고침 | **복원 X** → '부품 떼어 팔기'만(나중: 촉매·알루미늄 휠·도는 엔진) | — |
- 첫 몇 대(Lv8~9)는 CLEAN·SALVAGE만. FLOOD·JUNK는 Lv10+.
- '타이틀 세탁'(서류 도장 지우기) 같은 불법 유혹은 넣지 않음(아이 대상).

- **감정 카드 맨 위 줄 = 팔 수 있는지**(feel_guards ⓒ): "Can sell: Showroom ✓" / "Can sell: Dealer only until it passes State Inspection" / "Parts & scrap only (JUNK)" + 잠긴 조건 줄("Needs: Showroom (Garage Lv 9)"). 복원 베이 체크리스트에 판매 조건까지, 다 차면 "Ready to sell!", 안 되면 판매 버튼은 처음부터 회색 + 이유. 첫 폐차장 방문엔 **살 만한 차 하나 보장**(feel_guards B).

### 1-2. 바닥값 (폐차가 아무리 나빠도 이만큼은)
- 입구 트럭 저울: **"3,400 lb × $175/ton = $298"** 처럼 쇠값이 먼저 뜸(실제 2026 고철 차 톤당 약 $150~200) → 매입가는 이것보다 아래로 안 내려감.
- 보너스 확인: **촉매가 있나?**(없으면 "Stolen!" — 실제 촉매 도난이 많음, 매입가 −$, 복원 땐 촉매 사서 달기) · 알루미늄 휠 · **엔진이 도나?**

### 1-3. 더 깊은 감정 도구 (선택, 레벨로 열림 — '?'를 하나씩 더 풂)
| 도구 | Lv | 하는 일 | 함정 |
|---|---|---|---|
| **Tap Hammer** | 8 | 녹 자리 6곳(프레임 레일·바닥판·스트럿 타워·문턱·뒤 바퀴집·트렁크 바닥)을 톡톡 → '땡'(멀쩡) / '퍽'(녹·퍼티). 자리별 심각도 **★★★ = 뼈대**(프레임·바닥·스트럿 타워: 수리비 크고 위험) · ★★ = 문턱·바퀴집 · ★ = 펜더·문 아래(볼트 판 → 통째 교체) | |
| **Magnet** | 8 | 판 위로 끌면 퍼티 자리에서 '툭' 떨어짐 | **알루미늄 판은 원래 안 붙음** → 퍼티로 착각하면 오진 |
| **Panel Gap Gauge** | 9 | 문·보닛·트렁크 틈을 끝에서 끝까지 — 한쪽만 3~4 mm 차이면 **사고 차** 단서 | |
| **Flood Check** | 10 | 카펫 들추기(진흙 선) · 스페어 칸 물 자국 · **모든 라이트 김**(하나만이면 증거 X) · 퓨즈 단자 녹 · 진한 방향제 냄새 → 3개 이상이면 FLOOD 의심 | 찾기 전에 시동 걸면 전기 고장 1개 추가 |
| **Breaker Bar** | 8 | 크랭크 풀리를 손으로 돌려 엔진이 도는지 | **벨트를 먼저 안 벗기면 '가짜 굳음'**(발전기가 굳은 것) — 오진 |
| **Compression Gauge** | 11 | 실린더 4개 바늘: 10% 넘게 차이 = 빨강, **이웃 두 개가 같이 낮음 = 헤드 개스킷**, 오일 한 방울 넣어 오르면 = 링 | |
- 감정 카드의 '예상 수리비 $0~250' 범위가 도구를 쓸수록 **좁아짐**(운 대신 실력 — CMS 유저 바람).

## 3. 복원 (RestoreBay)
### 3-1. 필수 / 선택 (30~45분 목표 — 다 넣으면 45분을 넘겨서 나눔)
| | 작업 | 메모 |
|---|---|---|
| **필수** | 세척 20~30초(작은 구역 파워워시) | 먼지·녹이 보이게 — 무엇을 고칠지 단서 |
| **필수** | 기계 고장 **2~3개**(fault_catalog, 시동·주행·안전에 필요한 것) | `Config.FaultCount` 2~5 중 폐차는 2~3으로 시작 |
| **필수** | 눈에 띄는 외장 문제 **1개**: 얕은 긁힘 = 광내기만 / 깊은 긁힘·녹 = **필요한 도색 단계만**(샌딩 → 프라이머 → 색 → 클리어 → 광) / 찌그러짐 = 해머 | 도색 순서는 fault_catalog |
| **필수** | 시동 확인 + 짧은 시운전 | 끝났다는 확인 |
| 선택 | 실내 청소, 전체 광내기, 유리 교체, **숨은 발견물**(주차권·사진·장난감 → 도감), 튜닝 | 복원도·판매가를 더 올림 |
| 가끔(사건) | **녹슨 볼트**: 침투유 뿌리고 기다리면 쉽게, 바로 돌리면 가끔 "똑!" 부러짐 → 드릴 미니게임 | wr-carbook 08 아이디어. 매번 X |
| 가끔(시대 차) | 그 시대 특수 수리 1개(era_cars §1) | |
- Lv8 기본 도색(스프레이건)은 처음부터 됨. Lv16 Paint Booth = **품질↑ 장비**(도색 점수 상한 70 → 100).

### 3-1b. 복원 수준 고르기 (차를 베이에 올릴 때)
| 수준 | 뜻 | 정답인 차 |
|---|---|---|
| **Driver** | 싸고 빠르게, 매일 탈 만큼 | 흔한 차(기본) |
| **Restomod** | 옛 차 + 요즘 부품(튜닝) — 되돌릴 수 있는 개조 | **흔한 클래식** — 잘 만든 레스토모드가 순정보다 비싸게 팔리기도(Tuner 바이어 +) |
| **Original (Concours)** | 순정 부품·원래 모습, 오래·비쌈 | **희귀 시대 차** — 순정일 때 거의 항상 최고가, 개조하면 그 웃돈이 사라짐(Collector 바이어 +) |
- 차 희귀도에 따라 정답이 달라서 고르는 게 재미(§4 튜닝과 연결).

### 3-1c. 흔한 복원 실수 → 함정 (실제 정비소 실수, 아이가 바로 이해하는 6개)
| 실수 | 무슨 일이 | 언제 드러나나 |
|---|---|---|
| **탈지를 건너뜀** | 칠에 동그란 구멍(피시아이) — 실리콘·왁스·기름 때문 | 칠한 직후(확률). 하룻밤 말리고 다시 칠 |
| **녹 위에 그냥 칠** | 밑에서 녹이 자라 물집 | **쇼룸에 진열한 다음 날** 물집 → 시세 ↓(판매 뒤 반품 X — 받은 돈은 안 빼앗음) |
| **퍼티를 너무 두껍게** | 핀홀, 들킴 | 바이어가 **자석을 꺼내** 확인 → 제안 ↓ |
| **스프레이를 한 곳에 오래** | 흘러내림 | 바로 — 갈고 다시 |
| **용접을 길게 한 번에** | 판이 물결처럼 휨 | 바로 — '식히기' 게이지를 기다려야 함 |
| **떼어 낸 볼트를 봉투에 안 넣음** | 조립 때 볼트가 남거나 모자람 | 조립 때 '남은 볼트' 퍼즐 |
- 맨 쇠엔 **에폭시 프라이머 먼저**(실러·퍼티를 맨 쇠에 바로 X — 혼다 정비 지침) → 도색 순서 카드에 단계로 넣음(fault_catalog 도색 순서와 같음).
- 나머지 실수(샌딩 자국 부풂·솔벤트 팝·오렌지 필·센 매체로 블라스팅 등)는 나중 확장.

### 3-2. 복원도 → 등급
- **복원도 %** = 핵심 부품 상태 60%(시동·주행·안전 부품만 — 멀쩡한 부품이 많아 고장이 묻히지 않게) + 외관 25%(도색·판금) + 청결 15%(세척·실내). 외관과 청결은 서로 안 겹치게(세척은 청결에만).
- 등급: **Bronze 60%+ · Silver 80%+ · Gold 95%+**(아이가 읽기 쉬움). 가격표엔 미국 시세표 말로 같이: Gold = **Excellent**(실제 KBB에서도 매물의 2%뿐 — 진짜 어려움), Silver = **Very Good**, Bronze = **Good**, 60% 밑 = **Fair**. 시대 차는 클래식 등급 **#1 Concours · #2 Excellent · #3 Good · #4 Fair**(Hagerty식). 시동·안전 문제가 남으면 **쇼룸 진열 X**(즉시 판매만 — 낮은 값).

| 부품 | 효과 | 표시 |
|---|---|---|
| Custom Wheels · Spoiler/Body Kit · Paint Pattern | 외관 | 장착비 + **"Tuner buyers +$X"** |
| Sport Exhaust | 배기음 | 〃 |
| Performance Air Filter · Lowering Springs | 성능 표시(다이노 Lv16) | 〃 |
- **가격표에서 먼저 보이게**: "Collector: original +$X / Tuner: mods +$Y". 시대 차는 **원래 부품을 보관 → 언제든 되돌리기** 가능(영구 손해 X). 도감 기록은 팔거나 되돌려도 남음.
- 튜닝은 차 값에 배수가 아니라 **장착비 + 예상 판매 증가액**을 따로 보여 줌(손익이 읽히게).

## 5. 쇼룸·바이어·흥정 (Showroom)
- 진열: `Showroom.DisplaySpots.SpotN`(Lv9 1칸 / Lv12 3칸 / Lv16 6칸). 가격표(추천값 = 시세)는 보여 주기용 — **바이어 제안은 호가가 아니라 시세·상태·선호로 계산**(호가 부풀리기 악용 X).
- 바이어: 쇼룸에 **한 번에 한 명씩** `BuyerDoor`로 들어옴(진열 차가 여럿이면 차례로), 접속 중에만(오프라인 판매 X). 처음엔 **3종**: **Quick Buyer**(빠름, 시세 95~100% 제시) · **Bargain Hunter**(75~85%로 시작) · **Collector**(시대 차·순정·Gold 등급 +). Tuner·Family는 나중에 '선호 표시'로.
- 흥정 (베타, fun_boost #17): 기본은 **Sell now**(사무실 `Junkyard.Office`나 쇼룸 `SellDesk`에서 딜러에게 즉시 0.8×) — 언제나 가능. 쇼룸에서만 선택형 3번 주고받기: 바이어 제시 → **Accept / Counter +5% / Counter +10% / Decline**, 버튼 옆에 **성공 예상 표시**(Likely / Maybe / Risky), 머리 위 기분 게이지 1개. 반격이 거절되면 **직전 제안을 한 번 더 받을 기회**. 떠나도 차는 진열된 채 다음 바이어.
- **값을 움직이는 작은 것들**(가격표에 줄로 보임, 실제 중고차 값 요인에서): 타이틀 배수(§1-1) · **정비 기록 폴더**(고친 걸 전부 기록 = +3%, 자동) · **1인 소유**(폐차에 가끔 붙은 표시, +5%) · **드문 색**(노랑·주황·초록 = +3% — 실제로 3년 뒤 값이 가장 덜 떨어진 색) · 튜닝(§4, 바이어마다 ±).
- 바이어의 깎는 폭 = 3~15%(실제 흥정 관습), 무기 = 찾은 흠(자석·틈). 우리 무기 = 정비 기록 폴더·Gold 등급.
- (나중 이벤트) 온라인 7일 경매·'노 리저브' 현장 경매.
- **최종 판매가 상한 = 시세의 110%**(흥정 보너스 최대 +10% — economy와 같음).

## 6. 숫자
- 시세 = 차종 기본값(복원 완료 일반 세단 **$4,800** — v0.3 시뮬, 아래 검산은 $4,200 기준 옛 값) × **타이틀 배수**(CLEAN 1.0 / REBUILT 0.65 / FLOOD 0.6) × 시대 가치 배수(era_cars: 1× / 1.15× / 1.35× / 1.6× / 2× / 2.5×) × 복원도 + 작은 요인(§5) + 튜닝 바이어 보정.
- SALVAGE 검산: 매입 $350 + 부품 $550, Silver 82% → REBUILT 쇼룸 $4,200 × 0.65 × 0.82 = $2,239 → 순이익 **약 $1,340**(싸게 들어가는 대신 덜 남음 — 초반 연습용).
- 검산(GPT, 내가 다시 계산해 확인):
| 예 | 계산 | 순이익 |
|---|---|---|
| 일반, 복원도 82%(Silver), 매입 $700 + 부품 $550 | 쇼룸 $4,200 × 0.82 = $3,444 | **$2,194** |
| 같은 차 즉시 판매 | $3,444 × 0.8 = $2,755 | **$1,505** |
| Rare 1.35×, 82%, 매입 $945 + 부품 $650 | 쇼룸 $4,200 × 1.35 × 0.82 = $4,649 | **$3,054** |
| 같은 Rare 즉시 판매 | $4,649 × 0.8 = $3,719 | **$2,124** |
| 일반 Gold 100%, 매입 $500 + 부품 $400 | 쇼룸 $4,200 | 약 **$3,300** |
→ 일반 목표 $1,500~2,200은 **Silver(82%) 근처**에서 맞음. **Gold 완전 복원 약 $3,300은 '상급 보상'으로 둠** — 선택 작업이 15분쯤 더 걸려서(약 60분), 중반 손님 일 시간당 $3,600과 비슷.

## 7. 협동
- 판매가에서 **매입가·부품값을 산 사람에게 먼저 환급** → **남은 이익 100%만** 나눔(손님 일의 `CoopShare`를 그대로 쓰면 4명일 때 이익의 180%가 생김 — GPT 지적, 동의).
- 나누는 비율(주인 = 폐차를 산 사람): 2명 **70/30** · 3명 **60/20/20** · 4명 **55/15/15/15**. 기여 조건 = 작업 단위 1개 이상 완료(economy §3).
- 손해가 나면 도우미 몫은 0(음수 X), 손해는 산 사람이 — **구매 전에 감정 카드로 알려 줌**.
- 평판: 주인 100%, 실제로 일한 도우미 50%(기존 협동 규칙). 판매 평판 = **Bronze 100 · Silver 150 · Gold 200**(economy v0.3, 시뮬).
